## D5. 선형대수: 좌표를 바꾸는 일과 정보를 얻는 일은 다르다

### D5.1 문제에서 출발하기: 작은 잔차가 정확한 해를 보장하는가

두 카메라 광선이 거의 평행하면 영상의 작은 오차가 깊이의 큰 오차가 된다.
최소제곱 프로그램이 정상 종료하고 잔차가 작아도 이 현상은 사라지지 않는다.
이 장의 목표는 행렬 계산법을 암기하는 것이 아니라, 관측이 어떤 방향을 얼마나 구속하는지 읽는 것이다.
기저는 좌표의 뜻을, 특잇값은 관측 민감도를, 영공간은 전혀 구속되지 않은 변화를 알려준다.
계산 순서는 물리량 정의, 좌표 계약, 선형 모델, 분해, 오차 해석이다.

여기서 선형 모델은 `b = A x + e`다.
x는 알아낼 상태, b는 이미 측정한 관측, A는 상태 변화가 관측에 나타나는 방식, e는 모델과 관측의 차이다.
행의 수 m은 관측 수, 열의 수 n은 상태 성분 수다.
영상의 점 개수가 많다고 독립적인 제약도 반드시 많은 것은 아니다.
같은 방향의 행을 반복하면 m은 커지지만 독립적인 방향 수인 rank는 늘지 않을 수 있다.

| 기호 | 크기 | 뜻과 단위 |
|---|---|---|
| x | n×1 | 상태; 위치라면 m, 각도라면 rad |
| b | m×1 | 관측; 영상 잔차라면 px |
| A | m×n | A_ij의 단위는 b_i의 단위/x_j의 단위 |
| e | m×1 | 관측 오차, b와 같은 단위 |
| B | n×n | 기저 벡터를 열로 쌓은 변환 |
| Q,U,V | 문맥별 | 직교 열 벡터, 무차원 좌표 예에서 무차원 |
| sigma_i | scalar | 상태와 관측의 수치 스케일에 의존하는 특잇값 |
| kappa_2 | scalar | 동일한 단위 정규화 아래의 2-노름 조건수 |

이 장의 작은 행렬 예는 명시하지 않으면 무차원이다.
실제 위치와 각도를 한 벡터에 섞을 때는 상태 스케일을 먼저 정의해야 한다.
미터를 밀리미터로 바꾸는 것만으로 열 크기와 조건수가 바뀔 수 있다.
따라서 조건수를 센서 배치의 물리적 품질과 곧바로 동일시하지 않는다.

### D5.2 벡터 자체와 좌표 숫자를 분리하기

물리적 평면의 점 p를 표준 기저로 쓰면 `[3,2] m`라고 하자.
새 기저의 첫 축은 `[1,0]`, 둘째 축은 `[1,1]`이다.
두 축은 독립적이지만 직교하지 않는다.
기저 행렬 B의 열이 축이라는 약속을 지키면 다음처럼 계산한다.

```text
B = [1 1]       c = [c1]       p = B c
    [0 1]           [c2]

p1 = c1 + c2 = 3
p2 =      c2 = 2
따라서 c2 = 2, c1 = 1

c = B^-1 p = [ 1 -1 ] [3] = [1]
               [ 0  1 ] [2]   [2]
```

좌표 c의 두 숫자를 제곱해서 더하면 5지만 실제 길이 제곱은 13이다.
이것은 벡터가 늘어난 것이 아니라 좌표축 사이 각도를 무시한 오류다.
비직교 기저에서는 기저의 내적을 모은 Gram 행렬 G가 필요하다.

```text
G = B^T B = [1 0][1 1] = [1 1]
              [1 1][0 1]   [1 2]

||p||^2 = p^T p
        = (B c)^T (B c)
        = c^T B^T B c
        = c^T G c
        = [1 2][3] = 13 m^2
                 [5]
```

G는 좌표에서 길이와 각도를 재는 계량이다.
B가 직교행렬이면 `B^T B=I`이므로 일반적인 제곱합을 그대로 써도 된다.
회전행렬에서 역행렬 대신 전치를 쓸 수 있는 이유도 이 조건이지, 모든 변환이 그런 것은 아니다.
카메라 내부 행렬 K나 원근 투영 행렬에는 이 규칙을 적용할 수 없다.

기저 B에서 D로 좌표를 바꿀 때 물리 벡터는 동일해야 한다.
따라서 `B c_B = D c_D`이고 왼쪽에 `D^-1`을 곱하면 `c_D=D^-1 B c_B`다.
반대로 원래 좌표로 돌아가면 `c_B=B^-1 D c_D`다.
좌표변환 방향을 이름 없이 기억하는 대신 이 등식에서 다시 도출하면 전치·역행렬 실수를 줄인다.

선형 연산 T 자체도 입력·출력 기저에 따라 표현이 달라진다.
같은 기저 B를 양쪽에 쓰면 `T_B=B^-1 T B`다.
입력을 먼저 물리 좌표로 옮기는 B가 오른쪽에 있고, 결과를 새 좌표로 읽는 `B^-1`이 왼쪽에 있다.
이것은 물체를 실제로 회전시키는 능동 변환과 좌표 눈금을 바꾸는 수동 변환을 구분하는 가장 작은 계산 예다.

![D5 기저와 계량](../research/computer-vision-textbook/mathematics/figures/d5_basis.png)

그림 D5-1. 왼쪽은 좌표 성분의 단위 원, 오른쪽은 같은 성분에 B를 적용한 물리 평면이다.
가로·세로 축은 이 교육 예에서 m이고, 양쪽 축 범위와 종횡비를 같게 유지했다.
오른쪽이 타원이 되는 것은 비직교 기저의 단순 성분 제곱합이 물리 길이를 보존하지 않기 때문이다.
NumPy로 생성한 합성 도형이며 실제 카메라 영상이나 보정 결과가 아니다.

### D5.3 내적·외적·노름: 같은 곱셈 기호가 아닌 세 가지 질문

내적 `a^T b`는 한 벡터가 다른 벡터 방향으로 얼마나 놓였는지를 묻는다.
단위 벡터 u에 대한 a의 정사영 계수는 `u^T a`다.
u가 단위가 아니면 길이 제곱으로 나누어야 한다.
계수 alpha로 `alpha u`를 만들고 a와의 제곱거리를 최소화하면 이를 직접 얻는다.

```text
E(alpha) = (a-alpha u)^T(a-alpha u)
         = a^T a - 2 alpha u^T a + alpha^2 u^T u
dE/dalpha = -2 u^T a + 2 alpha u^T u = 0
alpha = (u^T a)/(u^T u)
projection = u (u^T a)/(u^T u)
```

`a=[3,2]`, `u=[1,1]`이면 alpha는 5/2이고 투영은 `[2.5,2.5]`다.
남은 벡터 `[0.5,-0.5]`와 u의 내적은 0이다.
이 직교성은 뒤에서 최소제곱의 정규방정식으로 확장된다.

외적은 3차원 방향 두 개에 수직인 방향과 평행사변형 면적을 함께 표현한다.
오른손 좌표계를 약속하고 다음 순서를 쓴다.

```text
a x b = [a2 b3-a3 b2,
         a3 b1-a1 b3,
         a1 b2-a2 b1]^T

a=[1,2,0], b=[0,1,3]
a x b=[6,-3,1]
a^T(a x b)=6-6+0=0
b^T(a x b)=0-3+3=0
```

a와 b가 길이 m인 변이면 외적의 단위는 m²다.
정규화한 법선은 무차원이고 외적의 노름은 면적이다.
거의 평행한 두 벡터의 외적은 작으므로 정규화 과정이 오차를 크게 증폭한다.
법선을 계산할 수 있다는 사실과 법선 방향을 안정적으로 알 수 있다는 사실은 다르다.

1-노름은 절댓값 합, 2-노름은 제곱합의 제곱근, 무한대 노름은 최대 절댓값이다.
`[3,-4]`의 값은 각각 7, 5, 4다.
행렬의 유도 2-노름은 단위 입력을 가장 크게 늘리는 배율이다.
이 배율은 가장 큰 특잇값과 같지만, 행렬 원소 제곱합의 제곱근인 Frobenius 노름과는 다르다.
`diag(3,4)`의 유도 2-노름은 4이고 Frobenius 노름은 5다.
오차 상계를 어떤 노름으로 쓰는지 명시해야 수치 비교가 의미를 갖는다.

### D5.4 양의 준정부호와 고유분해: 제곱합의 곡률을 읽기

대칭행렬 C가 모든 v에 대해 `v^T C v >= 0`이면 양의 준정부호다.
영어 positive semidefinite를 줄여 PSD라고 한다.
0이 아닌 모든 v에서 엄격히 양수이면 양의 정부호, positive definite다.
공분산이 PSD여야 하는 이유는 임의 방향으로 본 확률 변수의 분산이 음수일 수 없기 때문이다.
최소제곱에서 `A^T A`가 PSD인 이유는 더 직접적이다.

```text
v^T A^T A v = (A v)^T(A v) = ||A v||^2 >= 0
```

A의 영공간에 0이 아닌 v가 있으면 위 값이 0이 되므로 정부호는 아니다.
즉 곡률이 0인 방향은 상태를 움직여도 잔차가 바뀌지 않는 방향이다.
관측 불가능성을 수치적으로 매우 작은 양수로 바꾸어 출력했다고 정보가 생기지는 않는다.

대칭행렬의 고유분해를 `C=V diag(lambda_i) V^T`라고 쓰자.
V의 열은 서로 직교하는 단위 고유벡터이고 lambda_i는 그 방향의 배율이다.
다음 2×2 예는 행렬식을 실제로 전개할 수 있다.

```text
C = [2 1]
    [1 2]

det(C-lambda I) = (2-lambda)^2 - 1
               = lambda^2 - 4 lambda + 3
               = (lambda-1)(lambda-3)

lambda=3: (C-3I)v=0 -> -v1+v2=0
          v_plus=[1,1]/sqrt(2)
lambda=1: (C-I)v=0 -> v1+v2=0
          v_minus=[1,-1]/sqrt(2)
```

두 고유값이 양수이므로 C는 정부호다.
`v_plus` 방향의 분산이 3, `v_minus` 방향의 분산이 1인 공분산으로도 해석할 수 있다.
타원의 반축 길이는 고유값 자체가 아니라 제곱근에 비례한다.
반대로 목적함수 곡률 행렬이면 큰 고유값 방향이 더 가파른 방향이다.
같은 행렬 수학이라도 공분산과 정보행렬의 해석은 서로 역수 관계다.

비대칭행렬에 이 대칭 고유분해를 그대로 쓰지 않는다.
고유값이 복소수일 수 있고 고유벡터가 직교하지 않을 수 있으며 충분한 고유벡터가 없을 수도 있다.
직사각 관측행렬을 다루는 일반적인 도구는 다음의 특잇값 분해다.

### D5.5 SVD, rank, 영공간을 하나의 분해로 보기

특잇값 분해는 Singular Value Decomposition의 약자로 SVD다.
실수 m×n 행렬 A를 `A=U Sigma V^T`로 나타낸다.
U와 V의 열은 관측 공간과 상태 공간의 직교 방향이고 Sigma에는 음수가 아닌 특잇값이 놓인다.
이 분해의 의미는 입력 직교변환, 축별 스케일, 출력 직교변환의 세 단계다.
직교변환은 회전뿐 아니라 반사를 포함할 수 있으므로 U,V를 항상 순수 회전으로 부르지 않는다.

```text
x --V^T--> 상태의 독립 방향 좌표
  --Sigma--> 각 방향을 sigma_i 배로 확대/축소
  --U--> 관측 좌표로 조합

A v_i = sigma_i u_i
A^T A v_i = sigma_i^2 v_i
```

양수인 특잇값 개수가 정확 산술의 rank다.
sigma_i가 0인 오른쪽 특이벡터 v_i는 `A v_i=0`을 만족한다.
이것이 영공간, nullspace다.
열이 n개이면 rank와 영공간 차원의 합은 n이다.
full SVD와 economy SVD의 배열 크기를 혼동하면, 과소결정 문제에서 영공간 열을 놓칠 수 있다.

하나의 관측 `x1+x2=2`를 예로 들면 A는 `[1,1]`이다.
관측되는 방향은 `[1,1]/sqrt(2)`이고 관측되지 않는 방향은 `[1,-1]/sqrt(2)`다.
특잇값은 sqrt(2) 하나다.
모든 해는 `[1,1]+t[1,-1]`이고 t는 임의의 실수다.
상태 숫자 두 개가 출력되었다고 두 성분을 독립적으로 측정한 것은 아니다.

유한정밀도에서는 0과 아주 작은 특잇값을 구분하는 임계값이 필요하다.
예를 들어 `tau=max(m,n)*machine_epsilon*sigma_max` 형태는 수치 rank의 기준이 될 수 있다.
그러나 센서 잡음이 그보다 훨씬 크면 수치적으로 0이 아니어도 통계적으로 쓸모없는 방향일 수 있다.
수치 rank는 계산 형식의 기준이고 유효 관측성은 잡음·스케일·모델까지 포함한 기준이다.
두 판단을 하나의 tolerance에 숨기지 않는다.

### D5.6 최소제곱: 정규방정식은 유도식이지 필수 구현법이 아니다

관측이 상태보다 많고 오차가 있으면 `A x=b`를 정확하게 만족시키지 못한다.
그때 목적함수를 다음처럼 정의한다.

```text
E(x) = 1/2 ||A x-b||^2
     = 1/2 (x^T A^T A x - 2 x^T A^T b + b^T b)

gradient E = A^T A x - A^T b
stationary condition: A^T A x = A^T b
equivalently: A^T(A x-b)=0
```

마지막 식은 잔차가 A의 모든 열에 직교한다는 뜻이다.
즉 b를 A의 열공간에 정사영한 점이 `A x_hat`이다.
A가 full column rank이면 `A^T A`가 정부호이고 해가 유일하다.
rank가 부족하면 최소 잔차를 만드는 해가 여러 개일 수 있다.

직선 `b_i=a+c t_i`를 관측 `[1,2,2]`와 시간 `[0,1,2]`에 맞추자.
a의 단위는 m, c의 단위는 m/s이고 이 예의 시간 간격은 1s다.

```text
A = [1 0]       b=[1]
    [1 1]         [2]
    [1 2]         [2]

A^T A = [3 3]     A^T b=[5]
        [3 5]           [6]

3a+3c=5
3a+5c=6
두 식의 차: 2c=1 -> c=1/2
3a=5-3/2=7/2 -> a=7/6

prediction=[7/6,10/6,13/6]
residual prediction-b=[1/6,-2/6,1/6]
잔차 합=0, 시간 가중 잔차 합=0
```

이 예는 손계산에 정규방정식이 편리하다는 사실을 보여준다.
하지만 구현에서 A의 전치와 A를 곱하는 순간 작은 특잇값이 제곱된다.
정확한 해의 수학적 유도와 안정적인 수치 알고리즘의 선택을 분리해야 한다.

### D5.7 QR과 의사역행렬: 역행렬을 만들지 않고 해 구하기

QR 분해는 A를 직교 열을 가진 Q와 위삼각 R의 곱으로 쓴다.
full column rank인 m≥n 문제에서 economy 형태의 Q는 m×n, R은 n×n이다.
b를 Q의 열공간 성분과 그 직교 성분으로 나누면 목적함수는 다음처럼 분리된다.

```text
b = Q Q^T b + (I-Q Q^T)b
A x-b = Q(Rx-Q^T b) - (I-Q Q^T)b

두 항은 직교한다.
||Ax-b||^2 = ||Rx-Q^T b||^2 + ||(I-Q Q^T)b||^2

두 번째 항은 x와 무관하므로
R x = Q^T b 를 뒤에서부터 푼다.
```

위 직선 예에서 첫 열의 길이는 sqrt(3)이다.
두 번째 열 `[0,1,2]`에서 첫 방향 성분 `[1,1,1]`을 빼면 `[-1,0,1]`이 된다.
그 길이는 sqrt(2)이므로 다음 값을 얻는다.

```text
q1=[1,1,1]/sqrt(3), q2=[-1,0,1]/sqrt(2)
R=[sqrt(3) sqrt(3)]
  [0       sqrt(2)]
Q^T b=[5/sqrt(3),1/sqrt(2)]

sqrt(2)c=1/sqrt(2) -> c=1/2
sqrt(3)(a+c)=5/sqrt(3) -> a=7/6
```

이 설명은 기하를 보여주는 작은 Gram–Schmidt 계산이다.
실제 실험은 SciPy의 QR을 호출하며 이 손계산 반복을 대규모 구현으로 사용하지 않는다.
rank가 부족하면 피벗 QR이나 SVD로 독립 방향을 구분해야 한다.
LAPACK은 full-rank QR/LQ와 rank-deficient SVD 계열의 용도를 구분한다. [LAPACK 공식 문서](https://netlib.org/lapack/lug/node27.html)

SVD 의사역행렬은 양수인 특잇값만 역수로 바꾼다.
`A^+=V Sigma^+ U^T`이고 `x_hat=A^+b`다.
이것은 최소 잔차 해 중 유클리드 노름이 가장 작은 해를 선택한다.
앞의 `x1+x2=2`에서는 `[1,1]`을 선택한다.
그 선택은 두 성분이 실제로 같다는 측정 결과가 아니라 추가적인 최소 노름 규약이다.

작은 특잇값을 자르는 truncated SVD는 안정성을 얻는 대신 일부 정보를 버린다.
Tikhonov 정규화는 `||Ax-b||²+lambda||x||²`를 최소화하여 연속적으로 작은 방향을 억제한다.
SVD 방향 i에서 무정규화 배율이 `1/sigma_i`라면 정규화 배율은 `sigma_i/(sigma_i²+lambda)`다.
lambda가 커지면 분산은 줄 수 있지만 해가 0 쪽으로 편향된다.
규제항을 넣었다면 그 prior와 단위를 실험 계약에 밝혀야 한다.

### D5.8 조건수 실패 실험: 같은 입력, 다른 계산 경로

가역행렬에서 상대 입력 오차가 해에 얼마나 증폭될 수 있는지를 조건수로 요약한다.
2-노름 조건수는 `kappa_2(A)=sigma_max/sigma_min`이다.
이는 최악 방향의 상계이지 모든 입력 오차가 그만큼 커진다는 예언은 아니다.
A가 rank deficient이면 가장 작은 특잇값이 0이고 역문제 조건수는 무한대다.

```text
Ax=b, A(x+dx)=b+db -> A dx=db
||dx|| <= ||A^-1|| ||db||
||b|| = ||Ax|| <= ||A|| ||x||
따라서 ||dx||/||x|| <= kappa(A) ||db||/||b||

sigma_i(A^T A)=sigma_i(A)^2
kappa_2(A^T A)=kappa_2(A)^2
```

합성 실험은 30×2 행렬의 직교 방향을 고정하고 특잇값을 `[1,1/k]`로 설정한다.
진실값은 `[1,-2]`, 관측은 잡음을 더하지 않은 `b=A x_true`다.
k를 10에서 10¹⁰까지 바꾸고 float64 정규방정식, QR, SVD를 비교한다.
외부 센서 잡음이 없으므로 이 실험은 계산 경로의 차이를 분리한다.
단, b를 만드는 곱셈 자체에도 유한정밀도 반올림이 있다는 점은 남는다.

![D5 조건수와 수치 실패](../research/computer-vision-textbook/mathematics/figures/d5_condition.png)

그림 D5-2. 가로축은 무차원 조건수, 세로축은 진실값에 대한 해의 상대 2-노름 오차이며 둘 다 로그 축이다.
세 곡선은 같은 합성 행렬·관측을 서로 다른 분해로 푼 실제 NumPy/SciPy 결과다.
정규방정식에서 특이행렬 오류가 난 지점은 숫자로 덮지 않고 배열의 NaN 및 metrics의 실패 목록으로 남긴다.
이 그림은 특정 하드웨어의 반올림 결과이며 QR이 불량한 관측 기하 자체를 고친다는 뜻은 아니다.

여기서 ablation은 A와 b를 고정하고 해법만 바꾼 것이다.
QR/SVD의 상대오차가 더 작아도 새 측정 정보를 만든 것은 아니다.
입력 b에 실제 잡음을 더하면 안정적인 해법도 작은 특잇값 방향에서 큰 상태 오차를 피할 수 없다.
해결책은 계산 경로 변경과 관측 설계 변경을 구분하는 것이다.
전자는 QR/SVD·스케일 조정, 후자는 시차 추가·다른 방향의 센서·정당한 prior다.

### D5.9 PCA: 가장 큰 분산이 항상 원하는 구조는 아니다

Principal Component Analysis, 주성분 분석을 PCA라고 한다.
데이터를 평균 중심으로 이동한 뒤 가장 큰 분산 방향을 찾는다.
중심화된 행렬 X의 행에 점을 놓고 표본 수를 N이라고 하자.
이 절의 유도에서는 분모 N을 사용하는 경험적 이차 모멘트 `C=X^T X/N`을 쓴다.
실험 그림의 `np.cov`는 분모 N-1을 쓰며 방향은 같고 고유값 스케일만 달라진다.

```text
단위 방향 v의 투영값: Xv
투영 분산: (Xv)^T(Xv)/N = v^T C v
제약: v^T v=1

L(v,lambda)=v^T C v-lambda(v^T v-1)
dL/dv=2Cv-2lambda v=0
Cv=lambda v
```

가장 큰 고유값을 고르면 가장 큰 투영 분산을 얻는다.
점들을 그 축에 투영하고 다시 복원할 때 버려지는 제곱오차도 최소가 된다.
이 두 해석의 연결은 총 에너지가 방향별 제곱합으로 분리되기 때문이다.
`||X||_F²`는 고정이고 복원된 에너지는 `||Xv||²`이므로 버려진 에너지를 최소화하는 것은 보존 에너지를 최대화하는 것과 같다.

작은 예로 네 점 `[-2,-1],[-1,0],[1,0],[2,1]`은 이미 중심화되어 있다.
행렬 곱을 성분별로 계산하면 다음과 같다.

```text
sum x_i^2 = 4+1+1+4 = 10
sum y_i^2 = 1+0+0+1 = 2
sum x_i y_i = 2+0+0+2 = 4
C = [2.5 1.0]
    [1.0 0.5]

det(C-lambda I)=lambda^2-3lambda+0.25
lambda=(3 +/- sqrt(8))/2
```

분산이 큰 방향은 점군의 길쭉한 축을 설명한다.
그러나 다른 단위의 feature를 섞으면 큰 숫자 단위가 PCA를 지배할 수 있다.
표준화는 이 문제를 줄이지만 분석 질문도 바꾼다.
원래 물리 에너지를 최대화할지, 각 feature의 표준편차를 같게 볼지 먼저 정해야 한다.

![D5 PCA와 이상치](../research/computer-vision-textbook/mathematics/figures/d5_pca.png)

그림 D5-3. 두 축은 합성 점 위치 m이고 파란 점은 상관 Gaussian에서 뽑은 400개 표본이다.
같은 `[12,-12] m` 점을 25회 추가한 후 주축을 다시 구하여 깨끗한 PCA 주축과 비교했다.
멀리 떨어진 점은 제곱거리 기여가 커서 적은 수라도 분산 방향을 바꾼다.
반복 이상치는 실제 센서의 발생률 모형이 아니라 PCA의 영향력을 드러내기 위해 의도적으로 만든 실패 조건이다.

이 실패의 후속 선택은 무엇이 이상치인지에 달려 있다.
알려진 혼합집단이면 각 집단을 모델링하고, 드문 큰 오차이면 robust 공분산이나 기하 검증을 검토한다.
PCA 축을 삭제하기 전에 멀리 떨어진 점이 실제로 중요한 구조인지 확인해야 한다.
수학적으로 큰 분산을 찾는 목적과 의미론적으로 중요한 구조를 찾는 목적은 같지 않다.

## D6. 미분과 최적화: 비선형 모델을 어디까지 믿고 움직일 것인가

### D6.1 최적화의 계약: 답보다 먼저 잔차를 정의한다

카메라 자세를 조금 바꾸면 투영 픽셀이 움직인다.
관측 픽셀과 예측 픽셀의 차이를 줄이려면 어떤 상태 방향으로 얼마나 움직여야 하는지 알아야 한다.
미분은 그 국소 민감도를 계산하고, 최적화는 국소 예측을 실제 목적함수와 비교하며 이동을 결정한다.
미분값이 정확하다는 것과 큰 이동이 안전하다는 것은 다른 문제다.
이 장에서는 기하 모델 자체보다 그 모델을 푸는 공통 계산 구조에 집중한다.

상태를 x, 측정 벡터를 z, 예측 함수를 h(x), 잔차를 `r(x)=h(x)-z`로 고정한다.
반대 부호를 선택해도 제곱 목적함수는 같지만 Jacobian과 우변 부호를 함께 바꿔야 한다.
이 장의 기본 목적함수는 `E(x)=1/2 r(x)^T r(x)`다.
서로 단위가 다른 잔차는 먼저 표준편차로 나누거나 공분산으로 whitening한다.
그 후 E는 무차원이다.

| 기호 | 크기 | 의미 |
|---|---|---|
| x | n×1 | 현재 상태, 성분마다 물리 단위를 가질 수 있음 |
| delta | n×1 | 상태 증분, x와 같은 단위 |
| r | m×1 | whitening 전 관측 단위, 이후 무차원 |
| J | m×n | J_ij=dr_i/dx_j, 잔차 단위/상태 단위 |
| g | n×1 | 목적함수 gradient, E 단위/상태 단위 |
| H | n×n | Hessian, E 단위/(상태_i 단위×상태_j 단위) |
| D | n×n | 상태 스케일의 역수를 담는 대각행렬 |
| lambda | scalar | 감쇠 계수, 스케일 정의와 함께 해석 |
| Delta | scalar | 정규화한 상태 공간의 신뢰영역 반경 |

입력은 함수와 미분 또는 미분 계산 규칙, 시작 상태, 허용오차, 스케일이다.
출력에는 최종 상태뿐 아니라 종료 이유·목적함수·gradient 크기·반복 수가 포함되어야 한다.
반복 한도에 도달한 결과를 수렴한 최적해로 표시하지 않는다.
비선형 최소제곱의 국소해는 전역해 보증이 아니며, 잘못된 대응점은 미분이 정확해도 잘못된 해를 만든다.

### D6.2 편미분과 전미분: 무엇을 고정했는지 말하기

함수 `f(x,y)=x²+xy`를 생각하자.
x만 조금 바꾸고 y를 고정한 변화율은 `df/dx=2x+y`라는 편미분이다.
y만 바꾸면 `df/dy=x`다.
둘이 동시에 변할 때 첫째 차수 변화는 두 기여의 합이다.

```text
f(x+dx,y+dy)
 = (x+dx)^2 + (x+dx)(y+dy)
 = x^2+xy + (2x+y)dx + x dy + dx^2+dx dy

df = (2x+y)dx + x dy
높은 차수 나머지 = dx^2+dx dy
```

편미분 두 개를 쌓은 열벡터가 gradient다.
상태 공간에 유클리드 계량과 같은 단위의 좌표를 쓸 때 gradient는 가장 빠르게 증가하는 방향을 가리킨다.
좌표 단위를 바꾸면 수치 gradient도 바뀌므로 이 설명을 무조건 물리 공간의 방향이라고 해석하지 않는다.
길이와 각도를 섞은 상태에서는 스케일 행렬을 명시하는 것이 중요하다.

벡터 함수의 편미분들을 행별로 쌓으면 Jacobian이다.
첫 행은 첫 출력의 gradient를 전치한 것이고 열은 입력 성분을 뜻한다.
`f:R^n -> R^m`이면 J는 m×n이다.
`df=J dx`의 곱셈 크기를 확인하면 행·열 전치 오류를 쉽게 찾는다.

### D6.3 다변수 연쇄법칙을 중간 변수까지 전개하기

중간 함수 `u=g(x)`와 출력 `y=f(u)`의 합성에서는 먼저 dx가 du로 어떻게 전달되는지 쓴다.
`du=J_g dx`이고 `dy=J_f du`이므로 `dy=J_f J_g dx`다.
곱셈 순서는 계산 그래프에서 마지막 함수의 Jacobian이 왼쪽에 온다.
행렬은 일반적으로 교환되지 않으므로 순서를 암기 대신 크기로 확인한다.

스칼라 출력의 구체적인 예를 끝까지 계산하자.
`q=x y+sin(x)`, `E=q²`, 평가점은 `(x,y)=(2,3)`이다.

```text
dq/dx = y+cos(x)
dq/dy = x
dE/dq = 2q

dE/dx = 2(xy+sin x)(y+cos x)
dE/dy = 2(xy+sin x)x

x=2, y=3:
q = 6+sin(2)
gradient E = 2(6+sin 2)[3+cos 2, 2]^T
```

여기서 sin의 입력은 rad로 표현한 무차원 각도여야 한다.
위 예는 x,y가 모두 무차원인 교육 함수이므로 합과 곱의 단위 충돌이 없다.
실제 시스템에서 `xy+sin x`를 쓰려면 xy도 무차원인지 확인해야 한다.
수학 라이브러리가 숫자를 반환하는 것은 물리 단위가 맞다는 검증이 아니다.

카메라 투영의 간단한 연결도 보자.
`u=f X/Z+c`에서 f,c,u는 px, X,Z는 m다.
X와 Z에 대한 편미분은 `du/dX=f/Z`, `du/dZ=-fX/Z²`이며 단위는 px/m다.
3D 점이 다른 상태 theta의 함수이면 `du/dtheta=[f/Z,0,-fX/Z²] dP/dtheta`다.
Z가 0에 가까우면 민감도가 커져 선형화와 수치 계산이 동시에 불안정해진다.
미분을 잘 계산해도 분모의 물리적 퇴화는 제거되지 않는다.

### D6.4 Taylor 전개와 Hessian: 선형 근사의 오차를 눈에 보이게 하기

충분히 매끄러운 스칼라 함수의 한 점 주변 전개는 다음과 같다.

```text
E(x+delta)
 = E(x) + g(x)^T delta
   + 1/2 delta^T H(x) delta + R3

g_i = dE/dx_i
H_ij = d^2E/(dx_i dx_j)
R3는 매끄러움 가정 아래 ||delta||^3 크기의 나머지
```

Hessian은 gradient가 상태에 따라 바뀌는 속도다.
혼합 편미분이 연속이면 H는 대칭이다.
양의 정부호이면 그 점 부근 이차모델이 모든 방향으로 위로 굽는다.
음의 고유값이 있으면 그 방향으로 아래로 굽어, stationary point가 최소라는 보장이 없다.
gradient가 0이라는 조건만으로 최소를 선언할 수 없는 이유다.

2변수 함수 `E=x²+xy+2y²`에서는 `g=[2x+y,x+4y]`이고 `H=[[2,1],[1,4]]`다.
원점에서 g=0이며 H의 첫 주행렬식 2와 determinant 7이 양수이므로 정부호다.
이 함수는 정확한 이차식이라 Taylor의 나머지가 0이다.
반대로 `E=x²-y²`는 원점 gradient가 0이지만 y 방향으로 감소하므로 안장점이다.

제곱 잔차에서는 Hessian을 직접 전개하는 것이 Gauss–Newton의 가정을 드러낸다.

```text
E=1/2 sum_i r_i^2
g_j=sum_i r_i (dr_i/dx_j)

H_jk=sum_i [(dr_i/dx_k)(dr_i/dx_j)
           +r_i(d^2r_i/dx_k dx_j)]

H = J^T J + sum_i r_i H_i
H_i는 i번째 잔차 자체의 Hessian
```

Gauss–Newton을 줄여 GN이라고 쓰며, 이 방법은 두 번째 항을 생략한다.
잔차가 작거나 잔차 함수가 거의 선형이면 합리적일 수 있다.
하지만 큰 잔차에서는 곡률을 크게 잘못 볼 수 있다.
`r(x)=x²-4`에서 x=1이면 r=-3, J=2다.
따라서 `J^T J=4`지만 정확한 Hessian은 `4+(-3)*2=-2`다.
이 차이는 단순 반올림이 아니라 모델 근사 자체의 차이다.

### D6.5 수치 미분: h를 작게 할수록 정확하다는 착각

전진차분은 `(f(x+h)-f(x))/h`로 미분을 근사한다.
Taylor 전개를 대입하면 다음 오차를 얻는다.

```text
f(x+h)=f(x)+h f'(x)+h^2 f''(x)/2+O(h^3)
forward = f'(x)+h f''(x)/2+O(h^2)

f(x-h)=f(x)-h f'(x)+h^2 f''(x)/2-h^3 f'''(x)/6+...
central = [f(x+h)-f(x-h)]/(2h)
        = f'(x)+h^2 f'''(x)/6+O(h^4)
```

이 식만 보면 h가 작을수록 좋아 보인다.
하지만 컴퓨터의 f(x+h)와 f(x)에는 반올림이 있고 두 비슷한 수를 빼면 유효숫자가 사라진다.
대략적인 총오차는 전진차분에서 `C1 h+C2 epsilon/h`, 중앙차분에서 `C3 h²+C4 epsilon/h`다.
계수는 함수와 좌표 스케일에 의존하므로 하나의 h를 모든 변수에 적용하는 것은 위험하다.
위 모델을 최소화하면 전진차분의 적정 크기는 sqrt(epsilon), 중앙차분은 epsilon^(1/3) 정도로 나타난다.
이는 스케일이 1 부근인 함수에 대한 크기 추정이지 보편적인 최적값이 아니다.

복소수 단계는 해석적인 함수에서 `imag(f(x+i h))/h`를 사용한다.
실수 두 개의 뺄셈이 없어서 작은 h에서도 cancellation이 덜하다.
하지만 abs, 조건 분기, 실수로 강제 변환, 정렬 같은 비해석적 연산이 들어가면 이 성질이 깨진다.
복소 입력을 지원하지 않는 영상 라이브러리 경로에 무조건 적용할 수 없다.

![D6 미분 간격과 오차](../research/computer-vision-textbook/mathematics/figures/d6_derivatives.png)

그림 D6-1. `sin(x)`를 x=1에서 미분하고 정확한 `cos(1)`과 비교했다.
가로축 h와 세로축 절대 미분 오차는 무차원 로그 축이다.
계산상 0인 오차는 그림에만 10⁻¹⁸로 표시하고 원배열의 0은 보존했다.
전진·중앙차분의 U자형 변화는 절단오차와 반올림의 경쟁이며, 합성 함수의 NumPy float64 실행 결과다.

이 실행에서 최소 관측 오차의 h는 전진차분 약 7.56×10⁻⁹, 중앙차분 약 5.72×10⁻⁶이었다.
이 값은 설정한 100개 h 격자 중 최솟값이며 연속적인 최적 h를 증명한 것이 아니다.
미분 검증은 한 h에서 맞는지 보는 대신 여러 크기에서 예상한 오차 감소가 나타나는지 확인하는 편이 낫다.
상태 성분별 기준 크기 s_j를 두고 `h_j=eta max(|x_j|,s_j)`처럼 조정할 수 있다.
불연속점에서는 차분 검사가 실패해도 구현 버그가 아니라 미분 자체가 정의되지 않은 경우가 있다.

### D6.6 자동미분의 전방 모드: 값과 방향미분을 함께 운반하기

자동미분은 수치 차분이나 거대한 기호식을 만드는 방식과 다르다.
기본 연산의 정확한 미분 규칙을 프로그램의 실행 경로를 따라 조합한다.
Automatic Differentiation을 줄여 AD라고 하며, 이 분류와 전방·역방향의 차이는 Baydin 등(2018)의 정리와 일치한다.
여기서는 범용 AD 엔진을 새로 구현하지 않고 연산 그래프를 손으로 추적한다. [Baydin 등, 2018](https://www.jmlr.org/papers/v18/17-468.html)

`f=(xy)(x+y)`를 x=2,y=3에서 계산하자.
중간 변수 t=xy=6, u=x+y=5, f=tu=30이다.
전방 모드에서는 각 값에 점(dot)을 붙인 방향미분을 함께 저장한다.
x 방향을 알고 싶으면 시작값을 `xdot=1, ydot=0`으로 둔다.

```text
t = x*y
tdot = xdot*y + x*ydot = 1*3+2*0 = 3

u = x+y
udot = xdot+ydot = 1

f = t*u
fdot = tdot*u+t*udot = 3*5+6*1 = 21
```

y 방향에서는 `xdot=0,ydot=1`을 넣으면 tdot=2, udot=1, fdot=16이다.
임의 방향 `[a,b]`를 시작값으로 넣으면 `fdot=21a+16b`를 한 번에 얻는다.
이것이 Jacobian-vector product, Jv다.
입력 차원이 작고 출력이 많으면 각 입력 방향을 전파하는 전방 모드가 자연스럽다.
이 계산은 작은 h를 선택하지 않지만 원래 부동소수점 연산의 반올림까지 없애는 것은 아니다.

### D6.7 역방향 모드: 출력의 기여를 되돌리되 반드시 더하기

역방향 모드는 먼저 순방향 값을 저장한 뒤 출력에 대한 각 중간 변수의 민감도를 뒤로 전파한다.
막대(bar)는 최종 f에 대한 편미분을 뜻한다.
출력 자체의 민감도 fbar는 1로 시작한다.

```text
f=t*u:
tbar += fbar*u = 5
ubar += fbar*t = 6

t=x*y:
xbar += tbar*y = 15
ybar += tbar*x = 10

u=x+y:
xbar += ubar = 6
ybar += ubar = 6

최종 xbar=21, ybar=16
```

중요한 기호는 대입이 아니라 `+=`다.
x는 t와 u 두 경로에 영향을 주므로 두 기여를 더해야 한다.
한 경로의 값을 다른 값으로 덮어쓰면 공유된 중간 변수에서 gradient가 틀린다.
단일 스칼라 목적함수에서 입력이 많을 때 한 번의 역방향 전파로 모든 성분을 얻는 장점이 있다.
대신 중간 값 저장이나 재계산이 필요하므로 시간과 메모리의 교환이 생긴다.

역방향은 일반적으로 vector-Jacobian product, `v^T J`를 계산한다.
큰 Jacobian 전체가 필요 없는 최적화에서 Jv와 `J^T v`만으로 반복 선형 해법을 구성할 수 있다.
이때 희소성은 단순히 행렬을 0으로 채우는 것이 아니라, 어떤 잔차가 어떤 상태 블록에 의존하는지에서 나온다.
자동미분이 정확해도 잘못된 좌표변환·단위·잔차 정의를 미분하면 잘못된 문제를 정확하게 푼다.
미분 검증과 모델 검증은 별도의 검사여야 한다.

### D6.8 Gauss–Newton의 선형 시스템을 처음부터 만들기

현재 x에서 잔차를 선형화한다.
`r(x+delta)≈r+J delta`이고 이 근사 잔차의 제곱을 최소화한다.

```text
m(delta)=1/2(r+J delta)^T(r+J delta)
        =1/2 r^T r + delta^T J^T r
         +1/2 delta^T J^T J delta

dm/ddelta = J^T r + J^T J delta
J^T J delta = -J^T r
```

해를 구한 뒤 x에 delta를 더한다.
실제 회전 상태처럼 manifold 위에 있으면 단순 덧셈 대신 정의한 국소 갱신 연산을 사용한다.
이 장의 합성 예는 유클리드 공간이므로 덧셈이 정확한 계약이다.
가중 잔차에서는 whitening한 J와 r에 같은 유도를 적용한다.

작은 2×2 예를 손으로 풀어보자.

```text
J=[1  1]     r=[-1]
  [1 -1]       [-3]

J^T J=[2 0]     -J^T r=[4]
      [0 2]             [-2]
delta=[2,-1]

검산: r+J delta=[-1,-3]+[1,3]=[0,0]
```

선형화 모델의 잔차가 0이 되는 것은 실제 비선형 잔차가 0이라는 뜻이 아니다.
이 차이를 가장 간단히 보여주는 예가 다음의 두 잔차다.
`r1=10(y-x²)`, `r2=1-x`로 놓고 시작점을 `[-1.2,1]`로 둔다.
현재 잔차는 `[-4.4,2.2]`, 목적함수는 12.1이다.
Jacobian 첫 행은 `[-20x,10]=[24,10]`, 둘째 행은 `[-1,0]`다.

```text
-delta_x = -2.2 -> delta_x=2.2
24 delta_x + 10 delta_y = 4.4
52.8 + 10 delta_y = 4.4 -> delta_y=-4.84

x_new=1, y_new=-3.84
r1_new=10(-3.84-1)=-48.4
r2_new=0
E_new=48.4^2/2=1171.28
```

선형 모델은 완벽한 감소를 예측했지만 실제 비용은 약 97배가 되었다.
이는 GN의 수식 오류가 아니라 선형화 범위를 벗어난 이동의 실패다.
같은 함수에 대한 SciPy 최소제곱 해법은 이 실험에서 `[1,1]`을 얻었다.
이 사실을 모든 초기값에서 전역 수렴한다는 보증으로 확대하지 않는다.

### D6.9 감쇠·경사하강·신뢰영역을 구분하기

경사하강은 `delta=-alpha g`를 사용한다.
한 번의 방향 계산은 단순하지만 길고 좁은 골짜기에서는 큰 곡률 방향에 맞춘 작은 alpha 때문에 느릴 수 있다.
이차 목적함수 `E=1/2 x^T H x`에서 고유방향 i의 상태는 한 단계마다 `(1-alpha lambda_i)`배가 된다.
모든 양의 고유값 방향에서 줄어들려면 `0<alpha<2/lambda_max`가 필요하다.
큰 조건수에서는 작은 고유값 방향이 매우 천천히 줄어든다.

Levenberg–Marquardt, LM은 선형화 문제에 감쇠를 더해 이동을 제한한다.
정규화 스케일 D를 포함하면 다음처럼 쓸 수 있다.

```text
min_delta 1/2||r+J delta||^2 + lambda/2||D delta||^2

(J^T J + lambda D^T D)delta=-J^T r
```

lambda가 작고 rank가 충분하면 GN에 가깝다.
lambda가 크면 `delta≈-(1/lambda)(D^T D)^-1 g`가 되어 스케일 조정된 경사하강에 가깝다.
D=I를 무조건 쓰면 위치 m와 각도 rad를 같은 숫자 크기로 취급하는 문제가 있다.
Moré의 1977 기술보고서는 LM 구현에서 변수 스케일과 감쇠 선택의 중요성을 다룬다. [기관 보관본](https://digital.library.unt.edu/ark:/67531/metadc1448594/)

신뢰영역은 선형·이차 근사가 믿을 만한 범위 안에서만 움직인다는 별도의 해석이다.
`||D delta||<=Delta` 제약 아래 m(delta)를 줄이고 실제 감소를 비교한다.
비율 rho는 확률의 상관계수와 다른 기호이며 여기서는 모델의 예측 품질을 뜻한다.

```text
predicted = m(0)-m(delta)
actual = E(x)-E(x+delta)
rho = actual/predicted       (predicted > 0일 때)

rho가 음수: 실제로 악화 -> 이동 거절, 영역 축소
rho가 작은 양수: 모델이 과신 -> 영역 축소 검토
rho가 1 부근: 예측 신뢰 가능 -> 이동 수용, 확장 검토
```

감쇠항을 넣는다는 사실만으로 신뢰영역 구현이 완성되는 것은 아니다.
수용·거절, 스케일, 감쇠 조절, 종료 기준이 함께 있어야 한다.
이 실험의 damped 경로는 비용 감소가 나올 때까지 lambda를 10배씩 늘리는 교육용 규칙이다.
SciPy 내부 LM 또는 trust-region 알고리즘의 반복 궤적을 재현했다고 주장하지 않는다.

![D6 최적화 경로](../research/computer-vision-textbook/mathematics/figures/d6_optimization.png)

그림 D6-2. 등고선은 `1/2[100(y-x²)²+(1-x)²]`의 합성 무차원 비용이다.
점을 이은 경로는 동일 초기값에서 고정 간격 경사하강, full GN, 교육용 감쇠 반복을 실제 실행한 결과다.
GN 첫 점의 큰 이동이 원래 골짜기를 벗어나는지 읽는다.
경사하강은 120회, 나머지는 15회이므로 점 개수를 계산시간이나 공정한 성능 순위로 해석하지 않는다.

### D6.10 희소 연산: 잔차의 의존 관계가 메모리를 결정한다

연속 상태 x0부터 x5까지 있고 상대 관측은 이웃 두 상태의 차이를 측정한다고 하자.
잔차 `r_i=x_(i+1)-x_i-z_i`의 Jacobian 행은 두 위치에만 -1과 1이 있다.
어떤 상태와 무관한 잔차의 미분은 정확히 0이다.
한 anchor와 두 장거리 제약을 추가하면 일부 행의 비제로 위치만 늘어난다.
이 구조는 값의 크기와 별개로 알려져 있으므로 symbolic sparsity를 재사용할 수 있다.

![D6 Jacobian 희소 구조](../research/computer-vision-textbook/mathematics/figures/d6_sparsity.png)

그림 D6-3. 왼쪽은 합성 8×6 Jacobian의 비제로 위치, 오른쪽은 `J^T J`의 비제로 위치다.
축은 상태 열 번호와 잔차 또는 상태 행 번호이며 물리 단위가 없는 인덱스다.
파란 사각형은 값의 크기가 아니라 의존 관계의 존재를 나타낸다.
이 예는 실제 SLAM Hessian이 아니라 인접·장거리 제약의 패턴을 설명하는 작은 배열이다.

J가 희소하다고 소거 과정도 같은 정도로 희소한 것은 아니다.
한 변수를 제거하면 그 변수에 연결된 이웃 사이에 새 항이 생기는 fill-in이 발생한다.
변수 순서가 분해 메모리와 연산량에 영향을 주는 이유다.
대규모 문제에서는 sparse QR, Cholesky, 반복법 중 문제 구조와 안정성 요구에 맞는 해법을 선택한다.
이 장은 그 선택을 이해하는 기초이며 실제 대규모 sparse backend 성능을 측정하지 않았다.

### D6.11 해설 연습문제: 미분이 맞아도 이동은 틀릴 수 있다

문제 D6-1. `f=(xy)(x+y)`의 x=2,y=3에서 gradient를 전방·역방향으로 각각 구하라.

해설. 순방향 값 t=6,u=5를 먼저 계산한다.
x 방향은 `tdot=3,udot=1`이므로 21, y 방향은 `tdot=2,udot=1`이므로 16이다.
역방향에서는 `tbar=5,ubar=6`이고 x에는 15+6, y에는 10+6이 누적된다.
두 방법은 `[21,16]`으로 일치해야 한다.
검사는 `test_forward_reverse_value`가 수행한다.

문제 D6-2. `E=1/2(x²-4)²`의 x=1에서 정확한 Hessian과 GN 근사를 비교하라.

해설. r=-3, r'=2, r''=2다.
정확한 E''는 `(r')²+r r''=4-6=-2`이고 GN 근사는 4다.
양수 감쇠는 선형 시스템을 안정화할 수 있지만 생략한 비선형 곡률을 정확하게 복원하는 것은 아니다.
검사는 `test_hessian_exact`가 수행한다.

문제 D6-3. `J=[[1,1],[1,-1]]`, `r=[-1,-3]`에서 GN 증분을 구하라.

해설. `J^T J=2I`, `-J^T r=[4,-2]`이므로 delta는 `[2,-1]`이다.
`r+J delta=0`으로 검산한다.
J가 실제 잔차의 전역 선형 모델일 때만 이 한 번의 이동으로 실제 잔차도 정확히 0이다.
검사는 `test_gn_step`이 수행한다.

문제 D6-4. 왜 중앙차분 h를 10⁻¹⁶으로 줄이는 것이 10⁻⁵보다 나쁠 수 있는가?

해설. 중앙차분의 절단오차는 h²로 줄지만 반올림 항은 epsilon/h로 커진다.
float64에서 x=1 주변의 x±h가 같은 표현값으로 반올림되면 분자가 0이 될 수도 있다.
이때 미분이 실제로 0인 것이 아니라 두 입력을 구별하지 못한 것이다.
수치 근거는 `artifacts/d6/arrays.npz`의 h·central 배열에 남아 있다.

### D6.12 종료 조건과 다음 장으로 넘어가는 질문

상태 변화가 작음, gradient가 작음, 비용 변화가 작음은 서로 다른 종료 조건이다.

## D7. 확률과 통계: 오차를 숫자 하나가 아니라 분포로 설명하기

### D7.1 문제와 계약: 여러 관측을 합치면 정말 더 정확해지는가

같은 위치를 두 센서가 측정했다면 평균을 내면 될 것처럼 보인다.
하지만 두 센서가 같은 시간 오차나 공통 보정 오차를 공유하면 독립적인 정보 두 개가 아니다.
평균값은 맞아도 불확실성을 절반으로 줄였다는 보고가 틀릴 수 있다.
이 장은 관측의 분포를 정의하고, 상관과 이상치를 포함한 모델에서 추정식을 직접 만든다.
모델은 현실 자체가 아니라 확인 가능한 가정의 묶음이다.

확률 변수 X와 관측된 숫자 x를 구분한다.
대문자는 시행마다 달라지는 대상이고 소문자는 한 번 실현된 값이다.
모수 theta는 분포를 지정하는 미지의 상수로 볼 수도 있고 prior를 부여한 확률 변수로 볼 수도 있다.
관점이 바뀔 때 어떤 것을 조건부로 고정했는지 써야 한다.

| 기호 | 의미 | 단위 |
|---|---|---|
| p(x) | 연속 변수의 확률밀도 | x 단위의 역수 |
| P(A) | 사건 A의 확률 | 무차원, 0부터 1 |
| mu | 평균 | 변수와 같은 단위 |
| Sigma_ij | 공분산 | x_i 단위×x_j 단위 |
| rho_ij | 상관계수 | 무차원 |
| L(theta) | 고정 관측에 대한 likelihood | 밀도 단위 유지 가능 |
| Lambda | 정보행렬 Sigma의 역 | 공분산 단위의 역 |
| w_i | robust 또는 혼합 가중치 | 정의에 따라 무차원 |

목표는 평균뿐 아니라 추정의 불확실성과 모델의 실패 조건까지 출력하는 것이다.
이 장의 합성 데이터는 정확한 생성 분포를 알고 있으므로 잘못된 가정을 의도적으로 제거해 비교할 수 있다.
실제 영상에서 잔차가 Gaussian인지, 독립인지, 같은 분산인지 검증한 실험은 아니다.
그 일반화는 별도 자료와 진단을 요구한다.

### D7.2 밀도와 확률: 점의 높이는 확률이 아니다

연속 변수는 정확히 한 점을 가질 확률이 0일 수 있지만 그 주변 구간 확률은 양수다.
밀도 p(x)는 구간에 대해 적분할 때 확률이 된다.
`P(a<=X<=b)=integral_a^b p(x) dx`이고 전체 적분은 1이다.
밀도의 높이는 1보다 클 수 있다.
예를 들어 폭 0.2m 구간에 균일한 변수의 밀도는 5/m다.
높이 5라는 숫자는 확률 500%를 뜻하지 않는다.

단위를 바꾸면 밀도 값도 바뀐다.
위치 x를 m로 표현하고 y=100x를 cm로 표현하면 같은 사건의 확률은 같아야 한다.

```text
p_X(x) dx = p_Y(y) dy
dy = 100 dx
p_Y(y) = p_X(y/100)/100
```

다차원 가역변환에서는 이 배율이 Jacobian determinant의 절댓값으로 일반화된다.
이는 D6의 미분이 단지 최적화뿐 아니라 확률 질량 보존에도 필요하다는 연결이다.
비가역 투영에서는 이 공식을 무조건 쓸 수 없고 소실된 변수에 대해 적분해야 한다.
같은 평균과 분산을 갖는 분포도 꼬리나 여러 봉우리 구조가 다를 수 있다.
따라서 평균·공분산은 분포의 요약이지 항상 분포 전체는 아니다.

기댓값은 가능한 값들을 확률로 가중한 평균이다.
연속 변수에서 `E[X]=integral x p(x) dx`이고 분산은 `E[(X-mu)²]`다.
전개하면 `Var(X)=E[X²]-mu²`다.
표본 평균은 기댓값의 추정량이지 기댓값 자체와 항상 같지 않다.
Monte Carlo 실험에서 표본 수와 난수 seed를 함께 기록하는 이유다.

### D7.3 결합·조건부·Bayes: 데이터가 상태를 어떻게 바꾸는가

두 사건 또는 확률 변수의 결합을 조건부와 주변으로 분해하면 Bayes 규칙을 얻는다.

```text
p(x,z)=p(z|x)p(x)=p(x|z)p(z)
p(x|z)=p(z|x)p(x)/p(z)
p(z)=integral p(z|x)p(x) dx
```

prior p(x)는 관측 z 이전의 믿음이다.
likelihood p(z|x)는 상태를 고정했을 때 그 관측이 나올 모형이다.
posterior p(x|z)는 관측 후의 믿음이다.
evidence p(z)는 posterior의 적분을 1로 맞추며, 다른 모델을 비교할 때는 생략할 수 없다.
같은 모델 안에서 x에 대한 최대점만 찾을 때에는 x와 무관한 정규화 상수로 생략할 수 있다.

숫자가 있는 이산 예를 먼저 보자.
참 상태 A의 prior 확률이 0.2, 상태 B가 0.8이라고 하자.
양성 관측의 확률이 A에서는 0.9, B에서는 0.1이다.

```text
P(positive)=0.9*0.2+0.1*0.8=0.26
P(A|positive)=0.18/0.26=9/13
```

양성 관측이 A에서 자주 나온다는 사실만으로 posterior가 0.9인 것은 아니다.
prior 빈도와 B에서도 관측될 가능성이 함께 들어간다.
시각 대응에서 descriptor 유사도가 높다는 사실과 두 점이 같은 물리 점일 posterior는 같은 숫자가 아니다.
데이터 연관은 관측 모델뿐 아니라 후보 수와 오검출 모형에도 의존한다.

독립과 조건부 독립도 구분한다.
두 센서 z1,z2가 상태 x를 공유하면 주변적으로 상관될 수 있다.
하지만 x를 고정한 뒤 오차가 독립이라면 `p(z1,z2|x)=p(z1|x)p(z2|x)`를 쓸 수 있다.
공통 보정 오차 b가 남아 있다면 x만 조건으로 두고 이 분해를 쓰는 것이 틀릴 수 있다.
그 경우 b를 상태에 포함하거나 결합 공분산을 모델링해야 한다.

### D7.4 다변량 Gaussian: 타원의 방향과 면적까지 들어가는 모형

n차원 Gaussian의 밀도는 평균 mu와 정부호 공분산 Sigma로 정의한다.
모든 변수 단위를 정한 후 다음 수치식을 적용한다.

```text
p(x) = exp[-1/2 (x-mu)^T Sigma^-1 (x-mu)]
       /[(2*pi)^(n/2) sqrt(det(Sigma))]

negative log p(x)
 = 1/2 (x-mu)^T Sigma^-1 (x-mu)
   +1/2 log det(Sigma)+n/2 log(2*pi)
```

첫 항은 평균에서 얼마나 멀리 떨어졌는지를 분산 방향에 맞추어 측정한다.
둘째 항은 분포가 넓어질 때 밀도의 높이가 낮아지도록 정규화한다.
Sigma가 상태나 학습할 모수에 의존하면 log determinant 항을 버리면 안 된다.
그 항을 버리고 분산을 마음대로 키우면 모든 잔차 비용을 줄이는 잘못된 최적화가 가능해진다.

공분산의 대각은 각 성분의 분산이고 비대각은 함께 변하는 정도다.
`Sigma_ij=E[(X_i-mu_i)(X_j-mu_j)]`다.
상관계수는 `rho_ij=Sigma_ij/(sigma_i sigma_j)`로 표준화한다.
서로 다른 단위를 갖는 공분산 값은 직접 크기 비교가 어렵지만 상관계수는 무차원이다.
다만 상관 0이 일반적으로 독립을 뜻하지는 않는다.
공동 Gaussian일 때에만 상관 0과 독립이 연결된다.

Mahalanobis 거리 제곱을 `d²=(x-mu)^T Sigma^-1(x-mu)`라 한다.
Cholesky 분해 `Sigma=L L^T`를 사용하면 `e_white=L^-1(x-mu)`이고 `d²=||e_white||²`다.
이 whitening은 단위와 상관을 동시에 제거한다.
대각 표준편차로 나누기만 하면 비대각 상관은 남는다.
실제 구현에서는 L의 역행렬을 만들지 않고 삼각 solve를 사용한다.

퇴화 Gaussian에서 Sigma가 특이하면 일반적인 n차원 밀도식의 determinant가 0이다.
그 분포는 더 낮은 차원 부분공간에 놓일 수 있다.
작은 대각값을 임의로 더하는 것은 편리한 수치 보정이지만 새로운 잡음 가정을 추가하는 것이다.
추가한 크기와 이유를 기록하지 않으면 공분산 해석이 불가능해진다.

### D7.5 조건부 Gaussian: 상관이 있어야 다른 변수를 알게 된다

공동 Gaussian `[X,Y]`를 평균 `[mu_x,mu_y]`와 블록 공분산으로 쓰자.

```text
Sigma = [A C]
        [C^T B]

e = X-mu_x-C B^-1(Y-mu_y)
Cov(e,Y) = C-C B^-1 B = 0
Cov(e) = A-C B^-1 C^T
```

e와 Y는 공동 Gaussian이고 상관이 0이므로 독립이다.
따라서 Y=y가 알려져도 e의 분포는 바뀌지 않는다.
X를 다시 풀어 쓰면 조건부 평균과 공분산이 바로 나온다.

```text
E[X|Y=y] = mu_x+C B^-1(y-mu_y)
Cov(X|Y=y) = A-C B^-1 C^T
```

스칼라 X,Y의 평균을 0, `A=4m²`, `B=1m²`, `C=1.2m²`라고 하자.
Y=2m를 관측하면 X의 조건부 평균은 2.4m다.
조건부 분산은 `4-1.2²/1=2.56m²`로 줄어든다.
Y의 값이 양수일 때 X도 양수일 경향이 있다는 상관이 평균을 이동시킨다.
C=0이면 평균도 분산도 바뀌지 않는다.
이 계산은 D8의 Kalman 갱신을 한 번에 이해하는 핵심이다.

이 조건부 계산과 Y를 적분해 없애는 주변화는 다르다.
주변 X의 공분산은 원래 A=4m²다.
조건부에서는 Y가 정확히 알려져 2.56m²지만 주변화에서는 Y의 불확실성이 남는다.
상태를 메모리에서 지운다고 그 상태가 정확히 알려진 것이 아니다.
이 구분은 factor graph에서 변수를 제거할 때 다시 중요해진다.

### D7.6 Gaussian 전파와 선형화의 한계

선형 변환 `Y=A X+b`에서 평균과 공분산은 정확히 전파된다.
이 결과는 평균·공분산의 계산 자체에는 Gaussian 가정이 필요하지 않다.
분포가 Gaussian으로 유지된다는 결론에는 Gaussian 입력이 필요하다.

```text
mu_y=E[A X+b]=A mu_x+b
Y-mu_y=A(X-mu_x)
Sigma_y=E[A(X-mu_x)(X-mu_x)^T A^T]
       =A Sigma_x A^T
```

독립 잡음 v가 더해지면 공분산에 `Sigma_v`를 더한다.
상관이 있으면 `A Cov(X,v)+Cov(v,X) A^T`도 남는다.
잡음이라는 이름만으로 독립을 가정할 수 없다.
같은 이전 상태나 같은 영상에서 추출한 두 관측은 상관을 가질 수 있다.

비선형 h에서는 `h(X)≈h(mu)+J(X-mu)`로 근사한다.
평균을 h(mu), 공분산을 `J Sigma J^T`로 계산하지만 이것은 일반적으로 정확하지 않다.
`h(x)=x²`, `X~N(0,s²)`이면 h(mu)=0인 반면 실제 평균은 s²다.
J=2mu=0이므로 일차 전파는 분산도 0이라 예측한다.
실제 분산은 `E[X⁴]-E[X²]²=3s⁴-s⁴=2s⁴`다.
비선형성은 평균도 이동시키므로 공분산만 크게 조정하는 임시방편으로 모든 문제를 고칠 수 없다.

### D7.7 MLE와 MAP: 제곱 잔차는 가정에서 나온다

Maximum Likelihood Estimation은 최대가능도추정, MLE다.
고정된 관측 z가 가장 그럴듯해지는 모수 x를 고른다.
Maximum A Posteriori는 최대사후확률추정, MAP이며 prior까지 곱한 posterior의 최대점을 고른다.
둘 모두 평균 추정과 항상 같지 않다.
대칭 단봉 Gaussian에서는 평균·최빈값이 일치하지만 비대칭 또는 다봉 분포에서는 달라질 수 있다.

독립 Gaussian 오차 `z_i=h_i(x)+e_i`, `e_i~N(0,sigma_i²)`를 가정하자.

```text
L(x)=product_i [1/(sqrt(2*pi)*sigma_i)]
               exp[-(z_i-h_i(x))^2/(2 sigma_i^2)]

-log L(x)=sum_i (z_i-h_i(x))^2/(2 sigma_i^2)+constant
```

분산이 x와 무관할 때 상수항을 버리면 가중 최소제곱이다.
관측을 두 번 넣으면 likelihood를 두 번 곱해 다른 문제를 푸는 셈이다.
독립이 아닌 관측을 독립이라고 가정하면 정보가 중복 계산된다.
오차의 꼬리가 Gaussian보다 두꺼우면 큰 잔차의 영향이 과도해질 수 있다.
이것이 최소제곱과 확률 모형의 연결이며 손실함수 선택의 출발점이다.

스칼라 prior `x~N(mu,P)`와 관측 `z=x+v`, `v~N(0,R)`에서 MAP를 유도한다.

```text
E(x)=1/2(x-mu)^2/P+1/2(z-x)^2/R
dE/dx=(x-mu)/P+(x-z)/R=0
x(1/P+1/R)=mu/P+z/R

P_post=1/(1/P+1/R)
mu_post=P_post(mu/P+z/R)
```

mu=0m,P=4m²,z=3m,R=1m²이면 정보는 0.25와 1이다.
posterior 분산은 0.8m², 평균은 2.4m다.
단순 산술 평균 1.5m와 달리 더 정확한 관측 쪽으로 이동한다.
prior가 실제 독립 정보가 아니라 같은 관측에서 계산된 값이면 이 곱셈은 중복 사용이 된다.
Bayes 공식 자체가 데이터 출처의 중복을 자동으로 알아내지는 않는다.

### D7.8 Laplace 근사: 최적화 곡률을 불확실성으로 읽는 조건

posterior가 복잡하면 최대점 x_star 주변의 음의 로그를 이차식으로 근사할 수 있다.
그 점에서 gradient가 0이고 Hessian H가 정부호라고 하자.

```text
-log p(x|z)
 ≈ constant+1/2(x-x_star)^T H(x-x_star)

p(x|z) ≈ Gaussian(mean=x_star, covariance=H^-1)
```

이것이 Laplace 근사의 핵심이다.
모든 최적화 Hessian의 역이 자동으로 참 공분산이 되는 것은 아니다.
확률 모델, 단위, whitening, prior, 국소 근사의 타당성이 모두 맞아야 한다.
잔차 제곱합에서 `J^T J`만 쓰면 정확한 Hessian 대신 GN 근사를 사용한 추가 근사다.
관측 불가능한 gauge 방향이 있으면 H가 특이하여 일반 역행렬을 만들 수 없다.

다봉 posterior에서 한 봉우리 주변의 작은 공분산은 다른 봉우리의 존재를 표현하지 못한다.
반복 무늬에서 두 위치가 모두 가능한 경우가 대표적이다.
최적화가 한 위치에 수렴했다고 다른 위치의 확률이 0이 된 것은 아니다.
불확실성을 하나의 타원으로 전달하는 인터페이스의 한계를 명시해야 한다.
이 장의 EM 예와 다음 장의 sigma-point 예는 서로 다른 방식으로 그 한계를 보여준다.

### D7.9 Robust IRLS: 큰 잔차의 영향력을 제한하기

이상치 하나가 평균을 크게 움직이는 이유는 제곱 손실의 미분이 잔차 크기에 비례하기 때문이다.
Huber 손실은 작은 잔차에 이차식, 큰 잔차에 선형식을 사용한다.
위치 추정의 robust 접근은 Huber의 1964 논문에 역사적 근거를 둔다.
아래 계산과 합성 오염 실험은 본 교재가 별도로 구성한 예다. [Huber, 1964](https://doi.org/10.1214/aoms/1177703732)

```text
rho_delta(r) = r^2/2                     if |r|<=delta
             = delta|r|-delta^2/2        otherwise

psi(r)=d rho/dr = r                      if |r|<=delta
                = delta sign(r)         otherwise

w(r)=psi(r)/r = 1                        if |r|<=delta
              = delta/|r|                otherwise
```

r=0에서는 연속 극한에 따라 w=1로 정의한다.
실제 복합 잔차는 먼저 단위와 잡음 스케일을 맞춰 threshold를 해석해야 한다.
이 장의 위치 예에서는 r와 delta 모두 m라서 rho의 단위는 m²다.
whitening된 잔차를 쓰면 r와 delta는 무차원이다.

Iteratively Reweighted Least Squares, 반복 재가중 최소제곱을 IRLS라고 한다.
현재 잔차에서 w_i를 계산하고 고정한 뒤 가중 최소제곱을 풀며 반복한다.
스칼라 위치 x에 대한 잔차를 `x-y_i`로 두면 갱신식은 다음과 같다.

```text
고정 w에서 E=1/2 sum_i w_i(x-y_i)^2
dE/dx=sum_i w_i(x-y_i)=0
x_new=sum_i w_i y_i / sum_i w_i
```

가중치는 이전 추정에서 계산한 값이므로 새 x에서 다시 평가해야 한다.
임의의 손실과 임의 갱신이 항상 단조감소를 보장하는 것은 아니다.
또한 robust 가중치가 작다는 것은 오차가 크다는 의미이지 대응이 틀렸다는 완전한 증명은 아니다.
좋은 초기화와 잔차 스케일을 함께 확인해야 한다.

관측 `[0,0,0,4]m`, delta=1m의 손계산을 보자.
해가 0과 1 사이에 있다고 가정하면 앞의 세 잔차는 x, 마지막 잔차는 x-4라서 영향력이 -1로 포화된다.

```text
stationary equation: 3x-1=0
x=1/3 m
가정 확인: 0<=1/3<=1, |1/3-4|>1

산술 평균은 1m
Huber 해는 1/3m
```

Huber는 이상치의 영향력을 제한하지만 완전히 제거하지 않는다.
한 방향의 이상치가 늘면 제한된 힘도 누적되어 추정이 움직인다.
레버리지가 큰 설명변수의 이상치는 단순 위치 예보다 더 까다롭다.
따라서 robust loss를 모든 잘못된 대응의 대체 검증으로 사용하지 않는다.

![D7 robust 위치 추정](../research/computer-vision-textbook/mathematics/figures/d7_robust.png)

그림 D7-1. 왼쪽은 참 위치 0m에서 표준편차 0.25m인 합성 정상 관측 80개와 4m 이상치 20개다.
가로축은 관측 m, 세로축은 개수이며 평균과 delta=0.5m Huber 해를 수직선으로 표시했다.
오른쪽은 정상 표본을 고정한 채 같은 방향 이상치 수만 늘린 ablation으로, 가로축은 이상치 비율이고 세로축은 추정 m다.
실행값은 평균 0.7838m, Huber 0.1078m이며 실제 센서 성능 수치가 아니다.
오른쪽 끝의 50% 오염에서는 두 집단 사이에서 영향력 합이 0인 평평한 최소 구간이 생길 수 있다.
그 구간 안의 특정 출력은 초기값·종료 규칙에도 의존하므로 끝점의 급변을 유일한 물리 전이로 해석하지 않는다.

### D7.10 상관을 지우는 ablation: 평균은 같아도 자신감이 틀리다

두 센서 오차의 분산이 각각 1m²이고 상관계수가 rho라고 하자.
평균 오차 `e_bar=(e1+e2)/2`의 분산을 성분별로 전개한다.

```text
Var(e_bar)=E[(e1+e2)^2]/4
          =(Var(e1)+2Cov(e1,e2)+Var(e2))/4
          =(1+rho)/2 m^2

rho=0 -> 0.5 m^2
rho=0.9 -> 0.95 m^2
rho=1 -> 1 m^2
```

rho=1이면 두 관측은 같은 오차를 반복하므로 평균을 내도 분산이 줄지 않는다.
독립이라고 잘못 보고한 0.5m²는 실제 0.95m²에 비해 과도하게 작다.
평균 추정 자체는 두 경우 모두 산술 평균으로 동일하다.
따라서 평균 오차만 비교하는 평가로는 이 오류를 놓칠 수 있다.

![D7 상관과 과신](../research/computer-vision-textbook/mathematics/figures/d7_correlation.png)

그림 D7-2. 왼쪽은 상관 0.9인 합성 센서 오차 쌍 중 1,000개를 m 축에 표시했다.
오른쪽은 30,000개 쌍의 평균 오차 밀도이며 가로축 m, 세로축 1/m다.
같은 평균값에 대해 독립 가정의 분산 0.5와 올바른 분산 0.95를 비교했다.
실제 표본 분산은 0.9550m²였고, 이 그림은 데이터는 그대로 두고 공분산의 비대각만 무시한 실패를 보여준다.

공통 오차를 b, 독립 오차를 eta_i라 하여 `e_i=b+eta_i`로 쓸 수도 있다.
n개 평균의 분산은 `Var(b)+Var(eta)/n`이다.
n을 늘려도 공통 오차 항은 사라지지 않는다.
반복 관측 수만 늘려 확신도를 무한히 높이는 시스템은 이 바닥 오차를 놓칠 수 있다.
같은 영상 패치, 같은 지도점, 같은 보정값에서 파생된 측정의 정보 중복을 추적해야 하는 이유다.

### D7.11 혼합 Gaussian과 EM: 모르는 소속을 확률로 나누기

관측이 두 집단에서 섞여 왔다면 하나의 Gaussian은 두 봉우리 사이에 평균을 놓을 수 있다.
혼합 모델은 잠재 소속 c_i를 도입한다.
혼합 가중치 pi_k는 집단 k를 뽑을 확률이고 합이 1이다.

```text
p(y_i)=sum_k pi_k N(y_i;mu_k,sigma_k^2)
log L=sum_i log[sum_k pi_k N(y_i;mu_k,sigma_k^2)]
```

log 밖의 합 때문에 각 집단의 평균을 한 번의 분리된 평균 계산으로 구할 수 없다.
Expectation–Maximization, 기대값–최대화 알고리즘을 EM이라고 한다.
Dempster, Laird, Rubin(1977)은 불완전 데이터 likelihood에 대한 일반적 틀을 제시했다.
이 절은 그 틀을 분산이 알려진 두 1차원 집단의 작은 계산으로 제한한다. [출판사 원문](https://academic.oup.com/jrsssb/article/39/1/1/7027539)

E 단계에서는 현재 모수로 각 관측의 소속 확률을 구한다.
이를 responsibility gamma_ik라고 한다.

```text
gamma_ik = P(c_i=k | y_i)
         = pi_k N(y_i;mu_k,sigma_k^2)
           /sum_l pi_l N(y_i;mu_l,sigma_l^2)

각 i에서 sum_k gamma_ik=1
```

M 단계는 이 소속 확률을 고정하고 기대 완전자료 로그가능도를 최대화한다.
평균에 대한 관련 항만 남기면 가중 제곱합이다.

```text
Q_mu = -1/2 sum_i gamma_ik (y_i-mu_k)^2/sigma_k^2
dQ_mu/dmu_k = sum_i gamma_ik(y_i-mu_k)/sigma_k^2=0

N_k=sum_i gamma_ik
mu_k_new=sum_i gamma_ik y_i/N_k
pi_k_new=N_k/N
```

분산까지 추정하면 `sigma_k²_new=sum_i gamma_ik(y_i-mu_k_new)²/N_k`가 추가된다.
그러나 자유 분산 Gaussian mixture는 한 성분이 한 표본에 붕괴하며 likelihood가 커질 수 있다.
이 실험은 분산을 0.7²m²로 고정하여 그 별도 문제를 제거했다.
따라서 실행 결과를 범용 Gaussian mixture fitting 구현으로 해석하지 않는다.

작은 숫자 예에서 pi1=pi2=1/2, mu1=-1, mu2=1, sigma=1, 관측 y=0이면 두 밀도가 같아 gamma가 각각 1/2다.
y=1이면 첫 성분과 둘째 성분 밀도 비는 exp(-2):1이다.
따라서 둘째 responsibility는 `1/(1+exp(-2))≈0.8808`이다.
hard assignment처럼 무조건 1을 주지 않고 불확실성을 남긴다.

### D7.12 EM이 단조로워도 좋은 분리를 보장하지 않는 이유

E 단계의 분포를 q(c)라 쓰면 log evidence를 하한과 차이로 나눌 수 있다.
이 전개는 로그 안의 합을 다루는 이유를 보여준다.

```text
log p(y|theta)
 = sum_c q(c) log[p(y,c|theta)/q(c)]
   + sum_c q(c) log[q(c)/p(c|y,theta)]

첫 항: lower bound
둘째 항: KL divergence >= 0
```

KL은 Kullback–Leibler divergence, 두 확률 분포의 차이를 재는 발산이다.
거꾸로 분포 순서를 바꾸면 값이 같지 않을 수 있으므로 대칭적인 거리와 구분한다.
E 단계는 현재 posterior를 q로 택해 차이를 0으로 만든다.
M 단계가 그 q를 고정한 하한을 증가시키면 원래 likelihood도 감소하지 않는다.
그러나 이 논리는 전역 최대점에 도달한다는 보장이 아니다.
초기값에 따라 다른 stationary point나 대칭 상태에 머무를 수 있다.
수치 구현에서는 log-sum-exp로 작은 확률의 underflow를 피해야 한다.

![D7 EM의 초기화 실패](../research/computer-vision-textbook/mathematics/figures/d7_em.png)

그림 D7-3. 왼쪽은 -2m 부근 180개와 2m 부근 120개를 섞은 합성 자료의 밀도다.
분리된 초기 평균 `[-2,2]`와 동일한 초기 평균 `[0,0]`을 비교했으며 분산은 두 경우 모두 0.49m²로 고정했다.
오른쪽은 반복 번호와 로그가능도이다.
두 성분을 똑같이 시작하면 responsibility와 갱신도 같아 두 평균이 모두 -0.3856m에 남았고, 분리된 시작은 약 -2.0000m와 2.0212m를 얻었다.

이 실패는 나쁜 난수 하나를 선택한 사례가 아니라 대칭 갱신의 구조적 결과다.
처음 두 평균·분산·가중치가 같으면 모든 관측에 대한 responsibility가 같고 다음 평균도 같아진다.
작은 비대칭 초기화나 여러 시작점은 이 문제를 줄일 수 있지만 전역 보증은 여전히 없다.
두 집단의 label을 바꾸어도 같은 밀도이므로 모수 오차를 비교할 때 label permutation도 고려해야 한다.
이 실험은 장면 의미 분할이나 실제 다중 물체 추적의 정확도를 측정하지 않았다.

## D8. 상태 추정: 평균·불확실성·시간·관측 가능성을 함께 유지하기

### D8.1 무엇을 추정하는가: 현재 위치만 맞추면 충분하지 않다

센서는 현재 위치를 시끄럽게 측정하고 운동 모델은 이전 상태에서 다음 상태를 예측한다.
어느 쪽을 얼마나 믿을지는 고정 가중치가 아니라 예측 오차와 관측 오차의 공분산으로 결정된다.
더 중요한 것은 추정 결과가 얼마나 틀릴 수 있다고 보고하는지도 실제 오차와 맞아야 한다는 점이다.
이 장은 Kalman Filter, 칼만 필터를 KF로 줄여 부르고 조건부 Gaussian의 시간 재귀로 유도한다.
비선형 근사·정보형·smoothing·관측성까지 같은 계약 위에서 연결한다.

이 장의 실제 실행은 1차원 위치와 속도의 2상태 합성 시스템이다.
위치 p의 단위는 m, 속도 v의 단위는 m/s, 시간 간격 dt는 1s다.
입력은 관측 z와 알려진 F,H,Q,R, 초기 평균·공분산이다.
생성기의 진실값은 평가에만 전달하며 필터 갱신에는 들어가지 않는다.
영상, 관성계, 시각 관성 오도메트리 전체 또는 완전한 SLAM을 구현한 실험이 아니다.

| 기호 | 크기 | 뜻과 단위 |
|---|---|---|
| x_t=[p_t,v_t] | 2×1 | 위치 m와 속도 m/s |
| F | 2×2 | 시간 전이, F_12의 단위는 s |
| H | 1×2 | 위치 선택, `[1,0]` |
| Q | 2×2 | 과정 잡음 공분산, 항마다 m²·m²/s·m²/s² |
| R | 1×1 | 관측 잡음 분산 m² |
| m_t^-,P_t^- | 상태 크기 | 관측 전 예측 평균·공분산 |
| m_t^+,P_t^+ | 상태 크기 | 현재 관측 후 평균·공분산 |
| nu_t,S_t | 관측 크기 | innovation m와 그 분산 m² |
| K_t | 2×1 | 상태별 관측 보정량, 두 행 단위가 다름 |

위첨자 -와 +는 음수·양수가 아니라 갱신 전·후라는 시간 계약이다.
초기 시점 이후 먼저 예측하고 그 시점의 관측을 갱신한다.
관측이 이전 시각의 값이면 이 식에 그대로 넣어서는 안 된다.
시간 지연을 상태·버퍼·재전파로 처리하거나 정렬된 관측이라는 가정을 명시해야 한다.

### D8.2 Bayes filtering의 두 적분에서 선형 KF로 내려오기

상태가 1차 Markov라는 것은 현재 상태를 알면 다음 상태 분포가 그보다 과거 상태와 조건부 독립이라는 뜻이다.
관측은 현재 상태가 주어졌을 때 과거 관측과 조건부 독립이라고 가정한다.
이 두 가정에서 filtering 재귀가 나온다.

```text
prediction:
p(x_t|z_1:t-1)
 = integral p(x_t|x_t-1) p(x_t-1|z_1:t-1) dx_t-1

update:
p(x_t|z_1:t)
 proportional to p(z_t|x_t) p(x_t|z_1:t-1)
```

첫 단계는 이전 불확실성을 운동 모델로 전달한다.
둘째 단계는 새 관측과 양립하는 상태의 상대 확률을 키운다.
일반 비선형·비Gaussian 모델에서 이 분포는 유한한 평균·공분산만으로 표현되지 않을 수 있다.
선형 Gaussian 모델이면 두 연산 후에도 Gaussian이어서 평균과 공분산의 닫힌 재귀가 된다.
Kalman(1960)은 상태공간과 오차 공분산 재귀에 기초한 선형 추정의 원문이다. [Kalman, 1960](https://cs-www.cs.yale.edu/homes/yry/readings/general/Kalman1960.pdf)

Gaussian 가정을 빼도 알려진 이차 모멘트 아래 선형 최소평균제곱 추정으로 해석할 수 있다.
그러나 그 경우 같은 평균·공분산이 posterior 전체를 정확히 표현한다고 말할 수 없다.
이 장의 chi-square 일관성 검사는 더 강한 Gaussian·독립·정확한 모델 가정을 사용한다.
추정식의 성립 조건과 진단 통계량의 분포 조건을 분리해야 한다.

### D8.3 예측 단계: 평균뿐 아니라 교차 공분산이 생긴다

선형 상태 모델을 다음처럼 둔다.
제어 입력 u가 있으면 알려진 `B u`를 더할 수 있지만 이 합성 실험에서는 생략한다.

```text
x_t=F x_t-1+w_t
E[w_t]=0, Cov(w_t)=Q
w_t는 이전 상태 오차와 독립

m_t^-=F m_t-1^+
P_t^-=F P_t-1^+ F^T+Q
```

예측 오차는 `F(x-m)+w`다.
그 외적의 기대를 전개하면 `F P F^T`, Q, 그리고 두 교차항이 생긴다.
독립·영평균 가정 때문에 교차항이 0인 것이다.
과정 잡음이 이전 추정과 상관되어 있다면 그 항을 지우면 안 된다.

등속도 모델의 F는 `[[1,dt],[0,1]]`이다.
속도의 불확실성이 다음 위치에 누적되므로 처음에 위치·속도 공분산이 0이어도 다음에는 상관이 생긴다.
이 상관 때문에 위치만 측정해도 속도를 보정할 수 있다.
공분산의 비대각을 단순히 매번 0으로 만드는 것은 이 정보 경로를 끊는다.

손계산은 dt=1s, 초기 평균 `[0,1]`, 초기 P=I, Q=diag(0.25,0.25)를 사용한다.
P=I라는 표기는 수치 행렬이며 두 대각의 물리 단위는 각각 m²와 (m/s)²다.
이 Q는 손계산을 위한 독립 위치·속도 과정 잡음이고, 뒤의 Monte Carlo 가속도 Q와 구분한다.

```text
F=[1 1]      m^+=[0]
  [0 1]          [1]

m^-=[1,1]^T
F P F^T = [1 1][1 0] = [2 1]
          [0 1][1 1]   [1 1]
P^-=[2.25 1.00]
    [1.00 1.25]
```

위치 예측은 1m이고 속도 예측은 1m/s다.
두 상태의 공분산 1m²/s는 위치 오차가 양수일 때 속도 오차도 양수일 경향을 표현한다.
이것은 실제 운동 방향이 양수라는 뜻이 아니라 추정 오차 사이의 통계적 관계다.
공분산과 상태 값을 같은 의미로 읽지 않는다.

### D8.4 갱신 단계의 유도 1: 결합 Gaussian을 조건부로 만들기

관측 모델은 `z=H x+v`, v의 공분산은 R이고 상태 예측 오차와 독립이라고 하자.
innovation은 실제 관측에서 예측 관측을 뺀 `nu=z-Hm^-`다.
상태 예측 오차 e=x-m^-와 innovation을 함께 쓰면 다음 공분산을 얻는다.

```text
nu=H e+v
Cov(e,nu)=E[e(H e+v)^T]=P^- H^T
S=Cov(nu)=H P^- H^T+R

Cov([e,nu]) = [P^-       P^- H^T]
              [H P^-    S      ]
```

D7의 조건부 Gaussian 식에 `A=P^-`, `C=P^-H^T`, `B=S`를 대입한다.
그 결과가 Kalman gain과 갱신이다.

```text
K=P^- H^T S^-1
m^+=m^-+K nu
P^+=P^- - P^- H^T S^-1 H P^-
   =P^- - K S K^T
```

K는 관측을 무조건 믿는 고정 비율이 아니다.
예측이 불확실할수록 관측 쪽으로, 관측이 불확실할수록 예측 쪽으로 움직이는 행렬이다.
상태마다 관측과의 교차 공분산이 다르므로 보정량이 다르다.
보이지 않는 상태도 다른 상태와 상관되어 있으면 간접적으로 업데이트될 수 있다.

위 손계산에 위치 관측 z=2m, R=1m²를 추가한다.
H=[1,0]이므로 innovation은 1m이고 S=2.25+1=3.25m²다.

```text
K=[2.25,1]^T/3.25=[9/13,4/13]^T

m^+=[1,1]+[9/13,4/13]
    =[22/13,17/13]

P^+=P^- - (1/3.25)[2.25][2.25 1]
                       [1   ]
    =[9/13  4/13 ]
      [4/13 49/52]
```

위치 평균은 약 1.6923m, 속도는 약 1.3077m/s다.
속도를 직접 측정하지 않았는데도 위치가 예측보다 멀다는 관측이 속도를 올렸다.
이는 예측에서 만든 위치·속도 교차 공분산을 통한 보정이다.
초기 공분산과 운동 모델이 틀리면 같은 관측을 잘못된 속도 변화로 해석할 수도 있다.

### D8.5 갱신 단계의 유도 2: Joseph 형태와 수치 안정성

평균 갱신식을 참 상태에서 빼면 새 오차를 직접 구할 수 있다.
`e^+=x-m^+=e^- - K(H e^-+v)`다.

```text
e^+=(I-KH)e^- - K v

P^+=(I-KH)P^-(I-KH)^T+K R K^T
```

이것이 Joseph 형태다.
두 항이 모두 PSD의 합이므로 유한정밀도에서 단순 뺄셈형보다 공분산 구조를 보존하기 유리하다.
정확 산술에서 최적 K를 대입하면 앞의 `P^- - K S K^T`와 같다.
큰 수 두 개를 빼서 작은 분산을 만드는 과정은 반올림에 취약할 수 있다.
행렬을 대칭화하는 것만으로 음의 고유값 문제가 항상 해결되는 것은 아니다.

실제 구현에서는 S의 역을 만들지 않고 `S K^T=H P^-`를 푼다.
S가 정부호라면 Cholesky 계열 solve를 사용할 수 있다.
공분산이 매우 나쁜 조건이면 square-root filtering처럼 인자를 직접 유지하는 접근을 검토한다.
이 실험은 Joseph 갱신을 사용한 작은 dense 교육 구현이며 square-root filter까지 구현하지 않았다.
단순 업데이트와 Joseph 형태가 완전히 다른 확률 모델인 것은 아니다.

### D8.6 정보형: 관측 추가는 더하기, 예측은 그렇지 않다

정보행렬을 `Lambda=P^-1`, 정보벡터를 `eta=Lambda m`으로 정의한다.
Gaussian의 음의 로그를 전개하면 상수를 제외하고 `1/2 x^T Lambda x-eta^T x`다.
선형 관측 likelihood를 추가하면 다음 항이 더해진다.

```text
1/2(z-Hx)^T R^-1(z-Hx)
 =1/2 x^T H^T R^-1 H x-x^T H^T R^-1 z+constant

Lambda^+=Lambda^-+H^T R^-1 H
eta^+=eta^-+H^T R^-1 z
m^+=solve(Lambda^+,eta^+)
```

독립 관측을 여러 개 더할 때 정보형은 구조가 단순하다.
하지만 독립이 아닌 관측에 같은 덧셈을 적용하면 D7의 과신 문제가 그대로 생긴다.
또한 과정 예측은 `P^-=F P F^T+Q`의 역을 취해야 하므로 정보행렬을 단순히 `F Lambda F^T`로 전파하지 않는다.
행렬 역과 덧셈은 서로 교환되지 않는다.
정보형이 모든 단계에서 더 싸다는 주장은 문제 구조를 보고 판단해야 한다.

앞의 2상태 손계산에 정보형 갱신을 적용해도 평균 `[22/13,17/13]`을 얻는다.
이 동치는 `test_information_equivalence`가 검사한다.
서로 다른 구현에서 평균만 아니라 공분산도 비교해야 한다.
평균이 같아도 off-diagonal을 잘못 보존한 구현은 이후 단계에서 달라질 수 있다.

### D8.7 EKF: 평균에서 선형화한 모델은 참 분포가 아니다

Extended Kalman Filter, 확장 칼만 필터를 EKF라고 한다.
비선형 모델 `x_t=f(x_t-1)+w`, `z_t=h(x_t)+v`를 현재 평균 주변에서 선형화한다.
F와 H는 고정 행렬 대신 해당 지점의 Jacobian이 된다.

```text
m_t^-=f(m_t-1^+)
F_t=df/dx evaluated at m_t-1^+
P_t^-=F_t P_t-1^+ F_t^T+Q

nu=z_t-h(m_t^-)
H_t=dh/dx evaluated at m_t^-
S=H_t P_t^- H_t^T+R
K=P_t^- H_t^T S^-1
m_t^+=m_t^-+K nu
```

핵심 차이는 예측 평균에 f를 적용하고 innovation에는 h를 적용한다는 것이다.
`F m`이나 `H m`을 비선형 예측 자체 대신 쓰면 상수항을 빠뜨릴 수 있다.
Jacobian은 작은 오차의 전달을 위한 것이고 함수값은 실제 예측을 위한 것이다.
이 둘을 코드 인터페이스에서 분리하면 흔한 오류를 줄일 수 있다.

예측 평균이 잘못된 봉우리에 있거나 불확실성이 넓으면 한 점의 선형화가 분포를 대표하지 못한다.
특히 `h(x)=x²`, 평균 0에서는 H=0이므로 측정이 x의 크기에 정보를 주어도 일차 선형화는 민감도를 보지 못한다.
회전은 manifold에 있으므로 오류 상태의 정의와 tangent 공간 Jacobian을 별도로 정해야 한다.
이 장은 회전 EKF나 전체 VIO를 구현하지 않으며 유클리드 스칼라 반례로 근사 한계를 설명한다.

### D8.8 UKF와 sigma point: 평균 하나 대신 분포의 대표점을 변환하기

Unscented Kalman Filter, UKF는 시그마점을 이용해 비선형 변환의 평균·공분산을 근사한다.
Unscented Transform, UT가 그 모멘트 변환 단계다.
Julier와 Uhlmann(2004)은 이 접근의 동기와 모멘트 전파를 정리한다.
아래 실험은 전체 UKF 추적기가 아니라 UT 한 단계의 수치 확인이다. [Julier·Uhlmann, 2004](https://www.cs.ubc.ca/~murphyk/Papers/Julier_Uhlmann_mar04.pdf)

n차원 평균 m, 공분산 P에 대해 스케일 매개변수 alpha,beta,kappa를 정한다.
lambda라는 이름은 D6의 LM 감쇠와 무관한 시그마점 스케일이다.

```text
lambda=alpha^2(n+kappa)-n
C C^T=(n+lambda)P

X0=m
Xi=m+C_column_i             i=1,...,n
X_i+n=m-C_column_i

W0_mean=lambda/(n+lambda)
W0_cov=W0_mean+(1-alpha^2+beta)
Wi_mean=Wi_cov=1/[2(n+lambda)]
```

각 점을 비선형 함수 h로 보낸 뒤 가중 평균과 가중 공분산을 계산한다.
평균과 공분산의 중앙점 가중치가 다를 수 있다는 것이 중요하다.
가중치가 음수가 되는 설정도 있어 수치 안정성과 PSD를 주의해야 한다.
시그마점은 무작위 표본이 아니며 개수가 적다고 Monte Carlo 표본이라고 부르지 않는다.

1차원 `X~N(0,s²)`에 alpha=1,beta=2,kappa=0을 사용하면 lambda=0이다.
시그마점은 `[0,s,-s]`, 평균 가중치는 `[0,1/2,1/2]`, 공분산 가중치는 `[2,1/2,1/2]`다.
이를 `h(x)=x²`에 통과시킨다.

```text
Y=[0,s^2,s^2]
mean=0*0+(1/2)s^2+(1/2)s^2=s^2

Y-mean=[-s^2,0,0]
variance=2(s^2)^2+(1/2)*0+(1/2)*0=2s^4
```

s=0.8m이면 평균은 0.64m², 분산은 0.8192m⁴다.
이 특정 이차 변환에서는 정확한 Gaussian 모멘트와 일치한다.
그렇다고 모든 비선형 함수·고차원 상관에서 정확하다는 뜻은 아니다.
평균·공분산이 맞아도 출력 분포가 Gaussian이 된다는 뜻도 아니다.
x²의 출력은 음수가 될 수 없고 오른쪽 꼬리가 긴 분포다.

![D8 시그마점과 제곱 변환](../research/computer-vision-textbook/mathematics/figures/d8_unscented.png)

그림 D8-1. 합성 `X~N(0,0.64m²)`의 100,000개 표본에 x²를 적용한 밀도를 그렸다.
가로축은 m², 세로축은 1/m²이며 0–4m² 구간을 보여준다.
EKF 일차 평균 0과 UT 평균 0.64m²를 수직선으로 비교했다.
표본 평균 0.6411m²·분산 0.8282m⁴는 유한 표본 결과이고, 이론값 0.64·0.8192와 구분한다.

이 사례의 실패 조건은 “Jacobian이 0이라 정보가 없다”는 성급한 결론이다.
일차 민감도가 0이어도 이차 변화에는 정보가 있을 수 있다.
다만 x²만 관측하면 양수 x와 음수 x를 구분하지 못하므로 상태 posterior는 두 봉우리를 가질 수 있다.
UT가 변환 모멘트를 잘 근사해도 부호 모호성까지 제거하지는 않는다.
입자나 mixture 같은 다봉 표현이 필요한 문제와 모멘트 근사 문제가 서로 다름을 기억한다.

### D8.9 filtering과 smoothing: 미래 관측이 과거를 고칠 수 있는가

filtering은 시각 t까지의 관측으로 x_t를 추정한다.
smoothing은 더 나중 T까지의 관측으로 과거 x_t를 다시 추정한다.
실시간 현재 출력과 오프라인 궤적 최적화는 정보 조건이 다르므로 같은 정확도 숫자를 직접 비교하면 안 된다.
fixed-lag smoothing은 최근 일정 길이의 과거만 유지하여 지연과 계산량을 제한한다.

선형 Gaussian 시스템의 후방 보정은 조건부 Gaussian으로 유도할 수 있다.
필터가 알고 있는 x_t와 다음 예측 x_(t+1)의 교차 공분산은 `P_t^+ F^T`다.
다음 상태가 달라졌을 때 현재 상태를 얼마나 고칠지 나타내는 smoother gain C_t는 다음과 같다.

```text
C_t=P_t^+ F^T (P_t+1^-)^-1

m_t^smooth=m_t^+ + C_t(m_t+1^smooth-m_t+1^-)
P_t^smooth=P_t^+ + C_t(P_t+1^smooth-P_t+1^-)C_t^T
```

마지막 시점 T에서는 미래가 없으므로 smoother와 filter가 같다.
T-1부터 역순으로 보정하면 다음 상태에 들어온 미래 정보를 현재로 전달한다.
이 재귀는 Rauch–Tung–Striebel의 이름을 따 RTS smoother라고 부른다.
여기서는 선형 조건부식에서 직접 유도하고 작은 교육 구현으로 실행했다.
비선형 상태에서 같은 형태를 쓰려면 추가 선형화 계약이 필요하다.

![D8 filtering과 smoothing](../research/computer-vision-textbook/mathematics/figures/d8_smoothing.png)

그림 D8-2. 같은 합성 시퀀스 한 개에서 filter와 선형 RTS smoother의 위치 오차 및 보고 표준편차를 비교했다.
가로축은 1s 간격 step, 세로축은 m다.
오차 곡선은 부호가 있고 표준편차 곡선은 항상 음수가 아니므로 서로 다른 종류의 값을 구분해 읽는다.
미래 관측을 쓰는 smoother의 공분산 감소를 확인하는 그림이지 모든 시점의 실제 오차가 반드시 더 작다는 주장은 아니다.

평균제곱오차의 기대값을 줄이는 조건부 추정도 개별 표본에서는 오차가 커질 수 있다.
따라서 한 궤적에서 일부 구간이 나빠졌다고 곧바로 smoothing 이론이 틀렸다고 판단하지 않는다.
반대로 한 궤적의 예쁜 곡선만으로 모델의 일관성을 증명하지도 않는다.
뒤의 Monte Carlo 일관성 검사는 독립적인 여러 시행을 같은 시각에서 비교한다.

### D8.10 factor graph: 확률의 곱이 희소 제곱합이 되는 과정

상태 x0,...,xT와 관측 z1,...,zT의 posterior를 시간 모델로 분해한다.

```text
p(x0:T|z1:T)
 proportional to p(x0)
   * product_t p(x_t|x_t-1)
   * product_t p(z_t|x_t)
```

각 항은 연결된 변수에만 의존하는 factor다.
변수 노드와 factor 노드가 번갈아 연결되는 이분 그래프를 factor graph라 한다.
Gaussian 잡음의 음의 로그를 취하면 prior, motion, observation 잔차의 제곱합이 된다.
상대 상태 잔차는 이웃 두 상태에만 의존하므로 D6의 희소 Jacobian 구조가 나온다.
그래프는 장식이 아니라 조건부 독립과 선형 시스템의 구조를 표현한다.

선형 Gaussian에서 전체 batch 문제를 푼 뒤 최신 상태의 주변을 구하는 것과 올바르게 실행한 KF는 같은 정보를 사용한다.
과거 변수들을 어떤 순서로 제거하고 무엇을 유지하는지가 계산 방법을 바꾼다.
비선형에서는 선형화 시점과 재선형화 정책 때문에 결과가 달라질 수 있다.
그래프 표현과 sparse elimination의 관계는 Dellaert와 Kaess(2017)의 저자 자료에서 확인할 수 있다. [Dellaert·Kaess, 2017](https://www.cs.cmu.edu/~kaess/pub/Dellaert17fnt.html)

그래프에 연결선을 추가했다고 모두 유효한 정보가 되는 것은 아니다.
잘못된 loop correspondence는 잘못된 factor를 추가한다.
같은 관측을 독립 factor 두 개로 중복하면 과신한다.
연결 구조뿐 아니라 각 factor의 측정 출처·시간·단위·독립 가정을 추적해야 한다.
최적화 backend는 잘못된 데이터 계약을 자동으로 교정하지 않는다.

### D8.11 주변화의 Schur complement를 완전제곱으로 유도하기

없앨 변수 a와 남길 변수 b를 정보형 이차식으로 나누자.
정보행렬은 `[[A,B],[B^T,C]]`, 정보벡터는 `[eta_a,eta_b]`다.
A는 이 절에서 가역 정부호라고 가정한다.

```text
E(a,b)=1/2 a^T A a+a^T B b+1/2 b^T C b
       -eta_a^T a-eta_b^T b

q=eta_a-B b
1/2 a^T A a-q^T a
 =1/2(a-A^-1 q)^T A(a-A^-1 q)
  -1/2 q^T A^-1 q
```

a를 적분하면 첫 완전제곱의 적분은 b와 무관한 상수다.
남는 두 번째 항을 b에 대해 전개한다.

```text
q^T A^-1 q
 =eta_a^T A^-1 eta_a
  -2 b^T B^T A^-1 eta_a
  +b^T B^T A^-1 B b

Lambda_marg=C-B^T A^-1 B
eta_marg=eta_b-B^T A^-1 eta_a
```

이것이 Schur complement다.
Gaussian에서는 a를 최적값으로 대입하여 profile 비용을 만들 때도 b의 같은 이차항을 얻는다.
하지만 일반 비Gaussian에서 적분과 최대화가 같다고 확대하면 안 된다.
또한 A가 b에 의존하면 적분 정규화에서 나오는 determinant가 상수가 아닐 수 있다.

작은 정보행렬 `[[2,-1],[-1,2]]`에서 첫 변수를 주변화하면 남은 정보는 `2-(-1)²/2=1.5`다.
따라서 남은 분산은 2/3이다.
행과 열을 삭제해 2만 남기면 분산 1/2가 되어 과신한다.
행·열 삭제는 첫 변수를 정확히 안다고 조건화한 것과 연결되며 주변화가 아니다.
수치 검사는 `test_schur_marginal`이 수행한다.

### D8.12 소거가 만드는 fill-in과 재선형화 경계

상태 a가 여러 b 변수와 연결되어 있으면 `B^T A^-1 B`가 그 b들 사이에 새 결합을 만든다.
이것이 소거 fill-in이다.
원래 그래프에 직접 관측 edge가 없던 두 상태도 제거된 변수를 통해 상관되어 남는다.
이 항을 무시하면 단순 메모리 절약이 아니라 다른 근사 posterior를 만드는 것이다.
근사를 한다면 정보 손실과 일관성 영향을 따로 평가해야 한다.

비선형 sliding window에서는 제거한 변수를 다시 원래 잔차로 재선형화할 수 없다.
남은 prior는 제거 시점의 선형화와 좌표 원점에 묶인다.
현재 상태 좌표를 바꾸면서 prior의 선형 항·상수항·Jacobian 기준을 그대로 두면 잘못된 정보를 더할 수 있다.
선형화점 보존, 오류 상태 정의, nullspace 보존은 실무상 별도 계약이다.
이 장은 이를 구현했다고 주장하지 않고 선형 Schur 예가 보장하는 범위를 명확히 제한한다.

### D8.13 관측 가능성과 gauge: 숫자 해가 있어도 물리 원점은 모를 수 있다

선형 무잡음 시스템에서 초기 상태 x0가 출력에 어떻게 나타나는지 쌓아보자.
시간 불변 F,H를 가정하면 `z0=H x0`, `z1=H F x0`, `z2=H F² x0`다.

```text
stacked_z = O x0
O=[H; H F; H F^2; ...]

rank(O)=state dimension -> 선택한 시간 구간에서 관측 가능
O v=0인 v!=0 존재 -> 그 초기 상태 변화는 출력에 보이지 않음
```

등속도 상태에서 H=[1,0], F=[[1,dt],[0,1]]이면 두 시각의 O는 `[[1,0],[1,dt]]`다.
dt가 0이 아니면 determinant가 dt라서 위치·속도를 함께 구분할 수 있다.
dt가 매우 작으면 정확한 rank는 2여도 속도를 추정하는 수치 조건과 잡음 증폭은 나쁠 수 있다.
관측 가능 여부와 충분히 정확하게 관측되는지는 구분해야 한다.

상대 위치만 있는 세 상태의 잔차를 보자.
`r1=x1-x0-z01`, `r2=x2-x1-z12`다.

```text
J=[-1  1  0]
  [ 0 -1  1]

J [1,1,1]^T = 0
```

모든 위치에 같은 상수 c를 더해도 잔차가 바뀌지 않는다.
이 공통 이동은 gauge 자유도다.
한 상태를 0으로 고정하면 수치 해를 선택할 수 있지만 절대 위치 센서를 새로 얻은 것은 아니다.
gauge 고정은 좌표 규약이고 실제 외부 prior는 추가 물리 정보다.
공분산을 해석할 때 이 두 경우를 구분한다.

세 상태의 정보행렬을 실제로 곱하면 gauge가 어느 고유방향인지도 확인할 수 있다.

```text
L=J^T J=[ 1 -1  0]
        [-1  2 -1]
        [ 0 -1  1]

L[1,1,1]^T=[0,0,0]^T
L[1,0,-1]^T=[1,0,-1]^T
L[1,-2,1]^T=[3,-6,3]^T=3[1,-2,1]^T

세 벡터는 서로 직교한다.
고유값은 0,1,3이고 첫 고유방향만 관측되지 않는다.
```

상대 관측이 z01=1m,z12=2m이면 일반해는 `[c,c+1,c+3]m`다.
anchor x0=0을 쓰면 `[0,1,3]m`, 최소 노름 규약을 쓰면 c=-4/3으로 `[-4/3,-1/3,5/3]m`다.
두 해의 절대 숫자는 다르지만 상대 관측 1m와 2m는 같다.
이 3×3 예의 고유분해·의사역행렬 결과는 `test_three_state_gauge_solution`이 검사한다.

정규화나 감쇠로 Hessian을 가역으로 만들면 소프트웨어는 숫자를 반환한다.
그 숫자에는 인위적인 prior가 포함될 수 있다.
관측 불가능한 방향을 실제로 잘 아는 것처럼 보고하면 filter consistency가 깨진다.
비선형 선형화 과정에서도 본래 불변이어야 하는 방향에 가짜 정보가 생길 수 있다.
이 장의 실험은 gauge가 없는 위치 관측 시스템이므로 이러한 전체 SLAM 비일관성을 직접 측정한 것은 아니다.

### D8.14 innovation: 잔차와 추정 오차는 서로 다르다

innovation nu는 관측에서 예측 관측을 뺀 값이다.
이를 계산하는 데 참 상태는 필요 없다.
상태 오차 e는 참 상태에서 추정 평균을 뺀 값으로, 실제 시스템에서는 일반적으로 정확히 알 수 없다.
관측 잔차가 작다는 것만으로 상태 오차가 작거나 공분산이 정확하다고 결론내릴 수 없다.
잘못된 모델이 관측에 과도하게 맞춰지면 작은 잔차와 큰 상태 오차가 공존할 수 있다.

정확한 선형 Gaussian 모델에서 예측 innovation의 공분산은 S다.
whitening한 innovation의 제곱합을 Normalized Innovation Squared, NIS라 한다.

```text
NIS_t=nu_t^T S_t^-1 nu_t
관측 차원 m이면 이상적 분포는 chi-square(m)
E[NIS_t]=m
```

참 상태가 있는 합성 또는 신뢰할 만한 GT 평가에서는 상태 오차도 정규화할 수 있다.
Normalized Estimation Error Squared, NEES는 다음과 같다.

```text
NEES_t=e_t^T P_t^-1 e_t
상태 차원 n이면 이상적 분포는 chi-square(n)
E[NEES_t]=n
```

NIS는 관측 공간, NEES는 상태 공간의 진단이다.
둘 다 무차원이며 값이 너무 크면 오차에 비해 불확실성을 작게 보고했을 가능성이 있다.
너무 작으면 과도하게 보수적이거나 데이터 처리·차원·상관 가정이 잘못되었을 수 있다.
이 통계량 하나만으로 어떤 원인이 틀렸는지 식별할 수는 없다.

### D8.15 Monte Carlo 일관성: 시간 샘플을 독립 시행으로 착각하지 않기

한 시각 t에서 독립 실험 M개를 수행하면 NIS 합은 가정 아래 chi-square(Mm)이다.
평균 NIS의 95% 구간은 해당 분위수를 M으로 나눈 것이다.
NEES도 자유도 Mn으로 같은 계산을 한다.

```text
lower_NIS=chi2_quantile(0.025,M*m)/M
upper_NIS=chi2_quantile(0.975,M*m)/M

lower_NEES=chi2_quantile(0.025,M*n)/M
upper_NEES=chi2_quantile(0.975,M*n)/M
```

이 실험은 M=600, 관측 차원 1, 상태 차원 2다.
NIS 시각별 ensemble 평균 구간은 약 [0.8900,1.1163]이다.
NEES 구간은 약 [1.8431,2.1632]다.
여러 시각을 동시에 보는 family-wise 보정 구간은 아니므로 일부 점의 이탈만으로 즉시 실패를 선언하지 않는다.
시간에 따른 NEES 값은 상관될 수 있으므로 600×60개를 모두 독립 표본으로 보고 같은 공식을 적용하지 않는다.

초기 진실 상태는 필터가 가진 prior `N([0,1],diag(1,0.25))`에서 독립적으로 뽑는다.
초기 진실 상태를 prior 평균에 고정하면 초기 공분산과 실제 오차 분포가 불일치하는 다른 실험이 된다.
과정은 매 step 독립 가속도 a를 표준편차 0.15m/s²로 뽑아 더한다.
관측 위치 잡음 표준편차는 0.7m다.

```text
G=[dt^2/2,dt]^T
x_next=F x+G a
Q=sigma_a^2 G G^T

dt=1s, sigma_a=0.15m/s^2:
Q=[0.005625 0.01125]
  [0.01125  0.02250]
R=0.49m^2
```

이 Q는 각 구간에서 일정한 무작위 가속도를 하나 뽑는 이산 모형이다.
연속 white acceleration의 spectral density를 적분한 `[[dt³/3,dt²/2],[dt²/2,dt]]` 모형과 다르다.
두 행렬을 시간 간격만 맞춰 혼용하면 단위와 잡음 해석이 달라진다.
Q가 rank 1인 것은 한 구간의 같은 가속도 잡음이 위치와 속도를 함께 바꾸기 때문이다.
전체 예측 P는 초기 불확실성과 시간 누적 때문에 정부호일 수 있다.

R만 키워 숫자를 1에 맞추는 것이 원인 해결이라는 보장은 없다.
GT가 있는 실험에서는 NEES와 실제 오차도 확인하고, GT가 없는 환경에서는 모델 가정과 외부 검증을 분리한다.
본 파트는 자동 Q/R 학습이나 실제 센서의 통계 동정까지 수행하지 않았다.

### D8.17 데이터 연관 게이트: 가까운 점과 그럴듯한 점은 다르다

관측 후보가 여러 개이면 각 후보의 innovation을 계산할 수 있다.
유클리드 거리 게이트는 모든 방향의 불확실성이 같다고 가정한다.
Mahalanobis 게이트는 예측 공분산과 관측 잡음을 합친 S로 방향별 불확실성을 반영한다.

```text
d^2=nu^T S^-1 nu
accept candidate if d^2 <= chi2_quantile(p,m)
```

관측 차원이 2이고 p=0.95이면 문턱은 약 5.9915다.
정확한 대응과 Gaussian 모델 아래 약 95%가 통과하도록 정한 게이트다.
게이트 안에 들어왔다고 그 후보가 참 대응일 확률이 95%라는 뜻은 아니다.
배경 오검출의 밀도와 후보 수, 다른 후보와의 경쟁이 posterior에 영향을 준다.
선택 후 잔차는 게이팅으로 잘렸으므로 원래 chi-square 분포와 달라진다.

S를 `[[4,1.2],[1.2,1]]m²`로 두면 determinant는 2.56m⁴다.
역행렬과 후보 거리 계산을 직접 쓰면 다음과 같다.

```text
S^-1=(1/2.56)[1   -1.2]
              [-1.2 4  ]

nu=[2,0]m -> d^2=4/2.56=1.5625
nu=[0,2]m -> d^2=16/2.56=6.25
```

두 후보의 유클리드 거리는 모두 2m지만 첫 후보는 통과하고 둘째는 탈락한다.
첫 방향의 불확실성이 더 크고 상관 방향까지 반영되기 때문이다.
추가 후보 `[4,1]`은 d²=4.0625, `[1,0.5]`는 0.3125다.
가장 작은 d² 후보가 항상 참인 것은 아니며, 게이트는 계산량을 줄이는 필요조건 검사에 가깝다.

![D8 데이터 연관 게이트](../research/computer-vision-textbook/mathematics/figures/d8_gating.png)

그림 D8-5. 두 축은 합성 innovation의 성분 m이고 타원은 2차원 95% chi-square 게이트다.
점 옆 숫자는 후보 번호와 계산한 Mahalanobis 거리 제곱이다.
초록은 게이트 통과, 붉은색은 탈락이며 같은 2m 거리의 두 축 후보가 다르게 처리되는지 읽는다.
이 그림은 실제 특징점 대응 정확도를 측정한 것이 아니라 공분산 기반 plausibility 검사를 설명한다.

### D8.20 네 장을 다시 연결하는 읽기 경로

D5의 영공간은 D8에서 gauge와 관측 불가능성으로 나타난다.

같은 Schur complement는 선형 방정식 소거와 확률 주변화에 동시에 등장한다.

따라서 좋은 상태 추정기의 조건은 잔차를 작게 만드는 것 하나가 아니다.
좌표와 단위가 명시되어야 하고, 관측이 실제로 제약하는 방향만 정보로 세어야 한다.
미분·선형화·분해가 수치적으로 검증되어야 하며, 확률 모델의 상관과 꼬리를 숨기지 않아야 한다.
마지막으로 평균 오차와 보고 공분산이 함께 평가되어야 한다.
이 네 장의 실험은 그 계약을 작은 재현 가능한 문제에서 확인하는 출발점이다.

### D8.21 원문 출처와 이 교재가 새로 계산한 범위
