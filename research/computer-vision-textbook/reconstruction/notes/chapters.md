## D21. 3차원 지도의 수치 계약: 점에서 표면·거리·등록으로

<a id="d21-1"></a>
### 1. 문제부터 정한다: 같은 장면도 질문에 따라 다른 지도다

카메라가 책상 주변을 한 바퀴 돌았다고 하자.
사람은 결과를 보고 “책상이 잘 복원되었다”고 말할 수 있지만, 시스템이 대답해야 하는 질문은 적어도 네 가지다.
현재 영상은 어디에서 찍혔는가, 책상 모서리 사이 거리는 얼마인가, 로봇이 지나갈 빈 공간은 어디인가, 다른 시점에서 책상이 어떻게 보이는가이다.
이 네 질문을 하나의 “3D 품질” 점수로 합치면 실패의 원인이 사라진다.
텍스처가 그럴듯한 평면도 잘못된 치수를 가질 수 있고, 정확한 표면 점군도 관측하지 않은 공간의 안전성을 알려주지 않는다.

이 장의 출력 계약은 하나의 완성된 SLAM 시스템이 아니다.
관측된 깊이를 점으로 바꾸고, 점들의 기하적 불확실성을 설명하고, 정합 가능한 방향과 불가능한 방향을 구별하고, 여러 관측을 지도에 결합하는 작은 계산들이다.
SLAM은 Simultaneous Localization and Mapping, 즉 위치추정과 지도작성을 함께 수행하는 문제를 뜻한다.
점군을 만들었다는 사실만으로 위치추정과 지도 간 상호 의존성을 푼 것은 아니다.

| 표현 | 저장하는 것 | 직접 답하는 질문 | 추가 가정 없이는 답하지 못하는 것 |
|---|---|---|---|
| 깊이 영상 | 각 광선의 깊이와 유효성 | 이 시점에서 처음 보인 표면까지 얼마나 먼가 | 보이지 않는 뒷면 |
| 점군 | 좌표와 선택적 색·법선 | 관측 표면의 표본은 어디인가 | 점 사이 공간이 막혔는가 |
| 메시 | 정점·삼각형 연결 | 표면은 어떻게 이어지는가 | 연결이 실제 관측으로 지지되는가 |
| 점유 격자 | 셀의 점유 확률·관측 여부 | 셀이 차 있다고 믿는가 | 정확한 표면 위치와 외관 |
| TSDF | 표면 부근 부호 거리의 절단값·가중치 | 표면의 영점은 어디인가 | 먼 자유공간의 최근접 거리 |
| ESDF | 최근접 경계까지의 부호 거리 | 장애물까지 얼마나 떨어졌는가 | 외관과 관측 신뢰성 전체 |

TSDF는 Truncated Signed Distance Function, ESDF는 Euclidean Signed Distance Field의 약자다.
앞의 truncated는 먼 거리값을 잘라 저장한다는 뜻이고, 뒤의 Euclidean은 광선 방향이 아닌 공간의 최단 거리라는 뜻이다.
표현을 선택할 때 이름의 신구보다 질의의 의미를 먼저 보아야 한다.
가중 거리 누적의 역사적 출발점은 Curless와 Levoy의 1996년 연구이고, TSDF에서 거리 질의용 ESDF를 만드는 후속 예가 Voxblox다.
여기서는 이 논문들의 전체 구현 대신 단위와 가정을 드러내는 독립적인 수치 모델을 사용한다. [Curless·Levoy, 1996](https://graphics.stanford.edu/papers/volrange/), [Oleynikova 외, 2017](https://helenol.github.io/publications/iros_2017_voxblox.pdf)

### 2. 깊이의 의미를 고정한 뒤 점군으로 바꾼다

카메라 좌표를 x는 오른쪽, y는 아래쪽, z는 전방으로 정한다.
영상 좌표 u,v의 단위는 픽셀이고, 카메라 초점거리 f_x,f_y 역시 픽셀 단위다.
주점 c_x,c_y는 광축이 영상 평면을 만나는 위치다.
깊이 D(u,v)는 카메라의 z좌표이며 단위는 미터라고 약속한다.
이 약속이 없으면 광선 길이와 z깊이가 혼동된다.

```text
u = f_x X/Z + c_x
v = f_y Y/Z + c_y

u - c_x = f_x X/Z
(u - c_x) Z/f_x = X

따라서 D = Z 일 때
p_c = [ (u-c_x)D/f_x,
        (v-c_y)D/f_y,
        D ]^T
```

예를 들어 f_x=f_y=500 px, 주점=(320,240) px이고,
(u,v)=(420,290) px에서 깊이가 2 m라면 X=100·2/500=0.4 m, Y=50·2/500=0.2 m, Z=2 m다.
이 점까지의 실제 광선 길이는 sqrt(0.4²+0.2²+2²)=sqrt(4.2) m다.
그러므로 z깊이 2 m를 거리 2 m와 같은 것으로 취급하면 중심에서 멀수록 오류가 커진다.
센서가 광선 거리 r을 제공한다면 정규화된 광선 q=[(u-c_x)/f_x,(v-c_y)/f_y,1]을 만든 뒤 p=r q/||q||를 사용한다.

깊이의 무효값도 계약의 일부다.
0, 음수, NaN, 센서 최대 범위, 포화는 같은 물리적 사건이 아니다.
이들을 모두 0 m 점으로 바꾸면 카메라 원점에 거대한 가짜 표면이 생긴다.
필터링 후에는 유효 마스크를 따로 저장하고 점군의 누락을 관측 실패로 해석한다.
누락을 빈 공간으로 바꾸지 않는다.

점군 p_w를 세계 좌표로 옮기는 행렬 T_wc는 카메라에서 세계로 가는 변환이라고 이름 자체에 방향을 넣는다.
회전 R_wc는 3×3 무차원 행렬이고 이동 t_wc는 미터 벡터다.

```text
p_w = R_wc p_c + t_wc
p_c = R_wc^T (p_w - t_wc)
T_cw = inverse(T_wc)
```

행벡터로 배열을 저장하는 NumPy 코드에서는 `points @ R.T + t`가 같은 연산이다.
코드에 전치가 있다는 사실만 보고 변환 방향이 반대라고 결론 내리면 안 된다.
벡터 저장 방식과 좌표계 의미를 별도로 확인해야 한다.

### 3. 점 하나의 불확실성: 깊이 잡음은 등방 구가 아니다

깊이 관측 오차를 표준편차 sigma_D인 작은 영평균 잡음으로 모델링하자.
픽셀 위치를 고정하면 p=Dq이므로 미분 dp/dD=q다.
깊이 오차만 전파한 공분산은 Sigma_p=sigma_D² q q^T다.
q q^T는 3×3 외적 행렬이고 rank가 1이다.
이는 깊이 오차가 모든 방향으로 같은 크기의 구를 만들지 않고 광선 방향으로 늘어난다는 뜻이다.

픽셀 위치도 불확실하면 상태를 s=[u,v,D]로 확장한다.
서로 독립이라는 교육용 가정 아래 Sigma_s=diag(sigma_u²,sigma_v²,sigma_D²)로 둔다.

```text
J = dp/ds
  = [ D/f_x      0      (u-c_x)/f_x
        0      D/f_y    (v-c_y)/f_y
        0        0           1       ]

Sigma_p ≈ J Sigma_s J^T
```

J의 첫 두 열은 m/px, 마지막 열은 무차원이다.
Sigma_p의 모든 원소는 m²이므로 단위가 일치한다.
픽셀 오차 1 px가 깊이 2 m, 초점거리 500 px에서 만드는 횡방향 표준편차는 0.004 m다.
같은 픽셀 오차가 20 m에서는 0.04 m가 된다.
원거리 점을 근거리 점과 같은 위치 정밀도로 다루면 정합 가중치가 잘못된다.

스테레오에서는 z=fB/d이고 시차 d의 단위는 픽셀이다.
B는 두 카메라 중심 사이의 기준선 길이이며 미터다.
분모를 미분하면 dz/dd=-fB/d²이므로 sigma_z≈fB sigma_d/d²다.
f=500 px, B=0.5 m, d=10 px, sigma_d=0.2 px이면 z=25 m이고 sigma_z=0.5 m다.
시차가 두 배가 되면 깊이는 절반이지만 표준편차는 1/4이 된다.
이 계산은 작은 시차 오차에 대한 1차 근사이며 오정합처럼 여러 픽셀을 건너뛰는 이상치에는 적용하지 않는다.

자세 오차를 더하면 한 프레임의 여러 점이 서로 상관된다.
카메라가 x방향으로 2 cm 잘못 놓이면 그 프레임의 모든 점이 함께 2 cm 이동한다.
백만 점의 평균을 낸다고 이 공통 오차가 백만 배 줄지 않는다.
지도 불확실성을 설명할 때 픽셀 잡음과 공유 자세 오차를 분리해야 하는 이유다.

### 4. 점군·메시·복셀·옥트리의 메모리와 위상

점군은 점의 순서와 이웃 연결을 기본적으로 보장하지 않는다.
조밀한 깊이 영상은 원래 픽셀 이웃이 있지만 여러 시점 점을 합치면 그 배열 구조가 사라진다.
가까운 두 점을 연결하는 것과 같은 표면의 두 점을 연결하는 것도 다르다.
책상 앞면과 뒤면은 공간적으로 가까워도 사이에 빈 틈이 있을 수 있다.

메시는 정점 집합과 삼각형 인덱스를 저장한다.
삼각형 a,b,c의 법선 후보는 (b-a)×(c-a)이고, 면적은 그 길이의 절반이다.
정점 순서를 뒤집으면 법선의 부호가 바뀐다.
렌더러의 뒷면 제거와 충돌 질의의 안팎 판정이 이 순서에 의존한다.
점 세 개가 거의 일직선이면 외적이 거의 0이어서 법선을 정규화할 수 없다.
이 경우는 숫자를 억지로 나누는 문제가 아니라 삼각형 자체가 퇴화한 경우다.

복셀은 voxel, 즉 volume element로서 공간의 작은 상자다.
한 변 L인 공간을 한 변 h인 셀로 균일하게 나누면 축당 L/h개이고 총 셀 수는 (L/h)³이다.
10 m 정육면체에서 h=0.05 m라면 200³=8,000,000개 셀이다.
셀마다 float32 거리와 float32 가중치를 저장하면 순수 배열만 64,000,000 byte다.
해상도를 0.025 m로 두 배 높이면 셀 수는 여덟 배가 된다.
색·의미·타임스탬프·자료구조 오버헤드는 이 계산에 포함되지 않는다.

옥트리 octree는 각 상자를 여덟 자식으로 나누는 계층이다.
넓은 빈 영역을 하나의 큰 노드로 유지하고 경계 근처만 세분화할 수 있다.
그러나 항상 메모리를 줄이는 마법은 아니다.
관측이 불규칙하게 흩어져 모든 자식이 필요한 경우 포인터와 노드 메타데이터가 추가된다.
해시 복셀 블록은 공간적으로 가까운 셀 묶음을 저장하고 활성 블록만 할당하는 다른 선택이다.
자료구조와 저장 값의 의미도 독립이다. 옥트리 안에 점유확률을 저장할 수 있고, 블록 해시에 거리장을 저장할 수 있다.

이 구분은 계산 복잡도보다 먼저 해야 한다.
“옥트리를 썼으니 ESDF가 있다”거나 “메시가 있으니 내부가 알려졌다”는 결론은 성립하지 않는다.
닫히지 않은 메시에는 전역적인 안팎이 정의되지 않을 수 있다.
부분 관측 점유 지도에는 unknown, free, occupied라는 세 의미가 필요하다.

### 5. 점유 확률: 광선은 끝점뿐 아니라 통과 구간의 관측이다

점유 셀의 사건을 O라 하고 확률 P(O)=p라 하자.
오즈 odds는 p/(1-p), 로그 오즈 l은 log(p/(1-p))다.
오즈는 차 있음을 지지하는 정도를 비어 있음을 지지하는 정도와 비교한 값이다.
확률이 0.5이면 로그 오즈는 0이고, 양수는 점유 쪽, 음수는 비점유 쪽이다.

관측 z가 들어왔을 때 조건부 독립 가정으로 오즈를 곱하면 로그 공간에서는 더하기가 된다.
역센서 모델에서 얻은 점유 확률 p(O|z)를 사용하면 사전확률을 중복 계산하지 않도록 l_0를 뺀다.

```text
l_t = l_(t-1) + log(p(O|z_t)/(1-p(O|z_t))) - l_0
p_t = 1 / (1 + exp(-l_t))
```

사전 p_0=0.5, 끝점 관측의 p(O|z)=0.8이면 한 번의 증가량은 log4다.
같은 셀에 독립적인 끝점 관측 두 번이면 l=2log4=log16이고 p=16/17이다.
그러나 정지한 센서의 같은 프레임을 두 번 복사해 넣은 것은 독립적인 관측 두 번이 아니다.
계산식이 더 큰 확률을 출력한다고 근거가 늘어난 것은 아니다.

광선의 끝점 앞에 있는 셀은 자유공간 근거를 받는다.
끝점 바로 뒤는 가려졌으므로 단지 관측되지 않았을 뿐이다.
레이저나 깊이 영상의 무응답은 흡수성 재료, 범위 밖, 가림, 센서 실패 중 무엇인지 분명하지 않을 수 있다.
따라서 무응답을 끝까지 자유공간으로 지우는 정책은 별도의 센서 모델이 필요하다.

로그 오즈를 무한히 누적하면 오래된 오판을 되돌리기 어렵다.
상하한을 두거나 시간 감쇠를 사용하는 것은 지도 갱신의 설계 선택이다.
감쇠는 확실한 정적 벽도 불확실하게 만들 수 있으므로 모든 셀에 같은 시간 상수를 적용할 이유는 없다.
동적 객체와 정적 구조를 나누는 지도 수명주기로 이 문제가 이어진다.

<a id="d21-6"></a>
### 6. TSDF의 가중 평균을 최소제곱에서 직접 유도한다

한 복셀 중심이 카메라에서 z_v m이고 그 픽셀의 관측 표면 깊이가 D_i m라고 하자.
이 장은 표면 앞을 양수로 정의한다.
절단 거리 mu>0 m를 정하고 정규화 관측 f_i=clip((D_i-z_v)/mu,-1,1)을 사용한다.
f_i는 무차원이다.
표면 뒤에서 D_i-z_v<-mu인 셀을 어디까지 갱신할지는 가림 처리 정책에 달렸으며, 여기 그림은 거리함수 단면의 교육용 시각화이지 전체 광선 carving 구현이 아니다.

여러 관측이 같은 잠재값 F를 측정한다고 가정하면 다음 비용을 최소화할 수 있다.

```text
E(F) = sum_i w_i (F - f_i)^2
dE/dF = sum_i 2 w_i (F - f_i)
       = 2 F sum_i w_i - 2 sum_i w_i f_i

dE/dF = 0 이므로
F = (sum_i w_i f_i) / (sum_i w_i)
```

과거의 분자 합 S_old와 가중치 W_old를 보관하면 새 관측 하나는 S_new=S_old+w f, W_new=W_old+w다.
F_old=S_old/W_old를 대입하면 익숙한 온라인 식이 나온다.

```text
F_new = (W_old F_old + w f)/(W_old + w)
W_new = W_old + w
```

F_old=0.5, W_old=2, f=-0.25, w=1이면 분자는 1-0.25=0.75, 분모는 3이므로 F_new=0.25다.
이 값은 표면이 아직 복셀보다 뒤에 있다는 뜻이며 표면까지 0.25 m라는 뜻이 아니다.
mu=0.12 m이고 절단되지 않은 구간이라면 대응하는 광선 방향 거리는 0.03 m다.

가중치 w_i=1/sigma_i²는 독립 Gaussian 측정의 최대우도 해에서 나온다.
sigma_i가 정규화 거리의 표준편차이면 w_i도 그 역분산이다.
가중치에 노출·관측각·신뢰도 같은 경험적 값을 섞었다면 W를 곧바로 통계적 정보량이라고 부르면 안 된다.
절단된 값, 상관된 프레임, 이상치까지 포함하면 이 단순 Gaussian 해석은 더 약해진다.

합성 깊이 [2.00,2.03,1.98] m, 가중치 [1,1,4]의 공통 비절단 구간에서 영점은 가중 깊이 평균이다.
분자는 2+2.03+7.92=11.95 m, 분모는 6이므로 1.9916667 m다.
동일 가중치 평균 2.0033333 m와 다른 것은 세 번째 관측을 더 신뢰했기 때문이다.
세 번째 관측의 바이어스가 크다면 그 선택이 오히려 결과를 나쁘게 한다.

![D21-1 가중 TSDF와 자세 불일치](../research/computer-vision-textbook/reconstruction/figures/d21_01_tsdf.png)

그림 D21-1. 위는 합성 관측 세 개의 깊이와 가중치가 정규화 TSDF 영점에 미치는 영향을 보여준다. 가로축은 복셀 z좌표 m, 세로축은 무차원 거리값이다. 아래는 같은 표면을 0.15 m 다르게 배치한 두 자세의 관측을 평균한 교육용 단면이다. 참 표면 점선과 평균 영점의 차이는 많은 점을 합쳐도 공유 자세 오차가 사라지지 않음을 뜻한다. 출처는 이 연구의 `src/run.py`, 실제 센서 TSDF 구현이나 논문 재현 결과가 아니다.

### 7. 표면의 영점과 ESDF의 최근접 거리는 다르다

두 인접 복셀의 거리값이 F_a>0, F_b<0라면 선형 보간으로 영점 위치를 구할 수 있다.
위치를 x(t)=x_a+t(x_b-x_a), 값을 F(t)=F_a+t(F_b-F_a)라 두자.
F(t)=0을 풀면 t=F_a/(F_a-F_b)다.
F_a=0.25, F_b=-0.75이면 t=0.25이므로 영점은 a에서 b로 1/4 이동한 곳이다.
이 작은 계산이 격자 셀에서 등위면을 추출하는 방법의 기본 재료다.
실제 메시 추출에는 셀 모서리의 부호 구성, 모호한 연결, 경계 조건을 추가로 다뤄야 한다.

광선 방향 거리는 표면 법선 방향 거리와 일반적으로 다르다.
평면 n^T x=b와 단위 광선 방향 r을 생각하자.
광선상 점 x에서 평면까지 더 가야 할 거리 s는 n^T(x+s r)=b를 풀어 얻는다.

```text
s = (b - n^T x)/(n^T r)
법선 방향 거리 d = b - n^T x       (||n||=1)
따라서 d = s (n^T r)
```

광선이 비스듬히 닿아 n^T r=0.2이면 광선 방향 0.10 m가 법선 방향으로는 0.02 m다.
TSDF를 절단값 밖으로 단순 연장한다고 공간의 최단 거리장이 되지 않는 이유다.
여러 표면이 있으면 가장 가까운 표면이 해당 카메라 광선이 만난 표면과 다를 수도 있다.

이 장의 ESDF 그림은 SciPy의 Euclidean distance transform을 사용한 2차원 격자 단면이다.
비점유 셀에서 가장 가까운 점유 셀 중심까지의 거리와 그 반대 거리를 빼서 부호를 만든다.
셀 간격 0.05 m를 곱해 미터로 바꾸었다.
따라서 연속 사각형 경계까지의 정확한 signed distance가 아니라 셀 중심 기반 거리다.
격자 경계에서 반 셀 수준의 차이를 연속 기하 오차와 혼동하지 않아야 한다.

![D21-2 격자 점유와 셀 중심 ESDF](../research/computer-vision-textbook/reconstruction/figures/d21_02_esdf.png)

그림 D21-2. 합성 사각형 장애물의 알려진 점유 셀과 SciPy 거리변환 결과다. 두 축은 m, 오른쪽 색은 부호 거리 m이며 등고선은 장애물 바깥의 거리 수준을 표시한다. 실제 방이나 차량 데이터가 아니고 모든 셀의 점유 상태를 아는 교육 모델이다. 미관측 공간 처리와 TSDF에서 ESDF로 전파하는 Voxblox의 증분 알고리즘은 실행하지 않았다.

### 8. 법선은 가까운 점들의 공분산에서 얻되, 이웃의 의미를 검사한다

ICP는 Iterative Closest Point, 즉 대응점을 반복 갱신하며 정합하는 방법의 계열이다.
점-평면 ICP에서 목적 함수는 한 점이 대응 표면의 접평면으로부터 얼마나 떨어졌는지를 사용한다.
그러려면 표면 법선이 필요하다.
이웃 점 p_j의 평균을 c라 하고 Q_j=p_j-c라고 하면 공분산 C=(1/k) sum_j Q_j Q_j^T를 만든다.

평면 법선 후보 n은 점들이 법선 방향으로 퍼진 양을 최소화해야 한다.

```text
minimize sum_j (n^T Q_j)^2 subject to n^T n = 1
sum_j (n^T Q_j)^2 = n^T (sum_j Q_j Q_j^T) n

라그랑주 함수 L = n^T C n - lambda(n^T n - 1)
dL/dn = 2 C n - 2 lambda n = 0
C n = lambda n
```

따라서 가장 작은 고유값의 고유벡터가 법선 방향이다.
고유벡터 n과 -n은 같은 평면을 나타내므로 방향은 따로 정한다.
센서를 향하는 법선을 원하면 n^T(c_sensor-c)>0이 되도록 부호를 정한다.
서로 다른 시점에서 얻은 법선의 부호가 뒤집히면 법선 각도 게이트가 올바른 점을 버릴 수 있다.

KD-tree는 k-dimensional tree이며 공간을 축에 따라 분할해 가까운 이웃 검색을 가속하는 자료구조다.
이 연구는 SciPy cKDTree를 사용해 12개 이웃을 찾고 NumPy 고유분해로 법선을 구한다.
직접 만든 검색 엔진의 속도를 논하지 않는다.
반경이 너무 크면 모서리 양쪽 면을 평균하고, 너무 작으면 잡음에 민감하다.
깊이 불연속을 가로질러 이웃을 섞으면 실제 어느 표면에도 속하지 않는 법선이 생긴다.

고유값이 lambda_1≤lambda_2≤lambda_3일 때 lambda_1이 작고 lambda_2가 충분히 크면 평면의 근거가 있다.
lambda_1과 lambda_2가 함께 작으면 선에 가까워 법선이 유일하지 않다.
모두 크고 비슷하면 이웃이 구처럼 흩어져 접평면 모델이 부적절하다.
“법선 계산 성공”이라는 함수 반환값보다 고유값 구조가 중요하다.

### 9. 점-평면 정합의 야코비안을 부호까지 유도한다

현재 변환으로 옮긴 원본 점을 p, 대상 점을 q, 대상 단위 법선을 n이라 하자.
잔차 r=n^T(p-q)는 미터다.
작은 왼쪽 회전 증가량 delta_theta와 이동 delta_t를 현재 p에 적용한다.
회전 1차 근사에서 p_new≈p+delta_theta×p+delta_t다.

```text
r_new ≈ n^T(p-q) + n^T(delta_theta × p) + n^T delta_t

스칼라 삼중곱 a^T(b×c)=b^T(c×a)를 사용하면
n^T(delta_theta × p) = (p × n)^T delta_theta

delta = [delta_theta_x, delta_theta_y, delta_theta_z,
         delta_t_x, delta_t_y, delta_t_z]^T
J = [ (p×n)^T, n^T ]
r_new ≈ r + J delta
```

회전 증가량은 rad, 이동은 m이다.
J의 회전 열은 m/rad로 볼 수 있고 이동 열은 무차원이다.
전체 J의 특이값 크기를 다른 길이 스케일의 문제와 그대로 비교하면 단위 혼합 문제가 생긴다.
rank나 정확한 영공간은 유용하지만 조건수를 물리적으로 해석할 때는 회전·이동 스케일을 정규화해야 한다.

잔차 벡터와 가중 행렬 W가 주어지면 비용은 ||W^(1/2)(r+Jdelta)||²다.
미분을 0으로 놓으면 J^T W J delta=-J^T W r다.
수치 구현에서는 역행렬을 명시적으로 만들기보다 최소제곱 분해나 적절한 선형해법을 사용한다.
가까운 대응점은 현재 변환에 따라 달라지므로 이 식 한 번으로 전체 ICP가 끝나지 않는다.
변환 적용, 대응 검색, 게이트, 선형해, 종료 검사를 반복한다.
각 단계의 선택이 수렴에 미치는 영향을 분리한 고전적 연구가 Rusinkiewicz와 Levoy의 ICP 변형 비교다. [저자 원문, 2001](https://graphics.stanford.edu/papers/fasticp/)

평면 z=1에 n=[0,0,1]을 대입하면 p×n=[y,-x,0]이다.
따라서 J=[y,-x,0,0,0,1]이다.
z축 회전과 x,y 평행이동의 세 열이 0이다.
벽 앞에서 좌우로 움직이거나 벽의 법선 주위로 돌더라도 점-평면 거리는 변하지 않는다.
센서 잡음이 작아도 이 세 방향은 관측되지 않는다.
정규화나 더 많은 반복으로 없는 정보를 만들 수 없다.

### 10. 강건 손실이 고치는 오류와 고치지 못하는 오류

독립 대응점이 정해진 상태에서 법선 방향 이동량을 관측한다고 하자.
진짜 이동은 0.04 m이고 400개 관측 중 80개에 0.4 m 이상치를 더했다.
관측 y_i에 대해 최소제곱은 sum(t-y_i)²를 최소화하므로 t=mean(y_i)다.
이상치가 20%이므로 잡음을 무시한 바이어스는 0.2·0.4=0.08 m다.
작은 Gaussian 잡음을 포함한 실행 결과는 0.1200614 m였다.

Huber 손실은 작은 잔차에는 제곱, 큰 잔차에는 선형 증가를 사용한다.
전이값 delta의 단위는 잔차와 같은 미터다.

```text
rho(r) = 0.5 r^2                      if |r| <= delta
       = delta |r| - 0.5 delta^2     otherwise

psi(r) = d rho/dr
       = r                           if |r| <= delta
       = delta sign(r)              otherwise
```

큰 잔차의 기울기가 delta에서 포화되므로 한 이상치가 무한한 영향력을 갖지 않는다.
이 예에서 delta=0.01 m인 SciPy least_squares의 Huber 해는 0.0426860 m다.
참값과의 차이는 약 0.0026860 m이고 최소제곱의 차이는 약 0.0800614 m다.
이는 실제 ICP 시스템의 정확도 수치가 아니라 대응점을 알고 있는 1차원 부분 문제의 결과다.
Huber가 대응 검색, 초기 정렬, 움직이는 물체 분리까지 해결했다고 주장하지 않는다.

![D21-3 관측 불가능성과 강건 추정](../research/computer-vision-textbook/reconstruction/figures/d21_03_registration.png)

그림 D21-3. 왼쪽은 합성 평면의 점-평면 야코비안 특이값으로 rank=3임을 보여준다. 회전·이동 열의 단위가 혼합되어 있으므로 막대의 절대 크기는 일반적인 정합 품질 점수가 아니다. 오른쪽 가로축은 알려진 대응점의 법선 이동 m, 세로축은 개수이며 20% 이상치에서 평균과 Huber 추정의 차이를 읽는다. 출처는 시드 21024의 자체 생성 실험, 실제 등록 벤치마크가 아니다.

대부분의 대응이 잘못되었거나 두 표면이 서로 비슷한 경우에는 강건 손실도 잘못된 해를 지지할 수 있다.
모든 잔차가 작지만 잘못된 주기적 패턴에 정렬된 상황이 그 예다.
후속 설계는 법선 방향 다양성, 거리·각도 게이트, 다중 해상도 초기화, 추가 센서 또는 특징 대응으로 부족한 정보를 보완해야 한다.
추가 정보 없이 손실 함수만 바꾸는 것은 식별 가능성의 해결책이 아니다.

### 11. 색 정렬과 실제 KITTI 점군: 예쁜 색이 기하 검증은 아니다

깊이 카메라 D와 색 카메라 C가 다르면 깊이 점 p_D를 T_CD로 옮긴 뒤 색 카메라에 투영해야 한다.
깊이 영상의 (u,v)를 그대로 색 영상 배열의 인덱스로 쓰는 것은 두 카메라가 이미 정렬된 경우에만 맞다.
색 카메라에서 같은 픽셀로 여러 깊이 점이 투영되면 가장 가까운 가시 표면을 선택하는 z-buffer 검사가 필요하다.
그렇지 않으면 뒤쪽 벽의 색이 앞쪽 물체에 칠해질 수 있다.
시간차가 있다면 T_CD만 맞아도 움직이는 장면에서는 색이 어긋난다.

색의 수치 공간도 구분한다.
sRGB 같은 비선형 표시값을 그대로 물리적 광도 평균으로 해석하면 밝기 모델이 틀어진다.
색 정렬에 성공했다는 사실과 광도 보정에 성공했다는 사실은 별개다.
본 실험은 컬러 센서가 아니라 KITTI의 실제 흑백 영상 두 장을 사용한다.
점의 명암은 왼쪽 영상에서 가져오며 합성 RGB를 실제 차량 컬러로 표시하지 않는다.

OpenCV StereoSGBM으로 계산한 고정소수점 시차를 16으로 나누고,
`calib.txt`의 P0/P1에서 초점거리와 기준선을 읽어 점군을 만들었다.
Semi-Global Block Matching이라는 이름의 SGBM 내부를 재구현하지 않고 검증된 라이브러리를 사용했다.
양의 시차 1 px 초과, 깊이 45 m 미만인 점만 남기고 그림에는 6픽셀 간격으로 표본화했다.
이 유효 조건은 깊이 정확성을 증명하는 조건이 아니라 시각화를 위한 거친 게이트다.

그림 D21-4. 위는 KITTI Odometry 00의 실제 `image_0/000000.png`이며 축은 픽셀이다. 아래는 같은 시점 좌우 흑백 영상으로 계산한 StereoSGBM 점군, 축은 카메라 x,z,-y의 m다. 수직축 부호를 바꿔 위쪽이 위로 보이게 표시했으나 저장 좌표는 x오른쪽·y아래·z전방이다. 회색은 실제 왼쪽 명암이며 깊이 GT, 좌우 일관성 완전 검증, 다중 프레임 융합은 사용하지 않았다. 출처: 로컬 KITTI 00 데이터와 연구 코드.

실제 복원 품질을 평가하려면 별도 깊이 참조, 영역별 오차, 좌우 검사와 시간 일관성 등이 필요하다.
KITTI의 데이터셋 및 공식 평가의 목적은 공식 설명과 분리해 읽는다. [KITTI 공식 odometry](https://www.cvlibs.net/datasets/kitti/eval_odometry.php)

### 12. 풀이가 있는 연습문제: 지도 수치의 일관성

**문제 D21-A. 독립 깊이 두 개의 최적 가중치를 구하라.**
같은 깊이를 2.00 m와 2.04 m로 관측했고 표준편차는 각각 0.01 m와 0.02 m다.
역분산 가중 융합값과 분산을 구하고, 두 관측이 완전히 상관되면 무엇이 달라지는지 설명하라.

**풀이.** 가중치는 10,000과 2,500 m^-2다.
가중 평균은 (20,000+5,100)/12,500=2.008 m다.
독립 가정의 분산은 1/12,500=0.00008 m², 표준편차는 약 0.008944 m다.
완전 상관이면 두 오차의 교차항이 0이 아니므로 이 역분산 합 공식으로 신뢰도를 계산할 수 없다.
특히 같은 원본 프레임을 복제했다면 두 번째 표본이 새 정보를 주지 않는다.
단위검사 `test_24_fusion_variance`는 독립인 경우의 분산만 검증한다.

**문제 D21-B. 표면 영점의 위치를 계산하라.**
두 복셀 중심 x_a=1.90 m, x_b=2.00 m에서 F_a=0.3, F_b=-0.2다.
선형 보간 영점과 절단값에서의 한계를 설명하라.

**풀이.** t=0.3/(0.3+0.2)=0.6이므로 x=1.90+0.6·0.10=1.96 m다.
값이 표면 근처 선형 근사로 의미가 있다는 가정이 필요하다.
멀리 절단된 ±1만 보고 큰 간격을 보간하면 표면 근처 실제 기울기를 알 수 없으므로 같은 해석이 성립하지 않는다.
또한 서로 다른 표면의 관측이 한 셀에 섞인 경우 영점은 평균의 결과이지 실제 표면의 증명이 아니다.

**문제 D21-C. 평면 하나로 보이지 않는 운동을 찾으라.**
p=(1,2,1), n=(0,0,1)일 때 J를 구하고, delta=(0,0,0.1,0.2,-0.3,0)의 예측 잔차 변화를 계산하라.

**풀이.** p×n=(2,-1,0)이므로 J=(2,-1,0,0,0,1)이다.
Jdelta=0이다. 즉 z축 작은 회전과 평면 내 이동은 1차 점-평면 잔차를 바꾸지 않는다.
“잔차가 작으니 pose가 정확하다”는 판단이 왜 불충분한지 보여주는 반례다.
면적이 넓은 같은 평면의 점을 더 넣어도 이 세 열의 0은 변하지 않는다.
다른 방향 법선의 표면이나 별도 시각 특징이 필요하다.

**문제 D21-D. 큰 점유 확률과 미관측을 구분하라.**
사전확률 0.5, 점유 근거 p=0.8을 두 번 적용한 셀 A와 한 번도 관측하지 않은 셀 B가 있다.

**풀이.** A는 오즈 4²=16이므로 16/17≈0.941176이다.
B는 사전 0.5지만 이것을 반쯤 빈 공간으로 확정하지 않는다.
관측 여부 비트를 별도로 보관해 unknown으로 질의해야 한다.
경로 계획에서 unknown을 통과할지 여부는 탐사 정책과 위험 제약이 결정한다.

## D22. 장면에서 영상으로, 영상에서 장면으로: 렌더링과 역그래픽스

<a id="d22-1"></a>
### 1. 왜 SLAM 학습에 렌더링의 순방향 모델이 필요한가

지도와 카메라 자세가 주어졌을 때 어떤 영상이 보여야 하는지를 계산하는 것이 렌더링이다.
반대로 영상과 예측 영상의 차이로 형상·재료·조명·자세를 찾으면 역그래픽스가 된다.
여기서 “역”은 행렬 하나를 뒤집는다는 뜻이 아니다.
다른 3차원 장면이 같은 2차원 영상을 만들 수 있으므로 관측만으로 해가 유일하지 않을 수 있다.
순방향 모델의 어느 가정을 쓰는지를 먼저 정해야 역문제의 의미가 명확해진다.

이 장은 삼각형 메시의 가시성, 광도에 의한 법선 추정, 광선 위 부피 합성, Gaussian의 화면 투영을 연결한다.
네 방법의 공통 질문은 “무엇이 이 픽셀에 얼마나 기여하는가”이다.
그러나 깊이 선택, 빛 반사, 투과율, 학습된 외관을 동일한 물리량이라고 생각해서는 안 된다.
신경망이 출력을 만들었다는 사실은 물리적 식별 불가능성을 없애지 않는다.

입력은 카메라 내부·외부 파라미터, 장면 표현, 조명 또는 학습된 radiance다.
출력은 픽셀의 선형 색 또는 명암, 선택적 깊이·법선·가시성이다.
radiance는 특정 위치에서 특정 방향으로 나가는 빛의 양을 나타내는 복사휘도다.
실제 물리 단위는 W/(m² sr)이지만, 이 장의 합성 실험에서는 노출과 센서 응답을 생략한 정규화 선형 RGB [0,1]을 사용한다.
따라서 본문 예제의 0.5는 절대 광량 측정값이 아니다.

<a id="d22-2"></a>
### 2. 카메라 앞의 삼각형을 화면의 픽셀로 바꾼다

세계 점 p_w를 카메라로 옮기는 변환 T_cw를 적용하면 p_c=(X,Y,Z)다.
이 장은 Z>0을 카메라 전방으로 사용한다.
일부 그래픽스 API가 카메라 전방을 -z로 정하는 관례와 섞지 않는다.
투영은 u=f_x X/Z+c_x, v=f_y Y/Z+c_y다.
Z가 0에 가까우면 값이 발산하므로 가까운 절단면 z_near>0이 필요하다.

가까운 절단면을 가로지르는 삼각형을 “정점 세 개 중 하나가 뒤에 있으니 통째로 삭제”하면 화면 가장자리에서 큰 구멍이 생길 수 있다.
정확한 clipping은 간선을 절단면과 교차시켜 남은 다각형을 만든다.
간선 p(t)=a+t(b-a)의 z성분이 z_near가 되는 t를 구하면 된다.

```text
a_z + t(b_z-a_z) = z_near
t = (z_near-a_z)/(b_z-a_z)
p_intersection = a + t(b-a)
```

예를 들어 a_z=0.05 m, b_z=0.25 m, z_near=0.10 m이면 t=0.25다.
교차점의 위치뿐 아니라 정점에 붙은 속성도 같은 간선 파라미터로 보간해야 한다.
clipping과 화면 밖 culling은 목적이 다르다.
culling은 보이지 않을 것이 확실한 프리미티브를 생략하는 것이고 clipping은 일부만 보이는 프리미티브를 잘라내는 것이다.

화면 삼각형의 정점 s_0,s_1,s_2에 대해 한 픽셀 중심 s를 무게중심 좌표 lambda_i로 표현한다.
lambda_0+lambda_1+lambda_2=1이고 s=sum_i lambda_i s_i다.
세 lambda가 모두 0 이상이면 삼각형 안에 있다.
경계 위 픽셀을 인접 삼각형이 둘 다 소유하거나 둘 다 버리지 않도록 일관된 edge rule도 필요하다.
이 장의 그림은 연속 화면 좌표 격자를 사용한 보간 실험이며 그래픽스 API의 모든 래스터 규칙을 재현한 것은 아니다.

<a id="d22-3"></a>
### 3. 깊이를 화면에서 선형 보간하면 왜 틀리는가

3차원 선분이나 삼각형의 점은 카메라 투영에서 깊이로 나누어진다.
따라서 화면 무게중심 lambda_i가 3차원 표면의 무게중심과 같지 않다.
각 정점의 깊이를 Z_i, 선형 속성을 a_i라 할 때 원근 보정 보간은 다음 형태다.

```text
q_i = lambda_i / Z_i
q_sum = sum_i q_i
beta_i = q_i/q_sum
a_pixel = sum_i beta_i a_i
        = sum_i(lambda_i a_i/Z_i) / sum_i(lambda_i/Z_i)

Z_pixel = sum_i beta_i Z_i
        = sum_i lambda_i / sum_i(lambda_i/Z_i)
        = 1 / sum_i(lambda_i/Z_i)
```

마지막 식의 분자가 1이 되는 이유는 화면 무게중심의 합이 1이기 때문이다.
즉 카메라 Z 자체가 아니라 1/Z가 화면 삼각형에서 선형 보간된다.
메모리에 저장하는 GPU depth 값은 투영 규약에 따라 Z와 다른 비선형 값일 수 있으므로, 이 식의 Z와 depth buffer 비트를 동일시하지 않는다.

Z=[1,2,4] m, lambda=[0.25,0.25,0.5]라면 역깊이 합은 0.25+0.125+0.125=0.5 m^-1이다.
정확한 카메라 깊이는 2 m다.
깊이를 그대로 가중 평균하면 0.25+0.5+2=2.75 m가 되어 0.75 m 과대 추정한다.
beta는 [0.5,0.25,0.25]이므로 3차원 속성의 보간에도 이 가중치를 사용해야 한다.

z-buffer는 픽셀마다 지금까지 본 가장 가까운 깊이를 보관한다.
새 삼각형이 같은 픽셀에 들어오면 유효 깊이를 비교하고 가까운 것이 색과 깊이를 갱신한다.
불투명 표면에서는 보통 가장 앞의 표면만 남기지만 반투명에서는 뒤의 표면도 기여할 수 있다.
그래서 z-buffer의 “최솟값 선택”과 뒤에서 볼 alpha 합성의 “가중합”은 다른 연산이다.

![D22-1 원근 보정 깊이 보간](../research/computer-vision-textbook/reconstruction/figures/d22_01_raster.png)

그림 D22-1. 합성 화면 삼각형에서 왼쪽은 역깊이 보간으로 얻은 카메라 깊이, 오른쪽은 단순 깊이 선형 보간에서 이를 뺀 오차다. 화면 두 축은 0–1 정규화 좌표이고 색막대는 m다. 삼각형 바깥은 표시하지 않는다. 이 그림은 직접 계산한 교육용 보간 배열이며 실제 GPU 렌더러, KITTI 표면 또는 전체 메시 래스터화 결과가 아니다.

### 4. 빛의 반사는 법선과 재료와 입사광의 결합이다

BRDF는 Bidirectional Reflectance Distribution Function, 양방향 반사 분포 함수다.
표면에 들어오는 방향 omega_i의 빛이 나가는 방향 omega_o로 얼마나 반사되는지 나타낸다.
기호 f_r의 단위는 sr^-1이고, 단위 법선 n과 입사 방향의 내적이 투영 면적을 결정한다.
표면에서 나가는 빛은 입사 반구의 기여를 적분한 값과 자체 발광의 합이다.

```text
L_o(x, omega_o)
  = L_e(x, omega_o)
    + integral_hemisphere
      f_r(x, omega_i, omega_o)
      L_i(x, omega_i)
      max(0, n^T omega_i) d omega_i
```

이 식에서 그림자, 가림, 상호 반사는 L_i와 가시성 모델에 영향을 준다.
하나의 픽셀 값에 형상·재료·조명·노출이 함께 섞이는 이유가 여기 드러난다.
Lambertian 모델에서는 f_r=rho/pi이며 방향에 따른 반사 특성이 일정하다.
rho는 확산 반사율로 무차원이다.
이상적 원거리 단일 조명 아래에서는 노출·광원 세기와 pi를 묶어 I=rho max(0,n^T l)처럼 쓸 수 있다.

이 장에서 l은 조명 방향에 세기를 포함한 알려진 벡터다.
따라서 l의 길이가 1이면 단위 세기라는 추가 약속이 있다.
실제 영상의 감마 처리값을 선형 I로 바로 쓰지 않고, 센서 응답과 포화가 있는지도 확인해야 한다.
검은 재료와 그림자를 같은 작은 I로 관측할 수 있으므로 하나의 밝기만으로 표면 법선은 결정되지 않는다.

법선 n은 길이 1이지만 자유도는 2다.
한 이미지의 밝기 방정식은 스칼라 하나이고, 재료 rho까지 모르므로 미지수는 더 많다.
shape from shading, 즉 명암에서 형상을 찾는 문제에는 조명·재료·경계·매끄러움 같은 추가 가정이 필요하다.
이 장은 그러한 가정을 숨긴 단안 형상 복원을 실행하지 않는다.
다음 절에서는 카메라와 물체를 고정하고 조명만 바꾸어 방정식을 늘린다.

<a id="d22-5"></a>
### 5. 광도 스테레오의 선형해를 손으로 풀어 본다

Photometric stereo는 광도 스테레오이며 서로 다른 카메라 위치가 아니라 서로 다른 조명을 이용한다.
카메라와 표면이 고정되어 같은 픽셀이 같은 표면점을 관측해야 한다.
그림자와 정반사가 없고 조명이 알려졌다는 조건에서 I_j=rho l_j^T n이다.
미지수 g=rho n을 정의하면 I=L g가 된다.
L의 각 행이 조명 벡터의 전치이고, 최소 세 개의 독립적인 조명이 필요하다.
Woodham의 1980년 논문은 다중 영상의 광도로 표면 방향을 얻는 이 문제의 초기 원전이다. [Woodham 저자 출판 목록](https://www.cs.ubc.ca/~woodham/publications.html)

세 조명을 다음처럼 두자.

```text
L = [ 0    0   1
      0.6  0   0.8
      0   0.6  0.8 ]
I = [0.4, 0.44, 0.32]^T

첫 행: g_z = 0.4
둘째 행: 0.6 g_x + 0.8*0.4 = 0.44
         0.6 g_x = 0.12
         g_x = 0.2
셋째 행: 0.6 g_y + 0.8*0.4 = 0.32
         g_y = 0

rho = ||g|| = sqrt(0.2^2 + 0.4^2) = sqrt(0.20)
n = g/rho = [1/sqrt(5), 0, 2/sqrt(5)]
```

반사율과 법선을 분리할 수 있는 이유는 법선 길이가 1이라는 제약 때문이다.
조명의 세기가 모두 두 배인데 이를 모르면 추정 rho가 두 배로 바뀐다.
조명 방향이 거의 같으면 L의 열이 독립적이지 않아 작은 잡음이 큰 법선 오차로 커진다.
세 이미지를 얻었다는 개수보다 조명 기하의 rank가 중요하다.

조명이 셋보다 많으면 최소제곱 g=argmin||Lg-I||²를 구한다.
정상방정식 L^T Lg=L^T I를 쓸 수 있지만 수치 구현은 `lstsq`의 분해를 사용했다.
그림의 깨끗한 데이터는 n=[0.3,0.4,sqrt(0.75)], rho=0.7, 다섯 조명으로 생성했다.
그 중 한 밝기에 0.4를 더해 정반사성 위반을 흉내 내면 최소제곱 법선은 참 법선과 약 18.6282도 차이가 났다.
이 오염 밝기는 1을 조금 넘으며 실제 센서의 포화 처리는 적용하지 않았다. 색 합성의 [0,1] RGB와 달리 여기 밝기 축은 상대 선형 광도 단위다.
이 값은 실제 재료의 광학 성능이 아니라 의도적으로 Lambertian 조건을 깨뜨린 합성 반례다.

![D22-2 조명 가정 위반과 광도 스테레오](../research/computer-vision-textbook/reconstruction/figures/d22_02_photometric.png)

그림 D22-2. 왼쪽은 다섯 알려진 조명에서 얻은 합성 선형 밝기와 한 관측에 정반사성 증가를 넣은 밝기다. 오른쪽은 원래 단위 법선과 오염된 최소제곱 해를 비교한다. 밝기와 법선 성분은 무차원이고 제목의 각도는 degree다. 실제 물체 촬영이 아니며 그림자·감마·상호 반사를 모델링하지 않은 교육용 실패 실험이다.

표면 법선을 얻어도 전체 깊이가 바로 얻어지는 것은 아니다.
직교 투영에서 z=z(x,y)인 표면의 비정규화 법선은 [-z_x,-z_y,1]이다.
따라서 z_x=-n_x/n_z, z_y=-n_y/n_z이고 이를 적분해 높이를 찾는다.
잡음이 있으면 측정된 두 기울기가 하나의 높이 함수에서 나왔다는 적분 가능 조건 d z_x/dy=d z_y/dx를 만족하지 않을 수 있다.
경계 조건과 최소제곱 적분이 추가로 필요하며 높이의 상수 오프셋은 법선만으로 알 수 없다.

### 6. 역그래픽스의 식별 불가능성은 최적화 실패와 다르다

정규화 밝기 I=rho n^T l에서 rho를 두 배로 하고 조명 세기를 절반으로 하면 I는 같다.
관측 영상만으로 둘을 구분할 근거가 없다면 이는 최적화가 덜 되어서가 아니라 모델의 대칭성이다.
카메라와 장면의 전체 스케일을 함께 바꾸어 같은 투영을 만드는 기하학적 모호성도 비슷하다.
해를 고정하려면 조명 보정, known scale, 다중 시점, 반사율 범위 같은 별도 정보가 필요하다.

광도 잔차 E=sum||I_obs-I_render(theta)||²에서 theta에는 자세, 기하, 재료, 조명이 들어갈 수 있다.
하나의 잔차 감소가 어느 변수를 더 정확하게 했는지 자동으로 알려주지 않는다.
잘못된 형상을 복잡한 방향 의존 색으로 보상하거나 노출 오차를 밀도로 흡수할 수 있다.
그러므로 재투영 색 오차, 새로운 시점의 영상 품질, 깊이 오차, 법선 오차, 치수 오차를 분리한다.

미분 가능한 렌더러는 파라미터 변화가 영상에 미치는 기울기를 제공한다.
그 기울기가 있다는 것과 최적화 문제가 잘 조건화되었다는 것은 다르다.
가림 경계에서 가시성 변화는 불연속적일 수 있고, 표면 뒤쪽은 현재 시점의 손실에 거의 기여하지 않을 수 있다.
가려진 면의 매끄러운 결과가 관측의 산물인지 정규화나 모델의 사전 가정인지 표시해야 한다.
디지털 트윈에서 이 구분은 단순한 철학이 아니라 측정 가능 영역을 정하는 계약이다.

### 7. 광선 위 부피 밀도에서 alpha를 유도한다

신경 복사장으로 넘어가도 먼저 연속 매질의 감쇠를 이해해야 한다.
단위 길이당 빛을 종료시키는 밀도를 sigma(t)≥0, 단위는 m^-1로 두자.
광선은 r(t)=o+t d이며 ||d||=1이면 t와 구간 길이 delta의 단위는 m다.
T(t)는 시작점에서 t까지 아무 종료 사건 없이 도달한 투과율이다.
작은 구간 dt에서 살아남을 비율을 1-sigma(t)dt로 근사하면 다음 미분식이 된다.

```text
T(t+dt) ≈ T(t)(1-sigma(t)dt)
[T(t+dt)-T(t)]/dt ≈ -sigma(t)T(t)
dT/dt = -sigma(t)T(t)
d(log T)/dt = -sigma(t)
T(t) = exp(-integral_0^t sigma(s) ds)
```

한 구간에서 sigma_i가 일정하면 투과율 배수는 exp(-sigma_i delta_i)다.
그 구간에서 종료될 조건부 비율 alpha_i는 1-exp(-sigma_i delta_i)다.
sigma_i delta_i는 무차원이어야 지수함수가 의미를 갖는다.
광선 방향을 정규화하지 않았다면 delta가 단순한 t간격인지 실제 공간 길이인지 다시 확인해야 한다.

구간 i까지 도달하는 비율 T_i는 앞 구간들의 생존 비율 곱이다.
따라서 i번째 색 c_i의 가중치는 w_i=T_i alpha_i다.

```text
T_1 = 1
T_i = product_(j<i) (1-alpha_j)
w_i = T_i alpha_i
C = sum_i w_i c_i + T_end c_background
T_end = product_i (1-alpha_i)
```

가중치 합을 보면 w_i=T_i-T_(i+1)이므로 망원 합이 된다.
sum_i w_i=1-T_end다.
배경까지 포함하면 가중치가 정확히 1이 되어 색이 보존된다.
검정 배경을 암묵적으로 두면 빠진 질량은 검정에 기여한 것이다.
배경을 생략한 구현과 흰 배경을 둔 구현의 색을 직접 비교하면 다른 문제를 비교하는 셈이다.

### 8. 앞뒤 순서를 바꾸면 같은 색 표본도 다른 영상이 된다

세 구간 alpha=[0.5,0.25,0.8], 색을 빨강·초록·파랑 단위벡터, 배경을 흰색으로 두자.
가장 앞 구간의 T는 1이므로 빨강 가중치는 0.5다.
두 번째까지 살아남는 비율은 0.5이므로 초록 가중치는 0.5·0.25=0.125다.
세 번째까지는 0.5·0.75=0.375가 도달하고 파랑 가중치는 0.375·0.8=0.3이다.
남은 배경 가중치는 0.5·0.75·0.2=0.075다.

```text
C = 0.5 [1,0,0] + 0.125 [0,1,0] + 0.3 [0,0,1]
    + 0.075 [1,1,1]
  = [0.575, 0.200, 0.375]

전체 가중치 = 0.5 + 0.125 + 0.3 + 0.075 = 1
```

순서를 파랑·초록·빨강으로 바꾸면 파랑이 먼저 0.8을 차지한다.
초록은 0.2·0.25=0.05, 빨강은 0.2·0.75·0.5=0.075이고 배경은 여전히 0.075다.
새 색은 [0.15,0.125,0.875]다.
alpha의 곱은 순서에 무관하지만 어느 색에 얼마를 할당하는지는 순서에 의존한다.
투명도를 정렬하지 않고 평균하는 것이 잘못되는 수치적 이유다.

![D22-3 광선 종료 확률과 순서](../research/computer-vision-textbook/reconstruction/figures/d22_03_compositing.png)

그림 D22-3. 왼쪽 막대는 합성 세 구간과 배경의 종료 가중치이며 합이 1이다. 오른쪽 두 색은 같은 alpha·색 표본을 올바른 앞뒤 순서와 역순으로 합성한 결과다. 색은 정규화 선형 RGB의 교육용 값으로 실제 센서 색이 아니며, 화면 표시에서의 지각적 색 보정은 하지 않았다. 축의 가중치는 무차원이다.

예상 깊이를 D=sum_i w_i t_i로 계산하면 배경 투과가 남았을 때 전체 표면 가중치가 1보다 작다.
표면에 종료했다는 조건부 깊이는 D_cond=sum_i w_i t_i/(sum_i w_i)다.
배경에 유한한 깊이를 부여하는 정의와도 다르다.
깊이 지표를 보고할 때 어떤 정의인지 명시하지 않으면 낮은 밀도의 광선에서 숫자의 의미가 바뀐다.

### 9. NeRF의 학습 변수와 positional encoding을 분리해서 읽는다

NeRF는 Neural Radiance Fields, 신경 복사장이다.
Mildenhall 등은 위치와 시선 방향을 입력으로 밀도와 색을 표현하고 알려진 카메라들에서 영상을 합성하도록 최적화하는 방법을 제시했다.
이 장은 학습을 수행하지 않고 광선 합성의 수치 부분만 직접 검증한다. [Mildenhall 외, ECCV 2020 프로젝트](https://www.matthewtancik.com/nerf)

위치 x=(x,y,z)와 단위 시선 d를 받아 sigma(x), c(x,d)를 내는 함수를 생각하면 된다.
밀도가 시선에 따라 바뀌는지, 색만 방향 의존인지도 모델 계약의 일부다.
훈련 손실은 여러 카메라 광선의 관측 색과 합성 색 사이의 차이를 누적한다.
위치추정의 오차가 입력 pose에 있으면 장면 파라미터가 그 오차를 흡수할 수 있다.
따라서 NeRF라는 이름만으로 SLAM이나 보정 최적화가 포함된다고 보지 않는다.

Positional encoding은 좌표를 여러 주파수의 사인·코사인 성분으로 바꾸는 입력 표현이다.
한 스칼라 x를 [-1,1] 같은 선언된 범위로 정규화하고 L개의 주파수를 사용한다고 하자.

```text
gamma(x) = [sin(pi*x), cos(pi*x),
            sin(2*pi*x), cos(2*pi*x),
            ...,
            sin(2^(L-1)*pi*x), cos(2^(L-1)*pi*x)]
```

원좌표를 추가할지 여부도 구현마다 정해야 한다.
x=0.25, L=2이면 gamma=[sqrt(2)/2,sqrt(2)/2,1,0]이다.
고주파 성분은 작은 좌표 변화에 더 크게 반응하므로 세부 변화를 표현할 기회를 준다.
하지만 실제 관측 광선의 간격보다 빠른 변화는 aliasing을 만들 수 있다.
픽셀은 무한히 얇은 광선이 아니라 유한한 면적에 걸친 측정이므로 해상도가 바뀌면 적분 영역도 달라진다.

여기서 고주파 입력 표현, 밀도 표본의 배치, 픽셀 면적 필터링은 서로 다른 문제다.
주파수를 많이 넣는다고 밀도 표본 수가 자동으로 늘지 않는다.
표본을 많이 찍는다고 보지 못한 뒷면의 정보가 생기지도 않는다.
NeRF 프로젝트가 연결하는 다중 스케일 후속 연구는 이러한 샘플링 문제를 이해한 뒤 읽는 것이 낫다.
해당 후속 모델을 이 실험에서 실행했다거나 속도·품질 수치를 재현했다고 주장하지 않는다.

### 10. 3D Gaussian의 타원체를 화면 타원으로 투영한다

3DGS는 3D Gaussian Splatting의 약자다.
Kerbl 등은 장면을 위치·공분산·불투명도·방향 의존 외관을 가진 Gaussian들로 표현하고 화면에 합성하는 접근을 제안했다.
여기서는 전체 최적화·밀도 제어·GPU 정렬을 재현하지 않고 공분산의 투영과 alpha 계산만 살펴본다. [Kerbl 외, 2023](https://arxiv.org/abs/2308.04079)

3차원 Gaussian의 중심을 mu, 대칭 양의 정부호 공분산을 Sigma라 하자.
좌표 단위가 m이면 Sigma의 단위는 m²다.
등가 타원체는 (x-mu)^T Sigma^-1(x-mu)=k²인 점들의 집합이다.
회전 R과 축별 양의 표준편차 s_x,s_y,s_z를 사용하면 Sigma=R diag(s_x²,s_y²,s_z²) R^T로 만들 수 있다.
이 표현은 축이 회전해도 공분산이 양의 정부호임을 보장한다.

세계 Gaussian을 카메라로 옮길 때 중심은 R_cw mu+t_cw, 공분산은 R_cw Sigma R_cw^T다.
이동은 중심만 바꾸고 공분산을 바꾸지 않는다.
카메라 투영 pi(X,Y,Z)=[fX/Z,fY/Z]의 야코비안은 다음과 같다.

```text
J_pi = [ f/Z    0    -fX/Z^2
           0   f/Z   -fY/Z^2 ]

pi(mu+delta) ≈ pi(mu) + J_pi delta
E[delta delta^T] = Sigma_camera
Sigma_screen ≈ J_pi Sigma_camera J_pi^T
```

J_pi의 단위는 px/m이고 Sigma_screen의 단위는 px²다.
평균 mu=(0.3,0.1,2) m, f=500 px라면 화면 중심은 (75,25) px이다.
주점을 0으로 놓은 값이므로 실제 영상에서는 c_x,c_y를 더한다.
Sigma_camera=diag(0.04²,0.08²,0.12²) m²라면 J_pi의 행은 [250,0,-37.5], [0,250,-12.5]다.

```text
Sigma_uu = 250^2*0.04^2 + (-37.5)^2*0.12^2
         = 100 + 20.25 = 120.25 px^2
Sigma_vv = 250^2*0.08^2 + (-12.5)^2*0.12^2
         = 400 + 2.25 = 402.25 px^2
Sigma_uv = (-37.5)*(-12.5)*0.12^2 = 6.75 px^2

Sigma_screen = [120.25    6.75
                  6.75  402.25]
```

원래 3차원 공분산이 대각이어도 화면 공분산에 비대각 항이 생겼다.
깊이 불확실성이 u와 v에 함께 영향을 주기 때문이다.
이 항을 버리면 타원의 기울기와 기하학적 상관을 잃는다.
Gaussian 중심이 카메라에 아주 가깝거나 분산이 깊이에 비해 크면 선형화가 부정확해진다.
Z≤0까지 확률 질량이 걸치면 단순한 화면 Gaussian으로 설명하기 어렵다.

![D22-4 Gaussian 투영과 근거리 비선형성](../research/computer-vision-textbook/reconstruction/figures/d22_04_gaussian.png)

그림 D22-4. 왼쪽은 위 평균과 공분산에서 생성한 합성 3D 점 4,000개를 정확한 원근식으로 투영한 점과 선형 공분산의 2표준편차 타원이다. 축은 px다. 오른쪽은 중심 깊이를 바꿀 때 선형 투영 공분산 trace의 제곱근을 표시하며 x축 m, y축 px다. 참 3DGS 훈련 결과가 아니고 투영 선형화의 범위를 보는 자체 생성 실험이다.

### 11. Gaussian의 alpha와 물리적 표면의 안전 거리는 다르다

화면 중심 mu_2와 공분산 Sigma_2가 주어졌을 때 픽셀 s의 타원 거리 q는 다음과 같다.

```text
d = s-mu_2
q = d^T Sigma_2^-1 d
G(s) = exp(-0.5*q)
alpha(s) = opacity * G(s)
```

q는 무차원이고 중심에서 0, 한 표준편차 타원에서 1이다.
opacity=0.8일 때 중심 alpha는 0.8, q=1에서 0.8exp(-0.5)≈0.4852다.
이는 중심의 기하학적 점유확률이 80%라는 뜻이 아니다.
렌더링을 설명하는 합성 계수와 물리적 점유 사건의 확률은 다른 모델이다.

여러 Gaussian을 깊이 순서로 정렬한 뒤 앞 절의 alpha 합성으로 색을 계산할 수 있다.
그러나 중심 깊이 정렬은 모든 픽셀에서 정확한 표면 교차 순서를 보장하지 않을 수 있다.
크고 기울어진 타원체, 서로 겹치는 구조, 시점 변화에서는 근사가 드러날 수 있다.
빠른 렌더링의 구조와 정확한 기하 교차의 구조가 다르다는 점을 인식해야 한다.

지도에서 거리 질의를 하려면 어떤 Gaussian이 실제 표면인지, 어디가 자유공간인지, 미관측을 어떻게 표시하는지 별도 계약이 필요하다.
색 손실이 낮은 Gaussian 집합을 곧바로 비행 가능한 지도나 치수 검사 데이터로 내보내지 않는다.
대신 시각화 지도와 충돌 질의 지도를 함께 두고 각각의 근거와 갱신 정책을 명시할 수 있다.
그것은 이 장에서 구현한 기능이 아니라 실제 시스템 설계 시의 통합 제안이다.

대각 근사는 q_diag=100/120.25+100/402.25다.
비대각 교차항 -2·6.75·10·10이 사라져 두 값이 같지 않다.
두 픽셀 방향이 양의 상관을 가지므로 (+,+) 방향의 편차는 독립 가정보다 덜 놀라운 사건이다.
실제 Gaussian 합성에는 이 기하뿐 아니라 불투명도와 앞쪽 Gaussian의 투과율도 필요하다.

## D23. 움직이는 세계에서 지도를 유지한다: 동역학·시간·관성·평가

<a id="d23-1"></a>
### 1. 운용 중 추정의 목표는 “항상 숫자를 출력하기”가 아니다

센서가 정상일 때 위치를 출력하는 것과 환경이 바뀌고 관측이 끊겼을 때 추정의 유효성을 유지하는 것은 다른 문제다.
카메라를 가린 채 예측값을 계속 출력하면 궤적은 매끄러울 수 있지만 관측으로 뒷받침되지 않는다.
따라서 상태에는 pose뿐 아니라 시간, 좌표계, 관측으로 갱신되었는지, 지도 버전, 불확실성 또는 신뢰 상태가 함께 있어야 한다.
이 장은 새 SLAM을 구축하지 않고 그 계약이 왜 필요한지를 작은 모델로 유도한다.

semantic은 점이나 물체가 무엇인지에 관한 의미이고 dynamic은 현재 움직이는지에 관한 운동이다.
차량이라는 의미 라벨은 이동 가능성을 알려주지만 주차된 차량의 순간 속도를 결정하지 않는다.
반대로 의자나 문도 움직일 수 있다.
의미 마스크와 움직임 마스크는 함께 쓸 수 있지만 같은 진실값이 아니다.
배경을 추정하기 위해 pose가 필요하고 pose를 추정하기 위해 정적 배경이 필요한 순환 의존을 명시해야 한다.

입력 계약은 영상, 선택적인 깊이·IMU, 각 센서 타임스탬프, 보정값, 이전 지도다.
출력 계약은 시간 t의 T_wb, 속도 v_w, 상태 유효성, 변경된 지도 레코드다.
여기서 b는 몸체 또는 IMU 좌표이고 카메라 c와 다를 수 있다.
시간은 s, 이동은 m, 속도는 m/s, 각속도는 rad/s로 고정한다.
실제 OXTS 동기화나 비행 제어는 수행하지 않고 합성 시계열에서 수치 영향을 확인한다.

### 2. 정적·동적 혼합이 카메라 이동을 어떻게 치우치게 하는가

카메라가 실제로 t만큼 이동했고, 정적 특징의 측정 y는 t를 지지한다고 하자.
움직이는 물체의 특징은 카메라 운동에 물체 운동 b가 더해진 t+b를 지지한다.
총 N개 중 동적 비율이 p이면 최소제곱 평균의 기대값은 다음과 같다.

```text
E[t_hat] = (1-p)*t + p*(t+b)
         = t + p*b
bias = E[t_hat]-t = p*b
```

b=0.5 m, p=0.4라면 바이어스는 0.2 m다.
동적 특징이 매우 선명하고 많으면 평균의 분산은 작아도 바이어스는 커질 수 있다.
“특징점이 많다”를 곧바로 “위치추정이 정확하다”로 해석하면 이 실패를 놓친다.
강건 추정은 소수 이상치에 효과적일 수 있지만 동적 물체가 다수를 차지하거나 카메라와 비슷한 운동을 하면 정적 모형을 고르지 못할 수 있다.

완벽한 동적 마스크가 있다고 가정하면 바이어스는 제거되지만 남은 정적 점은 (1-p)N개다.
각 정적 측정의 독립 표준편차가 sigma일 때 평균의 표준오차는 sigma/sqrt((1-p)N)이다.
전부 정적일 때와 비교하면 1/sqrt(1-p)배다.
p=0.75이면 표준오차는 두 배가 된다.
잘못된 점을 제거하는 이득과 올바른 기하 정보를 잃는 비용을 함께 보아야 한다.

![D23-1 정적·동적 혼합과 정보 손실](../research/computer-vision-textbook/reconstruction/figures/d23_02_dynamic.png)

그림 D23-1. 왼쪽은 움직이는 점의 추가 이동 0.5 m를 가정한 1차원 혼합 모델의 평균 바이어스이며 세로축 m다. 완벽한 마스크의 0선은 실제 검출기 결과가 아니라 oracle 가정이다. 오른쪽은 남는 정적 비율과 독립 잡음 모델의 상대 표준오차다. 합성 해석식의 시각화이며 실제 동적 SLAM 성능이나 검출 정확도 수치가 아니다.

DynaSLAM은 의미 기반·다중 시점 기하 기반 동적 검출을 SLAM과 연결한 선행 예다.
이 장은 그 네트워크나 배경 복원 코드를 실행하지 않았으며, 위 그림을 DynaSLAM 결과로 부르지 않는다.
후속 방법을 읽을 때는 동적 판단이 의미 사전에서 왔는지, 기하 잔차에서 왔는지, 둘의 결합인지부터 구분한다. [Bescos·Fácil·Civera·Neira, 2018](https://arxiv.org/abs/1806.05620)

### 3. 지도 항목에는 생성·검증·갱신·폐기 상태가 있다

관측 한 번으로 생긴 점과 여러 시점에서 확인된 점을 같은 지위로 저장하면 오정합이 오래 살아남는다.
지도 점 레코드는 최소한 위치, 참조 좌표계, 생성 시각, 마지막 관측 시각, 관측 횟수, 관측 방향 또는 지지 프레임, 품질 상태를 가질 수 있다.
의미 분포나 동적 가설이 있다면 그 버전도 포함한다.
지도 수명주기는 이러한 상태가 바뀌는 규칙이다.

교육용 상태 전이를 다음처럼 정할 수 있다.
새 후보는 아직 공간 위치가 불안정할 수 있고, 다중 시점 검증을 통과하면 활성 상태가 된다.
오래 보이지 않으면 비활성으로 옮기되 지우지는 않을 수 있다.
충분한 반증이 들어오면 폐기하고, 동적 객체로 판정되면 정적 지도와 분리한다.
이 규칙은 실제 운영 시스템에 적용한 결과가 아니라 설계 계약의 예다.

가림 때문에 보이지 않은 것과 실제 사라진 것은 다르다.
카메라 뒤에 있는 벽은 이번 프레임에서 관측되지 않았지만 그 사실이 벽의 소멸 근거는 아니다.
반증을 만들려면 해당 위치가 가시 영역에 있었고, 광선이 그 위치를 통과했으며, 센서가 정상적으로 더 뒤의 표면을 관측했다는 조건이 필요하다.
그래서 관측 횟수만큼이나 관측 가능 기회의 수가 중요하다.

밀집 지도에서 루프 보정이 일어나면 과거 pose로 누적된 TSDF를 어떻게 고칠지도 결정해야 한다.
단순히 현재 카메라 아이콘만 옮기면 과거 표면은 원래 잘못된 위치에 남는다.
원본 깊이와 당시 기여량을 저장해 빼고 다시 적분할 수 있고, 로컬 서브맵을 강체로 옮길 수도 있다.
비가역 평균과 가중치 포화가 사용되었다면 정확한 역적분이 불가능할 수 있다.
저장 공간과 나중의 수정 가능성은 교환관계다.

지도 버전을 붙이면 위치추정 결과가 어느 지도에 대한 좌표인지 추적할 수 있다.
전역 루프 최적화가 좌표를 바꾸는 동안 제어기나 다른 소비자가 이전 좌표를 읽는 문제도 드러난다.
원자적인 스냅샷, 명시적 변환 또는 버전 전환 규칙 없이 두 지도를 섞으면 pose 자체가 수치적으로 정상이어도 의미가 깨진다.
이는 회전 행렬을 더 정밀하게 계산하는 것만으로 해결되지 않는다.

### 4. 장소 검색과 루프 검증은 서로 다른 확률 질문이다

장소 검색 retrieval은 현재 영상과 비슷한 과거 키프레임 후보를 빠르게 찾는다.
키프레임은 모든 프레임을 저장하는 대신 지도·최적화의 대표 관측으로 선택한 프레임이다.
검색 점수는 외관 유사도이고 상대 pose의 기하적 타당성 자체가 아니다.
같은 모양의 복도와 층별 반복 구조가 높은 유사도를 낼 수 있다.

후보 검증은 특징 대응으로 상대 기하를 구하고, 충분한 inlier·공간 분포·양의 깊이·일관된 변환을 확인하는 별도 단계다.
inlier는 선택한 모델의 허용 잔차 안에 들어온 관측이라는 뜻이며 절대적인 진실 라벨이 아니다.
같은 잘못된 반복 무늬에 몰린 대응은 모두 작게 맞을 수 있다.
점 개수와 함께 영상의 어느 영역에 분포하는지, 깊이와 법선이 다양하게 제약하는지도 본다.

루프 후보의 사전확률을 0.01, 검증기의 참양성률을 0.9, 비루프에서 통과할 확률을 0.01이라 하자.
통과했다는 사실만으로 진짜 루프 확률이 90%는 아니다.
베이즈 계산은 다음과 같다.

```text
P(loop | pass)
 = P(pass | loop) P(loop)
   / [P(pass | loop)P(loop) + P(pass | not loop)P(not loop)]
 = 0.9*0.01 / (0.9*0.01 + 0.01*0.99)
 = 0.009 / 0.0189
 ≈ 0.47619
```

낮은 사전확률의 후보를 많이 시험할수록 작은 거짓 통과율도 중요해진다.
이 계산은 실제 루프 검증기의 측정 성능이 아니라 base-rate 효과를 설명하기 위해 정한 수치다.
시간적 일관성, 다중 후보의 상호 일관성, 최적화 후 잔차 확인 같은 추가 방어를 검토할 이유를 준다.
그러나 같은 증거를 여러 번 시험한 결과를 독립 확률처럼 곱해서는 안 된다.

검증된 상대 변환을 pose graph에 넣는 순간에는 그 제약의 좌표 방향과 공분산도 계약에 포함된다.
T_ij와 T_ji를 혼동하면 올바른 장소를 찾아도 잘못된 제약을 넣는다.
“loop detected” 로그 한 줄을 완성된 전역 최적화와 동일시하지 않는다.
지도 보정이 실제로 적용되었는지, 기존 궤적과 밀집 표면이 어떤 버전으로 바뀌었는지까지 따로 확인한다.

<a id="d23-5"></a>
### 5. 시간 보정은 공간 보정만큼 기하학적이다

카메라 시각 t_c와 IMU 시각 t_i 사이에 t_i=t_c+tau라는 오프셋을 두자.
tau의 부호를 먼저 선언해야 한다.
이 장에서 tau>0이면 카메라 시각 숫자에 양수를 더한 IMU 시각을 대응시킨다.
이 선언 없이 “20 ms 보정”만 기록하면 적용 방향을 알 수 없다.

각속도 omega가 일정하고 시간차가 작으면 회전 오차는 delta_theta≈omega tau다.
광축 가까운 점의 픽셀 이동은 대략 f delta_theta다.
f=500 px, omega=0.5 rad/s, tau=0.02 s라면 500·0.5·0.02=5 px다.
움직임이 빠른 구간에서만 큰 재투영 오차가 나타나는 원인으로 시간 오프셋을 의심할 수 있다.
그러나 이 패턴 하나만으로 시간 오프셋이 원인이라고 확정할 수는 없다.

공간 외부 보정 T_cb의 회전 오차와 시간 오프셋은 특정 운동에서 비슷하게 보일 수 있다.
계속 같은 각속도로 회전하면 일정한 시간 오프셋이 일정한 회전 오차처럼 작용한다.
운동이 다양하지 않으면 둘을 구분할 관측이 부족하다.
보정 실험에서는 단순히 많은 프레임을 모으는 것보다 여러 축의 회전과 적절한 가속 변화가 어떤 파라미터를 자극하는지를 생각해야 한다.
여기서는 실제 센서 보정 동작을 수행하지 않았다.

타임스탬프가 노출 시작·중간·종료 중 어느 시각인지도 알아야 한다.
노출 시간이 길어지면 하나의 이미지가 단일 순간을 나타낸다는 가정이 약해진다.
수신 시각은 센서 측정 시각과 같지 않고 통신 지연의 변동을 포함할 수 있다.
시간 동기화는 메시지의 순서를 정렬하는 일만이 아니라 물리적 측정 순간을 일치시키는 일이다.

<a id="d23-6"></a>
### 6. IMU가 측정하는 specific force와 중력을 분리한다

IMU는 Inertial Measurement Unit, 관성측정장치다.
자이로는 각속도를 측정하고 가속도계는 중력을 제외한 비중력 specific force를 센서 좌표에서 측정하는 모델로 쓴다.
몸체에서 세계로 가는 회전을 R_wb, 세계 선형 가속도를 a_w, 중력을 g_w라 하면 측정 모델은 다음과 같다.

```text
omega_m = omega_true + b_g + n_g
a_m = R_wb^T (a_w - g_w) + b_a + n_a

따라서
a_w = R_wb (a_m - b_a - n_a) + g_w
```

b_g는 rad/s 단위 자이로 바이어스, b_a는 m/s² 단위 가속도 바이어스다.
n_g,n_a는 잡음이며 시간 상관과 연속·이산 잡음 밀도 구분이 실제 모델에서는 필요하다.
세계 z가 위이고 g_w=[0,0,-9.81] m/s², 정지한 센서가 세계와 정렬되어 있으면 a_w=0이다.
이때 이상적 a_m=[0,0,9.81]이다.
가속도계 값이 0이 아니어도 정지일 수 있다는 뜻이다.

가속도계 값을 바로 두 번 적분하면 정지한 센서가 위로 가속하는 가짜 궤적이 생긴다.
먼저 회전으로 세계 방향을 맞추고 중력을 더해 상쇄해야 한다.
중력 방향이 잘못 추정되면 작은 기울기 오차도 수평 가속도로 누출된다.
작은 기울기 epsilon에서 누출 크기는 대략 g epsilon이다.
epsilon=0.01 rad이면 약 0.0981 m/s²이고, 1 s 동안 일정하면 위치 오차는 약 0.04905 m다.

바이어스는 무작위 잡음처럼 표본 평균으로 항상 사라지지 않는다.
일정 가속도 바이어스 b가 t초 동안 남으면 속도 오차는 bt, 위치 오차는 0.5bt²다.
따라서 짧은 구간의 IMU가 시각 실패를 보완할 수 있다는 것과 장시간 관성 단독 위치가 안정적이라는 것은 다른 주장이다.
이 장의 수치 모델은 바이어스를 0으로 놓은 경우와 그 민감도만 계산한다.

<a id="d23-7"></a>
### 7. 사전적분: 여러 IMU 표본을 초기 좌표의 상대 제약으로 묶는다

VIO는 Visual-Inertial Odometry, 시각·관성 오도메트리다.
사전적분 preintegration은 두 키프레임 사이의 많은 IMU 측정을 상대 회전·속도·위치 항으로 요약한다.
Forster 등의 연구는 회전군의 구조와 바이어스 보정을 포함해 이를 체계화했다.
아래는 그 완전한 공분산·야코비안 구현이 아니라 이산 적분의 핵심을 드러내는 교육용 유도다. [Forster·Carlone·Dellaert·Scaramuzza, TRO 2017; preprint 2015](https://arxiv.org/abs/1512.02363)

초기 시각 i의 몸체 좌표를 기준으로 Delta_R, Delta_v, Delta_p를 누적한다.
초기값은 I,0,0이다.
구간 dt 동안 각속도와 가속도가 일정하다고 근사하고 구간 시작 회전을 사용한다.
회전 증가 Exp(omega dt)는 회전벡터를 회전행렬로 보내는 지수맵이며 SciPy Rotation으로 계산한다.

```text
Delta_p_next = Delta_p + Delta_v dt
               + 0.5 Delta_R (a_m-b_a) dt^2
Delta_v_next = Delta_v + Delta_R (a_m-b_a) dt
Delta_R_next = Delta_R Exp((omega_m-b_g) dt)
```

위치 갱신이 기존 Delta_v와 기존 Delta_R을 사용한다는 순서가 중요하다.
먼저 속도를 갱신한 뒤 그 새 속도를 같은 위치 식에 넣으면 일정 가속도에서도 오차가 생긴다.
dt=0.1 s, a=[1,0,0] m/s², 회전 0인 두 표본을 보자.

```text
초기: p0=0, v0=0
1단계: p1=0+0*0.1+0.5*1*0.1^2=0.005 m
       v1=0+1*0.1=0.1 m/s
2단계: p2=0.005+0.1*0.1+0.005=0.020 m
       v2=0.1+0.1=0.2 m/s
닫힌 해: 0.5*a*(0.2)^2=0.020 m
```

이 상대항을 세계 상태로 옮기면 중력과 초기 속도가 다시 등장한다.

```text
R_wb_j = R_wb_i Delta_R_ij
v_w_j = v_w_i + g_w Delta_t + R_wb_i Delta_v_ij
p_w_j = p_w_i + v_w_i Delta_t + 0.5 g_w Delta_t^2
        + R_wb_i Delta_p_ij
```

Delta_p는 세계 위치 자체가 아니고 초기 몸체 좌표에서 중력을 제외하고 누적한 항이다.
정지 센서의 a_m=[0,0,9.81]을 0.2 s 적분하면 Delta_p_z=0.1962 m다.
세계 식의 0.5g Delta_t²=-0.1962 m와 더해져 p 변화는 0이 된다.
중력을 적분 안에서 이미 뺐는데 세계 식에서 또 더하면 중복 보정이다.

<a id="d23-8"></a>
### 8. 회전하는 동안 가속도를 그대로 더하면 다른 운동이 된다

몸체 x축 방향 specific force가 일정해도 몸체가 회전하면 세계에서의 방향은 계속 달라진다.
자이로 각속도가 z축 0.2 rad/s, 몸체 가속도가 [1,0,0] m/s²이고 수평면만 보자.
dt=0.1 s, 100단계를 초기 좌표에 적분하면 총 10 s다.
이산 회전 보정 모델의 최종 Delta_p는 [35.6739939,26.9133882,0] m였다.
회전을 무시하면 [50,0,0] m가 된다.
둘의 차이는 잡음이 아니라 좌표계 처리의 차이다.

연속적인 이상화 모델도 검산 기준으로 만들 수 있다.
각속도 w가 일정하면 초기 좌표 가속도는 [cos(wt),sin(wt)]다.
초기 속도 0에서 각 성분을 한 번, 다시 한 번 적분하면 된다.

```text
v_x(t) = integral_0^t cos(ws) ds = sin(wt)/w
v_y(t) = integral_0^t sin(ws) ds = (1-cos(wt))/w

p_x(t) = integral_0^t sin(ws)/w ds = (1-cos(wt))/w^2
p_y(t) = integral_0^t (1-cos(ws))/w ds
       = t/w - sin(wt)/w^2
```

구간 시작 회전을 고정한 이산 모델은 이 연속 해와 완전히 같지 않다.
dt를 줄였을 때 연속 해로 가까워지는지 검사하면 적분 순서 오류와 이산화 오차를 구별할 수 있다.
회전이 빠른데 큰 dt를 쓰면 단순한 시작점 적분의 한계가 커진다.
실제 사전적분에서는 중간점 방법, 잡음 전파, 바이어스 보정 등이 더 필요하다.

![D23-2 관성 회전 처리와 시간 오프셋](../research/computer-vision-textbook/reconstruction/figures/d23_01_timing.png)

그림 D23-2. 왼쪽은 합성 10초 시계열의 수평 사전적분 궤적이며 축은 m다. 파선은 몸체 가속도를 회전 없이 누적한 잘못된 좌표 처리다. 오른쪽은 초점거리 500 px, 각속도 0.5 rad/s의 1차 시간 오프셋 영향이며 가로축 ms, 세로축 px다. 실제 차량 IMU, OXTS 정렬 또는 완전한 VIO 결과가 아니다.

바이어스 보정도 작은 예로 이해할 수 있다.
회전이 없고 일정 b_a를 Delta_t 동안 잘못 남겼다면 Delta_v의 미분은 -Delta_t I, Delta_p의 미분은 -0.5Delta_t² I다.
0.2 s에서 바이어스 추정이 +0.01 m/s² 바뀌면 Delta_v는 -0.002 m/s, Delta_p는 -0.0002 m 보정된다.
회전이 있으면 각 시각의 R이 가중되어 단순 스칼라 공식으로 끝나지 않는다.
최적화 중 바이어스가 크게 바뀌면 1차 보정만으로 충분하지 않을 수 있으므로 재적분 기준도 필요하다.

<a id="d23-9"></a>
### 9. 롤링셔터·저조도·먼지: 잔차가 커지는 원인을 분해한다

Rolling shutter는 영상 행마다 노출 시각이 다른 센서 읽기 방식이다.
첫 행 시각 t_0, 전체 행 읽기 시간 t_read, 영상 높이 H라면 교육용 선형 모델은 t(v)=t_0+v t_read/(H-1)이다.
같은 영상 안에서 위·아래 행이 서로 다른 pose를 가진다.
전역셔터 모델의 단일 T로 모든 점을 설명하면 회전 중 구조가 휘거나 기울어 보일 수 있다.

읽기 시간 20 ms, 각속도 0.5 rad/s라면 위아래 회전 차이는 0.01 rad다.
초점거리 500 px에서 광축 근처의 차이는 약 5 px다.
이 값이 모든 픽셀의 정확한 변위라는 뜻은 아니다.
원근 위치와 회전축에 따른 실제 optical flow 야코비안이 필요하며, 여기 계산은 규모를 파악하는 1차 예다.

저조도에서는 노출 시간을 늘리거나 증폭을 높이는 선택이 생긴다.
노출 증가에 따른 흐림은 한 순간의 영상이 아니라 시간 적분된 영상이라는 모델 변화를 만든다.
신호가 약할 때는 광자 잡음과 읽기 잡음의 상대적 영향도 달라진다.
단순히 모든 영상에 같은 분산의 Gaussian 잡음을 더하는 합성 실험은 이 현상을 전부 재현하지 않는다.
따라서 저조도 강건성을 주장하려면 실제 노출·감마·게인·흐림·센서 종류를 기록해야 한다.

먼지나 안개는 가시성을 낮추고 영상 대비를 줄이며 근거리 산란을 만들 수 있다.
깊이 센서에서는 무효값과 가짜 반사가 늘어날 수 있지만 구체적인 정도는 센서 방식과 환경에 달려 있다.
본 연구는 이런 환경을 측정하지 않았으므로 실제 성능 감소율을 제시하지 않는다.
실험 설계에서는 무효 깊이 비율, 포화 비율, 특징 분포, 잔차, 시간지연을 함께 기록해 원인 후보를 분리한다.

도메인 이동 domain shift는 훈련·개발 때의 관측 분포와 운용 분포가 달라지는 것이다.
실내의 짧은 거리 RGB-D에서 잘 동작한 게이트가 실외의 긴 거리 스테레오에 그대로 적합하지 않을 수 있다.
동일한 “10 cm” 잔차도 센서 거리 잡음에 비해 작거나 클 수 있다.
정규화 잔차와 거리별 분석이 필요한 이유다.

<a id="d23-10"></a>
### 10. 불확실성과 실패 상태는 숫자 하나의 신뢰도로 대체하지 않는다

추정 공분산 P가 있다는 것은 오류가 실제로 그 분포를 따른다는 보장이 아니다.
선형화, 대응 고정, 독립 잡음, 정적 장면의 가정이 깨지면 P가 지나치게 작을 수 있다.
오차 e에 대한 normalized estimation error squared, NEES는 e^T P^-1 e다.
이 값은 단위가 상쇄되어 무차원이지만 GT와 올바른 상태 차원·게이지 처리가 필요하다.
본 실험은 실제 SLAM 공분산과 GT를 수집하지 않았으므로 NEES 성능을 보고하지 않는다.

측정 잔차 r의 innovation 공분산 S를 사용한 정규화 값 r^T S^-1 r도 비슷한 역할을 한다.
그러나 같은 관측으로 pose를 최적화한 뒤의 잔차를 독립 예측 오차처럼 평가하면 낙관적으로 보일 수 있다.
학습과 시험의 구분이 통계 모델 안에서도 필요하다.
프레임 수보다 독립적인 정보량, 검증에 사용하지 않은 관측의 역할이 중요하다.

실패 상태는 예를 들어 tracking, degraded, lost, relocalizing처럼 구분할 수 있다.
degraded는 pose 숫자가 존재하지만 관측 조건이나 불확실성이 정상 범위를 벗어났다는 의미다.
lost에서는 관측 기반 pose를 유효하다고 계속 광고하지 않는다.
relocalizing은 기존 지도에 다시 연결하는 중이며 검색 후보와 검증된 연결을 구분한다.
이 명칭은 교육용 인터페이스 예이고 실제 저장소에 추가한 상태 머신이 아니다.

소비자에게 전달할 때는 마지막 정상 pose를 새 타임스탬프로 재포장하지 않는다.
오래된 관측임을 숨기면 정적 상황에서는 그럴듯하지만 동적 상황에서 위치가 뒤처진다.
pose의 물리적 시각과 결과가 준비된 시각을 함께 보관하면 추정 정확도와 시스템 지연을 나누어 분석할 수 있다.
다음 장의 대기열 실험은 이 두 시간을 섞었을 때 평균 처리시간이 왜 충분하지 않은지 보여준다.

<a id="d23-11"></a>
### 11. ATE·RPE·KITTI 점수는 서로 다른 오차 함수다

ATE는 Absolute Trajectory Error, 절대 궤적 오차이며 공통 좌표로 정렬한 추정 위치와 참 위치를 비교하는 데 자주 쓰인다.
여기서는 위치 ATE의 root mean square error, RMSE를 명시적으로 정의한다.
정렬 S를 한 번 고른 뒤 각 시각의 위치차 e_i=S(p_hat_i)-p_i를 계산하고 sqrt(mean||e_i||²)를 구한다.
RPE는 Relative Pose Error로 두 시각 사이의 상대 운동 오차를 본다.

```text
참 상대 pose: Delta_T_ij = inverse(T_wi) T_wj
추정 상대 pose: Delta_T_hat_ij = inverse(T_hat_wi) T_hat_wj
상대 오류: E_ij = inverse(Delta_T_ij) Delta_T_hat_ij

병진 오류: ||translation(E_ij)|| [m]
회전 오류: acos(clip((trace(R_E)-1)/2, -1, 1)) [rad]
```

회전 acos의 입력을 [-1,1]로 자르는 것은 부동소수점 오차 방어다.
원래 잘못된 회전행렬을 정상으로 만드는 보정은 아니다.
R^T R≈I, det(R)≈1인지 별도로 검사한다.
RPE의 간격을 한 프레임, 1초, 일정 이동거리 중 무엇으로 잡는지에 따라 질문이 달라진다.

SE(3) 정렬은 하나의 회전과 이동만 허용한다.
Sim(3) 정렬은 여기에 균일 스케일까지 허용한다.
단안 궤적의 게이지를 비교하기 위해 Sim(3)를 쓰는 것과 스테레오의 잘못된 metric scale을 GT로 고쳐 성능을 보고하는 것은 다른 실험이다.
정렬은 평가의 일부이므로 결과 표에서 감추면 안 된다.

합성 참 궤적에 1.2배 스케일, 25도 회전, [5,-2,1] m 이동을 넣었다.
정렬 전 RMSE는 약 5.65427 m, SE(3) 정렬 후는 약 0.515908 m, Sim(3) 후는 부동소수점 수준인 약 4.47e-15 m였다.
Sim(3)의 스케일은 1/1.2≈0.833333이다.
이 실험에는 잡음이 없고, GT를 사용해 허용된 게이지를 정확히 제거한 것이다.
Sim(3) 값이 작다고 스케일 추정이 정확했다고 결론 내릴 수 없다.

![D23-3 정렬 정책이 바꾸는 궤적 평가](../research/computer-vision-textbook/reconstruction/figures/d23_03_alignment.png)

그림 D23-3. 합성 타원 궤적과 20% 스케일 오차를 가진 추정의 정렬 실험이다. 왼쪽은 SE(3) 후에도 남는 크기 차이, 축은 m다. 오른쪽은 정렬 없음·SE(3)·Sim(3)의 위치 RMSE m다. GT를 사용한 oracle 정렬이며 실제 VO 또는 KITTI 점수가 아니다. Sim(3)의 거의 0인 막대는 스케일을 평가에서 제거한 결과다.

KITTI 공식 odometry는 시퀀스 내 이동거리 구간의 병진·회전 오류를 평가하는 별도 규약이다.
짧은 합성 궤적의 ATE나 한 프레임 StereoSGBM 결과를 KITTI 공식 점수라고 부르지 않는다.
공식 평가는 파라미터를 시퀀스마다 수동 조정하지 않는 조건도 명시한다.
실제 비교를 시작할 때는 공식 개발 키트, 구간 길이, 정렬 허용 여부, 실패 시퀀스 처리를 먼저 고정한다. [KITTI 공식 평가](https://www.cvlibs.net/datasets/kitti/eval_odometry.php)

### 12. 풀이가 있는 연습문제: 시간과 좌표의 반례

**문제 D23-A. 동적 마스크의 이득과 비용을 함께 계산하라.**
N=100, sigma=0.02 m, 동적 비율 p=0.75, 추가 운동 b=0.4 m다.
모두 평균했을 때 바이어스와 완벽한 마스크 후 표준오차를 구하라.

**풀이.** 바이어스는 p b=0.3 m다.
남은 정적 점은 25개이므로 표준오차는 0.02/sqrt25=0.004 m다.
처음부터 100개가 모두 정적이면 0.002 m이므로 마스크 후 정보량은 줄었다.
하지만 0.3 m의 체계적 오차를 줄이는 이득과 0.002 m의 표준오차 증가를 같은 종류의 숫자로 더하면 안 된다.
전체 평균제곱오차는 바이어스²와 분산의 합으로 비교할 수 있으며 가정이 맞는지 먼저 확인한다.

**문제 D23-B. 정지 IMU의 사전적분을 세계 위치로 변환하라.**
dt=0.1 s인 두 관측 a_m=[0,0,9.81], omega=0, 초기 속도 0, 초기 회전 I다.
Delta_v, Delta_p와 세계 위치 변화를 계산하라.

**풀이.** Delta_v_z=9.81·0.2=1.962 m/s, Delta_p_z=0.5·9.81·0.2²=0.1962 m다.
세계 속도는 -9.81·0.2+1.962=0이고 세계 위치는 -0.1962+0.1962=0이다.
Delta_p를 그 자체로 최종 위치라고 읽으면 정지 센서가 움직인다고 잘못 판단한다.
`test_16_gravity`가 이 상쇄를 확인한다.

**문제 D23-C. 바이어스와 시간 오프셋의 단위를 점검하라.**
가속도 바이어스 0.02 m/s²를 3 s 동안 무시했고, 동시에 초점거리 500 px·각속도 0.5 rad/s에서 20 ms 시간 오차가 있다.
각 오차의 1차 규모를 구하라.

**풀이.** 바이어스의 위치 효과는 0.5·0.02·3²=0.09 m다.
시간 오차의 영상 효과는 500·0.5·0.020=5 px다.
0.09와 5를 직접 비교할 수 없는 이유는 단위와 관측 공간이 다르기 때문이다.
공통 잔차 공간으로 옮기려면 깊이와 투영 야코비안이 필요하다.
바이어스도 회전 상태에 따라 실제 세계 위치 영향이 달라질 수 있다.

**문제 D23-D. 좋은 RPE와 나쁜 ATE가 함께 가능한가?**
1초마다 실제 1 m 전진하는 경로를 추정기가 매번 1.01 m 전진한다고 보고한다.
100초 뒤 시작점 기준 위치 오차와 1초 RPE를 구하라.

**풀이.** 1초 상대 병진 오류는 0.01 m다.
시작점을 맞춘 상태의 100초 누적 위치 오차는 1 m다.
각 구간 오류가 작은 것과 전역 일관성이 좋은 것은 같지 않다.
여기에 전체 Sim(3)를 허용하면 일정 스케일 오차를 제거할 수 있으므로 평가 정책이 또 달라진다.
루프 보정이 끝점 오류를 줄여도 중간 구간 RPE나 온라인 지연이 자동으로 좋아지는 것은 아니다.

## D24. 재현 가능한 비전 연구: 가설·검증·실패·배포 경계

<a id="d24-1"></a>
### 1. 실험의 산출물은 그림이 아니라 반증 가능한 주장이다

“강건 정합이 더 좋다”는 문장은 실험 명세가 아니다.
좋다는 기준, 입력 분포, 비교 대상, 실패 처리, 시간과 메모리의 제약을 정해야 한다.
이 장에서 검증한 좁은 주장은 “동일한 400개 법선 방향 관측에 20%의 +0.4 m 이상치를 넣었을 때, Huber 전이값 0.01 m가 평균보다 참 이동 0.04 m에 가까운 추정을 만든다”이다.
이 문장은 재실행으로 확인하거나 반증할 수 있고, 전체 ICP나 실제 차량 일반화로 범위를 부풀리지 않는다.

실험 계약에는 관측 단위와 평가 단위가 모두 필요하다.
픽셀을 처리해도 평가 단위는 프레임일 수 있고, 프레임으로 오차를 계산해도 독립적인 통계 단위는 장면일 수 있다.
한 시퀀스에서 연속된 천 프레임은 천 개의 독립 환경이 아니다.
실험이 답하는 모집단을 정하지 않으면 정교한 평균과 신뢰구간도 해석할 수 없다.

이 장의 목표는 두 층이다.
첫째는 수식·코드·배열·그림의 내부 일치 여부다.
둘째는 이 작은 일치로 어디까지 주장할 수 있는지의 경계를 정하는 일이다.
전자에 성공했다고 실제 배포 안전성이나 미관측 도메인 성능이 증명되지는 않는다.
따라서 잘 통과한 테스트와 아직 필요한 실험을 같은 페이지에 남긴다.

### 2. 재현성 명세: 시드 외에 무엇을 고정해야 하는가

난수 시드 seed는 난수열의 시작 상태를 정한다.
하지만 시드만 같으면 모든 플랫폼에서 완전히 동일한 결과가 나온다는 뜻은 아니다.
라이브러리 버전, BLAS 구현, 스레드 수, 연산 순서, 부동소수점 정밀도, GPU의 비결정성 등이 결과와 실행시간에 영향을 줄 수 있다.
이 실험은 CPU의 NumPy·SciPy·OpenCV를 사용하고, 수치 허용오차를 둔 검사를 수행한다.
GPU 학습이나 대형 모델 다운로드는 없다.

설정 파일 `configs/default.json`은 시드 21024, DPI 190, 그림 폭 7 inch, TSDF 절단 0.12 m, 스테레오 게이트와 IMU 간격 등을 기록한다.
`src/run.py`는 실행 당시 의존성 버전·Python·플랫폼·Git 커밋·실행시간을 `artifacts/manifest.json`에 저장한다.
원본 코드와 설정, 실제 입력 영상 두 장과 보정 파일의 SHA256을 함께 저장한다.
SHA256은 입력 바이트가 달라졌는지 확인하기 위한 암호학적 해시이지 데이터의 진실성을 인증하는 증명서는 아니다.

커밋 해시만으로 공유 작업 트리의 실행 소스를 완전히 설명하지 못할 수 있다.
커밋되지 않은 연구 파일도 실행되므로 source hash가 별도로 필요하다.
코드가 같은데 설정이 달라졌거나 입력 영상이 바뀌어도 결과는 달라진다.
따라서 실험 식별자는 코드·설정·데이터·환경의 묶음으로 생각하는 것이 낫다.
이 연구의 기준 커밋은 `75f7140d0dec421971c9b13d088e1967ebe124d5`이며 실제 manifest에는 실행 당시 값이 기록된다.

재현 명령은 저장소 루트에서 다음 두 줄이다.

```text
research/20261031_vo-lo-study/.venv/bin/python research/computer-vision-textbook/reconstruction/src/run.py
research/20261031_vo-lo-study/.venv/bin/python research/computer-vision-textbook/reconstruction/src/test_numerics.py
```

첫 명령은 PNG와 NPZ·JSON을 다시 만든다.
두 번째 명령은 작은 수치 계약을 검사한다.
NPZ는 NumPy 배열 묶음이며 계산 중간값을 압축 저장한다.
그림만 있으면 색상 범위나 표본 선택을 바꾸어 재검사하기 어렵지만 배열이 있으면 같은 계산에서 다른 요약을 만들 수 있다.
산출물은 연구 폴더의 ignore 규칙으로 버전 관리에서 제외하며, 정본 문서와 렌더 도구를 이 부분 작업에서 수정하지 않는다.

수치 단위·성질 검사 42개가 통과했고, 별도 산출물 검사는 4개 장·54개 고유 앵커·16개 풀이·14개 PNG·5개 NPZ 모듈의 유한값과 파일 해시를 확인한다.
그림 폭은 모두 1,330 px, 저장 해상도는 190 dpi로 7 inch다. 원고의 이미지 링크는 `docs/` 기준 상대경로이며, 통합 담당자가 정본에 옮길 때 링크를 연구 notes 기준으로 다시 바꾸지 않는다.
이 수치는 정본 PDF 페이지수나 통합 렌더 검사를 완료했다는 뜻은 아니다. 이 부분 작업은 원고와 근거의 인계에서 끝난다.

### 3. 데이터셋 분류를 센서·운동·정답·환경 축으로 한다

데이터셋 이름을 외우는 것보다 어떤 가정을 시험할 수 있는지를 분류하는 것이 유용하다.
센서 축에는 단안·스테레오·RGB-D·LiDAR·IMU가 있다.
운동 축에는 차량의 대체로 평면적인 이동, 손에 든 카메라, 비행체의 다축 회전 등이 있다.
정답 축에는 위치만, 전체 pose, 깊이, 의미, 동작 명령, 접촉 상태가 있다.
환경 축에는 실내·실외, 조명 변화, 동적 물체, 악천후, 반복 구조가 있다.

| 데이터 유형 | 가능한 질문 | 남는 한계 |
|---|---|---|
| 실제 차량 스테레오 | 시차·원거리 기하·차량 궤적 | 실내 RGB-D·행동 학습으로 직접 일반화하지 못함 |
| 시간 보정된 시각·IMU | VIO의 시간·관성 모델 | 정답이 존재하는 구간과 센서 특성을 확인해야 함 |
| 합성 다중 센서 | 정확한 기하로 원인별 ablation | 실제 센서·재료·환경의 분포 차이 |
| 실제 RGB-D 물체/실내 | 근거리 깊이와 표면 융합 | 반사·무응답·측정 범위와 외부 보정 |
| 로봇 행동 시연 | 영상·언어에서 행동 예측 | 동작 단위·몸체·안전 제약·실패 기록이 추가 필요 |

KITTI 공식 odometry는 실제 스테레오 시퀀스와 궤적 평가의 구조를 제공한다.
이번 실험은 그중 00의 한 쌍만 사용하므로 궤적 평가를 수행한 것은 아니다. [KITTI 공식](https://www.cvlibs.net/datasets/kitti/eval_odometry.php)
Schubert 등의 TUM VI는 시간 동기화된 영상·IMU와 평가용 정답을 제공하는 VIO 데이터셋이다.
논문은 정답의 확보 구간도 명시하므로 모든 경로에서 같은 종류의 정답이 있다고 가정하지 않는다. [Schubert·Goll·Demmel·Usenko·Stückler·Cremers, 2018](https://arxiv.org/abs/1804.06120)

Wang 등의 TartanAir는 합성 환경을 사용해 시각 SLAM의 어려운 조건을 연구하는 데이터셋이다.
합성이라는 이유로 쓸모없거나, 정답이 정확하다는 이유로 실제를 완전히 대체한다고 보지 않는다.
통제 가능한 원인 실험과 실제 센서 검증은 서로 보완적이다. [Wang 외, 2020 원문](https://arxiv.org/abs/2003.14338)

데이터 선택은 최소한 “내가 깨뜨리려는 가정이 이 데이터에 있는가”를 묻는 과정이다.
시간 오프셋을 시험하려는데 타임스탬프의 의미가 불명확한 자료를 쓰면 원인을 분리하기 어렵다.
동적 마스크를 시험하면서 정적 장면만 사용하면 삭제된 정보의 비용만 보이고 본래 목적을 평가하지 못한다.
모델이 없는 것과 평가 자료가 없는 것은 서로 다른 연구 병목이다.

<a id="d24-4"></a>
### 4. 데이터 누출: GT는 평가자이지 몰래 들어오는 센서가 아니다

GT는 Ground Truth, 평가에 쓰는 참조값이다.
실제로는 참조 센서에도 오차가 있으므로 물리적으로 완전한 진실이라는 뜻으로 과신하지 않는다.
입력과 평가를 분리하려면 파일 접근 수준에서도 어떤 값이 추정기에 들어가는지 기록해야 한다.
GT로 프레임마다 스케일을 맞춘 뒤 “단안 metric odometry”라고 보고하면 추정기에 정답이 누출된 것이다.

평가 시 하나의 전역 Sim(3)로 게이지를 맞추는 것은 선언된 평가 정책일 수 있다.
하지만 구간별·프레임별로 다른 정답 보정을 하면 실제 드리프트까지 지워질 수 있다.
허용할 정렬을 먼저 고정하고, 정렬 전후 수치와 보정 파라미터를 함께 남긴다.
본문 D23의 0.833333 스케일은 GT로 구한 oracle 값이며 시스템이 센서만으로 알아낸 값이 아니다.

훈련·검증·시험 분할에서도 연속 프레임 누출을 조심한다.
동일한 장소의 거의 같은 프레임이 학습과 시험에 나뉘면 새 장소 일반화를 평가한다고 말하기 어렵다.
모든 프레임을 무작위로 섞는 분할은 시계열과 장소 상관을 파괴한다.
장면·경로·날짜·장치 중 연구 질문에 맞는 단위를 통째로 분리해야 한다.

하이퍼파라미터 선택에 사용한 시험 결과도 정보다.
시험 시퀀스에서 가장 잘 나온 전이값을 고른 뒤 같은 시퀀스 점수를 최종 일반화 성능으로 제시하면 선택 편향이 생긴다.
“학습하지 않는 고전 알고리즘”도 임계값을 시험 데이터에 맞추면 과적합할 수 있다.
최종 평가 전에 설정을 동결하고 선택에 사용한 자료를 따로 표시한다.

<a id="d24-5"></a>
### 5. 연속 프레임을 독립 표본으로 세면 불확실성이 작아 보인다

장면마다 공통 오차 b_s가 있고 프레임별 작은 잡음 epsilon_si가 있다고 하자.
관측 y_si=b_s+epsilon_si다.
b_s는 장면 특성 때문에 생기는 오차이며 같은 장면의 모든 프레임이 공유한다.
장면당 m개, 총 S장면이면 전체 프레임 수는 N=Sm이다.

분산을 직접 전개하면 평균의 불확실성에서 상관이 어떻게 작용하는지 보인다.

```text
y_bar = (1/S) sum_s b_s + (1/(Sm)) sum_s sum_i epsilon_si
Var(y_bar) = sigma_b^2/S + sigma_epsilon^2/(Sm)

잘못된 프레임 독립 근사:
Var_iid(y_bar) ≈ (sigma_b^2 + sigma_epsilon^2)/(Sm)
```

sigma_b²가 지배적이면 올바른 분산은 프레임 독립 근사보다 대략 m배 크다.
표준오차는 sqrt(m)배가 된다.
같은 장면에서 더 촘촘한 프레임을 뽑는 것만으로 새로운 환경에 대한 불확실성이 계속 줄어들지는 않는다.
새 장면을 더 모으는 것과 같은 장면의 프레임을 더 모으는 것의 가치가 다르다.

실험에서는 20장면, 장면당 20프레임, 장면 공통 표준편차 1 m, 프레임 잡음 표준편차 0.1 m인 합성 오차를 만들었다.
프레임을 독립으로 재표집한 평균의 표준편차는 약 0.05246 m였다.
장면의 공통 오차를 장면 단위로 재표집한 평균은 약 0.22848 m였다.
후자는 장면 공통항의 bootstrap이며 프레임 잡음까지 계층적으로 다시 뽑는 완전한 hierarchical bootstrap은 아니다.
이 구분을 적어 두어 서로 다른 생성 모형의 숫자를 과도하게 해석하지 않는다.

![D24-1 장면 상관과 재표집 단위](../research/computer-vision-textbook/reconstruction/figures/d24_02_bias.png)

그림 D24-1. 왼쪽은 장면마다 공통 오차를 가진 합성 400프레임, 세로축 m다. 오른쪽은 1,000회 재표집한 평균의 분포로 프레임 독립 가정과 장면 공통항 재표집을 비교한다. 가로축 평균 오차 m, 세로축 빈도다. 실제 SLAM 신뢰구간이 아니며 “프레임 수=독립 실험 수”라는 잘못된 가정의 영향을 보여주는 자체 생성 실험이다.

bootstrap은 표본을 다시 뽑아 통계량의 변동을 보는 방법이다.
원자료가 대표적이지 않으면 재표집을 많이 해도 모집단 편향을 해결하지 못한다.
재표집 횟수 1,000을 독립 장면 1,000개로 세어서도 안 된다.
실제 비교에서는 시퀀스별 결과를 먼저 보여주고, 어떤 단위로 불확실성을 계산했는지 적는다.

<a id="d24-6"></a>
### 6. Ablation은 부품을 빼는 행위보다 인과 질문의 설계다

ablation은 한 요소의 기여를 분리하기 위해 설정을 바꾸어 비교하는 실험이다.
Huber 손실의 효과를 보려면 데이터·초기값·종료조건·대응점·기타 게이트를 같게 두고 손실만 바꾼다.
강건 손실과 함께 점 선택과 반복 횟수까지 바꾸면 좋아진 원인을 하나로 귀속할 수 없다.
복합 시스템에서는 한 요소를 제거하면 다른 요소의 입력 분포도 바뀌므로 결과의 해석을 신중히 해야 한다.

이 연구의 paired ablation은 정확히 같은 400개 관측을 사용한다.
평균의 절대 오차는 0.0800614 m, Huber 0.01의 절대 오차는 0.0026860 m였다.
이 차이가 한 오염 시나리오에 대한 증거라는 점을 강조한다.
이상치 비율, 이상치 방향, 작은 잡음 크기, 대응 오정합 구조를 바꾸면 결과가 달라질 수 있다.

![D24-2 Huber 전이값의 민감도와 paired 비교](../research/computer-vision-textbook/reconstruction/figures/d24_03_ablation.png)

그림 D24-2. 왼쪽은 동일한 합성 오염 관측에서 Huber 전이값을 0.005–0.5 m로 바꾼 절대 이동 오차이며 두 축 모두 m다. 오른쪽은 같은 입력의 최소제곱과 Huber 0.01 m 비교다. 대응점을 알고 있는 1차원 부분 문제이며 실제 ICP·차량·센서 벤치마크 점수가 아니다. 그림의 최적 위치를 일반화된 최적 임계값이라고 주장하지 않는다.

전이값이 매우 크면 대부분 잔차가 제곱 구간에 남아 평균에 가까워진다.
매우 작으면 큰 잔차의 기여를 제한하지만 깨끗한 Gaussian 관측의 효율과 수렴 특성도 변할 수 있다.
절대 단위 전이값을 다른 센서에 옮기려면 잔차 분산과 거리 의존성을 고려해야 한다.
잔차 r/sigma로 정규화한 뒤 무차원 임계값을 쓰는 설계가 가능하지만 sigma 자체가 신뢰할 만해야 한다.

여러 시퀀스에서 방법 A와 B를 비교한다면 차이 d_s=error_A_s-error_B_s를 같은 시퀀스끼리 짝지어 계산한다.
쉬운 시퀀스가 A에 더 많이 들어가고 어려운 시퀀스가 B에 더 많이 들어가면 전체 평균 비교는 편향된다.
실패한 시퀀스를 한 방법에서만 제외해도 같은 문제가 생긴다.
성공 구간 오차와 전체 완료율을 함께 기록해야 한다.

<a id="d24-7"></a>
### 7. 단위·통합·성질 테스트를 서로 다른 질문에 배치한다

단위 테스트는 작은 함수가 정해진 입력에서 맞는 값을 내는지 본다.
예를 들어 TSDF 평균 0.25, alpha 합성 [0.575,0.2,0.375], 0.2초 일정 가속도 위치 0.02 m를 검사한다.
이런 테스트는 손계산이 가능한 작은 수를 사용해야 오류가 생겼을 때 사람이 원인을 추적할 수 있다.
대형 장면에서 그림이 그럴듯하다는 검사만으로 대체하지 않는다.

통합 테스트는 단계 사이의 의미가 일치하는지 본다.
깊이 역투영 후 다시 투영했을 때 원래 픽셀을 얻는지,
스테레오 고정소수점 값을 16으로 나누었는지,
저장 좌표와 그림 축 변환이 일치하는지,
설정 파일 변경이 실제 코드 경로에 반영되는지 등이 해당한다.
외부 라이브러리 함수가 성공해도 이 연결은 틀릴 수 있다.

성질 property 테스트는 특정 숫자보다 일반적인 불변성을 검사한다.
모든 가중치에 같은 양수를 곱해도 가중 평균이 같아야 한다.
모든 alpha가 0이면 배경색, 맨 앞 alpha가 1이면 맨 앞 색이어야 한다.
공분산을 회전·투영해도 대칭성과 양의 준정부호 성질이 유지되어야 한다.
강체 변환과 그 역변환을 연속 적용하면 원점군으로 돌아와야 한다.

미분은 중앙 유한차분으로 확인할 수 있다.
함수 f의 k번째 입력에 eps를 더하고 뺀 차이를 2eps로 나누어 해석 야코비안과 비교한다.

```text
J_numeric[:,k] = [f(x+eps e_k)-f(x-eps e_k)]/(2 eps)
error = max_abs(J_analytic-J_numeric)
```

eps가 너무 크면 비선형 곡률의 오차가 남고, 너무 작으면 뺄셈 소거와 반올림 오차가 커진다.
투영점이 Z=0 부근이면 함수 자체가 특이하므로 일반적인 허용오차를 적용하면 안 된다.
본 테스트는 mu=[0.3,0.1,2] m에서 eps=1e-6으로 투영 야코비안을 확인한다.
“유한차분과 맞는다”는 사실은 그 지점의 구현 일치 근거이며 모든 상태에서의 안정성 증명은 아니다.

평면 야코비안 rank=3은 일부러 실패를 검사하는 테스트다.
테스트가 항상 좋은 숫자만 기대하면 알고리즘이 정보 부족을 감지하지 못해도 통과한다.
빈 입력·영가중치·무효 깊이·비단조 시간 같은 경계 조건도 실제 구현에서는 다뤄야 한다.
이 연구의 함수들은 교육용 유효 입력을 가정하므로 생산용 입력 검증 API를 완성했다고 주장하지 않는다.

<a id="d24-8"></a>
### 8. 평균 처리시간이 짧아도 결과가 늦게 올 수 있다

실시간은 평균적으로 빠르다는 뜻이 아니라 필요한 시간 안에 유효한 결과가 도착한다는 뜻이다.
센서가 주기 P로 입력을 만들고 처리시간이 s_i인 단일 FIFO 작업자를 생각하자.
FIFO는 First In, First Out, 먼저 들어온 작업을 먼저 처리하는 대기열이다.
입력 i의 도착은 a_i=iP이고 완료 시각 f_i는 이전 완료와 현재 도착 중 늦은 시점에서 시작한다.

```text
f_i = max(a_i, f_(i-1)) + s_i
latency_i = f_i - a_i
waiting_i = max(0, f_(i-1)-a_i)
latency_i = waiting_i + s_i
```

P=30 ms, 처리시간 [20,60,20] ms의 작은 예를 보자.
첫 입력은 t=0에 와서 20 ms에 끝나 지연 20 ms다.
두 번째는 t=30에 와서 90 ms에 끝나 지연 60 ms다.
세 번째는 t=60에 왔지만 90까지 기다리고 110에 끝나 지연 50 ms다.
세 번째 계산 자체는 20 ms인데 결과는 50 ms 오래된 입력을 설명한다.

큰 합성 실험은 120프레임, 주기 33.3333 ms, 평소 처리시간 20 ms, 20프레임마다 180 ms의 긴 작업을 넣었다.
평균 처리시간은 28 ms로 주기보다 작다.
그런데 95백분위 end-to-end 지연은 약 167.3333 ms였고 주기 안에 끝나지 못한 비율은 0.6이었다.
이 값은 실제 컴퓨터의 프로파일링이 아니라 명시한 대기열 재귀식의 결과다.

![D24-3 처리시간과 대기열 지연](../research/computer-vision-textbook/reconstruction/figures/d24_01_latency.png)

그림 D24-3. 위는 합성 FIFO에서 계산시간과 입력부터 완료까지의 지연을 구분한다. 가로축 프레임 인덱스, 세로축 ms다. 아래는 지연의 경험 누적분포 CDF로 x ms 이내에 끝난 비율을 읽는다. 긴 작업 뒤에서 지연이 여러 프레임 동안 남는 현상이 핵심이다. 실제 하드웨어·SLAM 런타임 측정값으로 해석하지 않는다.

대응 정책에는 오래된 프레임을 버리기, 최신 프레임만 유지하기, 전역 최적화를 별도 작업자로 옮기기 등이 있을 수 있다.
그러나 프레임을 버리면 운동 간격이 커져 추적이 어려워질 수 있고,
작업을 분리하면 지도 버전과 동시성 문제가 생길 수 있다.
지연 감소만 보고 정확도·완료율·시간 동기화 영향을 생략해서는 안 된다.
이 장은 그러한 정책을 생산 코드에 적용하지 않았고 큐 모델만 제시한다.

실제 프로파일링에서는 입력 획득, 전송, 디코딩, 전처리, 추적, 최적화, 지도 갱신, 출력 시각을 나눠 기록한다.
벽시계 시간 wall time과 CPU time도 다르다.
가속기 작업은 비동기로 제출될 수 있으므로 완료 동기화 없이 잰 함수 반환시간이 실제 계산시간보다 짧을 수 있다.
워밍업·캐시·스레드·동시 작업·전력 상태를 기록해야 런타임 비교가 해석 가능하다.

<a id="d24-9"></a>
### 9. 실패 분석은 원인 후보를 좁히는 실험 순서다

오차가 커졌다는 사실만으로 최적화기를 교체하지 않는다.
먼저 입력이 같은가, 좌표 방향과 단위가 맞는가, 시간 순서가 단조로운가, 무효값을 어떻게 처리했는가를 본다.
다음으로 대응점이 맞는가, 기하가 관측 가능한가, 모델 가정이 깨졌는가를 본다.
그 다음에 손실·최적화·수치 정밀도 문제를 살핀다.
단순한 상류 오류가 하류에서 복잡한 잔차 패턴으로 나타날 수 있기 때문이다.

| 관측된 현상 | 가능한 원인 | 구분 실험 |
|---|---|---|
| 깊이가 정확히 16배 다름 | 고정소수점 시차 스케일 | 알려진 시차의 손계산과 비교 |
| 회전 구간만 재투영 오차 증가 | 시간차·롤링셔터·회전 보정 | 속도별 잔차, 행별 잔차, timestamp 검사 |
| 평면에서 특정 이동 불안정 | rank 결손 | J의 영공간과 법선 분포 |
| 그림은 좋지만 치수 틀림 | 스케일·외관 보상 | metric 참조와 깊이 별도 평가 |
| 평균 runtime은 빠른데 출력 늦음 | 대기열·비동기 작업 | 입력 시각부터 완료까지 추적 |
| 프레임 수 증가에도 재현 차이 | 장면 상관·도메인 이동 | 장면별 분할·반복 실험 |

원인 후보를 하나로 확정하려면 반례를 제거하는 실험이 필요하다.
예를 들어 회전 중 오차가 크면 시간 오프셋과 롤링셔터가 모두 가능하다.
오프셋을 바꾸었을 때 전체 행에서 비슷하게 개선되는지, 행 위치에 따른 잔차 기울기가 남는지를 보면 모델을 구분할 단서가 된다.
이런 실험을 실제로 하지 않았다면 “원인”이 아니라 “가능한 원인”이라고 쓴다.

실패 기록에는 실패한 입력도 포함한다.
성공한 결과만 저장하면 다음 연구자는 어떤 조건에서 방법을 쓰지 말아야 하는지 알 수 없다.
재현 가능한 최소 실패 사례는 큰 성공 영상보다 디버깅에 더 가치 있을 수 있다.
이 부분 연구에서 각 장의 실패 사례는 공유 pose 오차/이상치, Lambertian 위반/잘못된 합성 순서, 시간·회전 누락/정렬 은폐, 상관·대기열·전이값 민감도다.

<a id="d24-10"></a>
### 10. 디지털 트윈·Astra·드론·VLA로 연결할 때 추가되는 계약

디지털 트윈을 단순히 보기 좋은 3D 장면과 동일시하지 않는다.
어떤 물리 대상을 어떤 시간의 어떤 상태로 나타내며, 치수·좌표·속성·갱신 이력을 무엇으로 검증하는지가 필요하다.
렌더링용 Gaussian이나 메시를 만들었다면 시각화 자산은 얻었지만,
충돌 질의의 unknown 처리, 재질의 물리 파라미터, 유지보수 상태, 실제 좌표 정합은 별도로 남을 수 있다.
사용 목적이 치수 검사이면 metric 정확도와 측정 불확실성이, 외관 검토이면 시점별 재현과 노출 조건이 중요하다.

Astra와 같은 RGB-D 장치를 연구에 연결할 때는 제품군 이름만으로 보정·깊이 단위·센서 방식·타임스탬프를 가정하지 않는다.
본 연구는 특정 Astra 모델을 연결하거나 실측하지 않았다.
필요한 자료는 실제 모델 식별, 펌웨어·드라이버 버전, depth scale, 내부 보정, 깊이-색 외부 보정, 유효 범위, 무효값 코드, 노출 시각의 의미다.
수집 후에는 알려진 평면·거리에서 단위와 편향을 확인하고 색 정렬은 별도의 가시성 검사로 본다.
이 목록은 장비 운용 완료 보고가 아니라 다음 단계의 데이터 계약이다.

드론 관련 지도 활용에서는 지도 정확도 외에도 상태 추정의 최신성, 동적 장애물, 미관측 영역, 지연과 실패 상태가 중요하다.
이 교재는 실제 비행, 제어 명령, 장애물 통과, 안전 인증을 수행하지 않는다.
시뮬레이션·기록 재생에서의 평가와 실제 기체 검증은 구분하고,
독립적인 감독과 위험 제한 없이 이 교육 코드를 제어기에 연결하지 않는 경계를 둔다.
센서가 특정 순간에 오차를 냈을 때 시스템이 유효하지 않은 상태를 어떻게 드러내는지가 수치 정확도와 함께 검토되어야 한다.

VLA는 Vision-Language-Action, 영상·언어·행동을 연결하는 모델이다.
OpenVLA는 로봇 행동 데이터로 시각·언어 입력에서 행동을 예측하는 공개 연구의 한 예다.
이 장은 해당 모델을 다운로드·학습·실행하지 않았다. [Kim·Pertsch·Karamcheti 외, OpenVLA, 2024](https://openvla.github.io/)

KITTI의 이미지와 차량 pose만으로 로봇 조작의 행동 목표가 자동으로 생기지 않는다.
행동 학습에는 관측 시각에 대응하는 명령, 명령 좌표계, 이동·회전 단위, 그리퍼 상태, 제어 주기, 로봇 몸체, 성공·실패·중단 조건 같은 추가 자료가 필요하다.
같은 숫자 0.1도 0.1 m 상대 이동인지, 정규화 토큰인지, 관절 각도인지에 따라 완전히 다른 행동이다.
시각적으로 좋은 지도가 행동의 안전성과 성공을 보증하지 않는 이유가 여기 있다.

행동 데이터에는 무엇이 일어났는지뿐 아니라 어떤 명령이 언제 적용되었는지도 필요하다.
영상 지연과 명령 지연이 섞이면 학습기는 현재가 아닌 과거 관측에 대한 행동을 배울 수 있다.
실패한 행동을 데이터에서 지우면 위험 조건의 분포가 사라질 수 있다.
데이터의 권한·사람과 환경의 프라이버시·실험 중단 절차도 실제 프로젝트에서 별도 검토 대상이다.
본 연구의 산출물은 그 검토를 대신하지 않는다.

<a id="d24-11"></a>
### 11. 논문을 가설에서 ablation까지 읽는 연구 경로

첫 읽기에서는 논문의 최신성보다 문제의 계약을 추출한다.
입력은 무엇이고 출력은 무엇인가, 어떤 변수를 추정하며 어떤 변수를 이미 안다고 두는가를 쓴다.
NeRF에서 알려진 pose, 광도 스테레오에서 알려진 조명, 사전적분에서 바이어스 선형화점은 서로 다른 종류의 조건이다.
이 조건을 빼고 기법 이름만 옮기면 실행할 수 없는 설계가 된다.

둘째 읽기에서는 핵심 식 하나를 작은 수로 계산한다.
TSDF는 분자·분모 누적, ICP는 한 점의 J, NeRF는 세 구간의 alpha,
3DGS는 한 Gaussian의 투영 공분산, 사전적분은 두 시간 간격의 p·v·R을 선택한다.
중간 단위와 부호를 사람이 설명할 수 없으면 대형 코드의 출력도 검증하기 어렵다.
이 교재의 풀이와 테스트는 그 단계의 재사용 가능한 최소 예다.

셋째 읽기에서는 논문의 주장과 이를 지지하는 실험을 일대일로 대응시킨다.
정확도가 좋아졌다는 주장은 어떤 데이터·정렬·실패 처리에서 성립하는가,
빠르다는 주장은 어떤 하드웨어·해상도·학습 포함 여부에서 측정했는가,
강건하다는 주장은 어떤 분포 이동이나 이상치 조건을 실제로 바꾸었는가를 확인한다.
논문 초록의 형용사를 자신의 데이터에 대한 결론으로 옮기지 않는다.

넷째 읽기에서는 가장 싼 반증 실험을 만든다.
평면 ICP라면 법선을 모두 같은 방향으로 만들고,
광도 스테레오라면 조명 하나를 오염시키고,
시간 정렬이라면 알려진 offset을 넣고,
실시간 주장이라면 짧은 평균과 긴 tail을 가진 처리시간을 생성한다.
작은 실험에서 핵심 가정의 효과가 보이면 그 다음에 실제 데이터와 완전한 구현으로 넓힌다.

다섯째 읽기에서는 후속 논문이 원 방법의 어느 제한을 바꾸는지 표시한다.
표현을 바꾸는가, 샘플링을 바꾸는가, 최적화를 바꾸는가, 센서를 추가하는가, 평가 범위를 넓히는가를 구별한다.
예를 들어 TSDF에서 ESDF를 만드는 것은 외관을 더 사실적으로 만드는 문제가 아니라 거리 질의의 문제다.
다중 스케일 렌더링은 좌표 표현의 이름만 바꾸는 것이 아니라 픽셀 면적과 샘플링 문제를 다룬다.
후속 방법이 오래된 방법의 모든 목적을 포함한다고 가정하지 않는다.

이 부분의 추천 읽기 순서는 Curless–Levoy의 거리 누적, Rusinkiewicz–Levoy의 ICP 단계 분리,
Woodham의 조명-법선 선형계, Forster의 좌표계 사전적분,
NeRF의 광선 합성, 3DGS의 표현·투영, DynaSLAM의 정적 가정 완화다.
그 다음 실제 사용 목적에 따라 Voxblox의 거리 질의 또는 VLA의 행동 데이터 계약으로 갈라진다.
모든 경로를 한 번에 완전 구현하는 것이 학습의 성공 기준은 아니다.

<a id="d24-13"></a>
### 13. 풀이가 있는 연습문제: 실험 설계를 수치로 검산한다

**문제 D24-A. 상관된 표본의 평균 분산을 계산하라.**
S=10장면, 장면당 m=50프레임, sigma_b=1 m, sigma_epsilon=0.1 m일 때 올바른 평균 분산과 프레임 독립 근사를 비교하라.

**풀이.** 올바른 값은 1/10+0.01/500=0.10002 m²다.
독립 근사는 1.01/500=0.00202 m²다.
표준오차는 각각 sqrt(0.10002)≈0.316259 m와 sqrt(0.00202)≈0.044944 m다.
프레임 수는 같아도 장면 공통 오차 때문에 약 7배의 표준오차 차이가 생긴다.
시퀀스 상관을 무시한 좁은 신뢰구간이 왜 과신을 유발하는지 보여준다.

**문제 D24-B. FIFO의 지연을 직접 구하라.**
도착 주기 30 ms, 서비스 시간 [20,60,20] ms에서 각 도착·완료·지연을 표로 써라.

**풀이.** 도착은 [0,30,60], 완료는 [20,90,110], 지연은 [20,60,50] ms다.
마감이 한 주기라면 두 번째와 세 번째가 초과한다.
평균 서비스 시간은 100/3 ms이고 평균 지연은 130/3 ms다.
평균 서비스와 평균 지연의 차이는 세 번째 입력이 기다린 30 ms를 세 입력에 나눈 10 ms다.
`test_19_queue`는 이 재귀식의 구체적인 계산을 검사한다.

**문제 D24-C. 실패를 제외한 평균이 왜 위험한가?**
방법 A는 세 시퀀스에서 [0.1,0.2,실패] m, B는 [0.2,0.3,0.4] m를 기록했다.
실패를 버린 평균만으로 A가 우수하다고 결론 내릴 수 있는가?

**풀이.** 성공 구간 평균은 A=0.15 m, B=0.3 m지만 완료율은 A=2/3, B=1이다.
서로 다른 입력 집합의 평균이고 실패의 비용도 정의되지 않았다.
공통 성공 구간에서는 A=0.15 m, B=0.25 m라는 별도 비교가 가능하지만 전체 시스템 우열은 아니다.
완료율과 성공 구간 오차를 함께 보고하고, 실패 패널티를 쓸 경우 그 값을 사전에 정한다.
임의로 실패를 0 m 또는 무한대로 치환하면 다른 질문을 만들게 된다.

**문제 D24-D. 주장에 맞는 최소 테스트를 고르라.**
개발자가 “새 투영 코드가 정확하고, 더 빠르며, 모든 환경에서 안전하다”고 주장한다.
이 장의 유한차분·한 번의 wall time·합성 큐 실험 중 무엇이 각각을 지지하는가?

**풀이.** 유한차분은 특정 유효 지점에서 해석 미분과 구현의 일치를 지지한다.
한 번의 wall time은 그 실행에서 걸린 시간을 기록할 뿐 일반적인 속도 우위를 지지하지 않는다.
합성 큐는 입력·서비스 가정 아래 지연 현상을 보여줄 뿐 실제 안전성을 지지하지 않는다.
속도 우위에는 통제된 반복·동일 하드웨어·동일 입력·정확도 조건이 필요하고,
모든 환경의 안전성은 이 실험들이 다루지 않는 범위다.
주장을 작은 검증 가능한 문장들로 나누는 것이 정답이다.

### 14. 용어 사전: 계산에서 어디에 등장하는가

| 용어 | 풀어 쓴 이름 또는 의미 | 이 부분에서의 계산상 역할 |
|---|---|---|
| TSDF | Truncated Signed Distance Function | 절단 거리 관측의 가중 누적 |
| ESDF | Euclidean Signed Distance Field | 최근접 장애물 거리 질의 |
| ICP | Iterative Closest Point | 대응과 변환 갱신의 반복 |
| KD-tree | k-dimensional tree | 기하 이웃 검색 자료구조 |
| PCA | Principal Component Analysis | 이웃 공분산의 주성분; 최소 축이 평면 법선 |
| BRDF | Bidirectional Reflectance Distribution Function | 입사·출사 방향의 반사 관계 |
| radiance | 복사휘도 | 특정 위치·방향으로 나가는 빛 |
| alpha | 구간 종료·불투명 합성 계수 | 앞쪽 투과율과 곱해 색 기여 계산 |
| NeRF | Neural Radiance Fields | 좌표 함수로 밀도·방향 의존 외관 표현 |
| 3DGS | 3D Gaussian Splatting | 타원체 투영과 alpha 합성 |
| IMU | Inertial Measurement Unit | 각속도와 specific force 측정 |
| VIO | Visual-Inertial Odometry | 시각·관성 상대 운동 추정 |
| ATE | Absolute Trajectory Error | 정렬 정책 이후 전역 궤적 차이 |
| RPE | Relative Pose Error | 고정된 시간·거리 간격의 상대 운동 차이 |
| RMSE | Root Mean Square Error | 제곱 평균의 제곱근, 이상치에 민감 |
| SE(3) | 3D 특수 유클리드 변환군 | 회전·이동만 허용 |
| Sim(3) | 3D 유사변환군 | 회전·이동·균일 스케일 허용 |
| NEES | Normalized Estimation Error Squared | 추정 공분산 대비 상태 오차 |
| GT | Ground Truth | 입력과 분리한 평가 참조 |
| FIFO | First In, First Out | 도착 순서 대기열 |
| CDF | Cumulative Distribution Function | 특정 지연 이하 완료 비율 |
| ablation | 요소 변화 비교 | 같은 입력에서 원인 기여 분리 |
| oracle | 실제로는 알 수 없는 정답 사용 | 완벽한 마스크·GT 정렬의 한계 표시 |
| VLA | Vision-Language-Action | 관측·언어에서 행동을 예측하는 문제 |

용어를 외웠는지보다 각 변수의 단위와 관측 근거를 말할 수 있는지로 이해를 확인한다.
alpha와 occupancy가 모두 [0,1]이라고 같은 확률로 취급하지 않고,
TSDF와 ESDF가 모두 거리라는 이름을 가졌다고 같은 질의를 하지 않고,
ATE가 작다고 지연·관측가능성·실패율까지 좋다고 결론 내리지 않는다.
이 네 장의 연결점은 새로운 이름을 많이 아는 것이 아니라 계산과 주장 사이의 계약을 유지하는 데 있다.
